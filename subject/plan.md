## 1. 목표

**외국인이 대구 병원 정보를 스스로 찾고, 고른 병원에 직접 상담·시술 예약 요청을 보내면, 병원 캘린더에 요청이 들어가는 프로토타입**

- 웹페이지 2개를 시연
  - **① 환자용 정보 웹**: 병원 찾기 → 병원 상세 → 예약 요청서
  - **② 병원용 대시보드**: 캘린더에 요청 표시 → 직원이 확정·거절·시간 제안
- 서비스 본체는 **공공정보 제공**. 예약 요청은 "병원이 받는 접수 창구 하나"로 설계 ([규제-예약요청-캘린더.md](../research/의료관광/규제-예약요청-캘린더.md))
- 프로토타입은 **가상 병원·가상 환자 데이터**로만 시연 (실제 병원·환자 정보 X)

## 4. 에이전트 설계

| 에이전트 | 하는 일 | 하지 않는 일 |
|---|---|---|
| 환자 쪽 입력 도우미 | 요청서 칸 채우기 도움, 번역, 빠진 정보(날짜·연락처·비자) 알려주기 | 병원 고르기, 시술 추천, 증상 판단, 환자 대신 제출 |
| 병원 쪽 요청 정리 | 요약·번역·답장 초안 | 자동 확정, 의료 판단, 가격 흥정 |
| 챗봇 (정보) | 공공 문서 검색 → 출처·기준일과 함께 답 | 학습 지식만으로 답, 특정 병원 추천 |

- 숫자(진료시간·가격)는 **코드가 데이터에서 그대로** 넣고, LLM은 문장만 작성
- LLM: 데모는 무료 API(Nemotron 3 등) + **가상 데이터만** (무료 엔드포인트는 입력이 기록됨, 국외 이전 문제) ([폴더구조-무료LLM-검토.md](../research/기술/폴더구조-무료LLM-검토.md))
- 지원 언어: 9절 참고 (UI는 i18n 파일, LLM은 언어별 테스트 후 범위 결정)

## 5. 규제 안전장치 (요약)

| 원칙 | 구현 |
|---|---|
| 병원에서 건당·성과 수수료 받지 않음 | 결제·정산 기능 없음 |
| 병원 선택은 환자 | 요청서는 병원 상세에서만 시작, 1곳씩 |
| 확정은 병원 | 상태값 "대기"로 저장, 확정 버튼은 병원 대시보드에만 |
| 유료·제휴 병원 우대 X | "온라인 요청 가능"은 필터일 뿐 정렬에 미반영 |
| 등록 유치의료기관만 요청 받기 | 병원 계정에 등록 여부 필드 |
| 의료 판단 X | 챗봇·도우미 거절 규칙 + `ai/eval` 테스트셋 |
| 민감정보 별도 동의 | 동의 화면 2개, 건강정보 칸은 선택 |
| 유일한 접수 창구 X | 병원 상세에 전화·이메일 항상 표시 |
| 사후관리 Q&A·이벤트가·후기·순위 X | 기능 자체 없음 |

### 애드센스 주의
- **병원·시술 광고가 우리 정보 옆에 뜨면** "중립 공공정보" 원칙과 충돌하고, 이벤트가 광고가 노출될 수 있음 → 애드센스 **차단 설정에서 건강(Health)·미용 등 의료 관련 카테고리 차단** [A1]. 단 Google도 차단을 **보장하지 않는다고** 명시 [A1]
- 광고는 **목록·상세 옆에만**, 예약 요청서·동의 화면·챗봇 답변 안에는 넣지 않음
- 이용자가 일평균 10만명을 넘으면 병원이 우리 매체에 광고할 때 **사전 심의 대상 매체**가 됨 (의료법 제57조, 시행령 제24조) ([규제-가격노출-의료광고.md](../research/의료관광/규제-가격노출-의료광고.md))
- 공공 위탁(A안)과 함께 하면 위탁 조건상 광고가 허용되는지 **미확인** → BM을 구독+광고로 가면 A안은 보조로

### 진행 방법 (실현 가능성 검증용)
- **처리 기간**: 법령 해석 질의민원 **14일 이내**, 제도·절차 질의 **7일 이내** (민원 처리에 관한 법률 시행령 제14조) [B1]
  → 10/29~10/30 접수해도 법령 해석 답변은 11/9 진행 발표 이후일 수 있음 (최종 발표 12/9 전에는 도착 예상)
- 발표 전략: 답변이 없어도 **"질의 접수 완료(접수일·질문 요지) + 우리 판단 근거(조문·판례)"**를 보여주면 검증 과정 자체가 근거가 됨. 답변이 오면 추가
- 빨리 받을 수 있는 경로 (병행): 한국보건산업진흥원 외국인환자 유치 담당 전화 문의(제도·절차 성격), 대구시 의료관광 담당 부서, 멘토
- 접수는 팀원이 직접 (팀 계정·실명 필요). 질의서 초안은 위 표 1~3번으로 작성
