# 주제: 대구 의료관광객 늘리기

> 외국인 환자가 믿을 수 있는 대구 병원을 자기 언어로 찾고, 가격·진료시간까지 확인할 수 있는 서비스

## 문제
- 외국인 환자는 믿을 만한 병원인지, 가격이 적정한지 판단할 정보가 없고, 있어도 한국어뿐
- 2025년 대구 외국인 환자 19,243명, 전년 대비 +31.4% — 한국보건산업진흥원 보고서 원문 표 2.13·3.73에서 확인 (상세: research/의료관광/메디시티-병원-신뢰-가격-비교.md)

## 조사 계획

| 조사 항목 | 내용 |
|---|---|
| 데이터 확보 | 심평원 비급여 API에 의원급(피부·성형) 포함 여부, 유치기관·인증·전문병원 데이터 |
| 기존 서비스 | 메디컬코리아 등 기존 외국인 환자 안내 서비스와 무엇이 다른지 |
| 사용자 수요 | 외국인 환자 통계와 후기 |
| 기술 검증 | 기관별 병원명 매칭(주소·요양기호), 다국어 처리 |

### 데이터 채우기 원칙
1. **API 먼저 테스트** — API로 받을 수 있는 항목은 직접 수집하지 않음
2. **빈칸 목록 확정** — 테스트 후 "API에 없거나 비어 있는 항목"만 표로 정리
3. **직접 채우기는 범위를 좁혀서** — 예: 중구·수성구 피부과·성형외과 상위 병원부터 (전체 병원 아님)
4. **직접 채운 값은 칸마다 출처 URL·확인일 기록**, API 값과 구분하는 열(source: api / manual) 추가
5. 직접 채울 가능성이 높은 항목(추정): 임시 휴진, 이벤트·패키지 가격, 외국어 상담 가능 여부, 번체·태국어·베트남어 번역
