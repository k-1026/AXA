## 0. 한 장 요약

```
[왜]   대구 외국인환자는 늘지만(19,243명, +31.4%) 전국 비중 1.0% · 정보는 한국어뿐 · 문의는 병원마다 따로
  ↓
[누구] 이용자: 단기 방문 외국인 미용·외래 환자(대만 등)   돈 내는 쪽: 대구 등록 유치의료기관
  ↓
[무엇] AI 챗봇 → 상담 예약 → 병원 확정 → 사후관리  +  입점 병원 대시보드
  ↓
[어떻게] 공공데이터(출처·확인일) + AI 오케스트레이터 + 규제 안전장치
  ↓
[돈]   등급형 회원: 기본 무료 + 수수료 13% / 프리미엄 연 ₩1,800,000 + 수수료 8% — 요금안 v4 (11/18)
  ↓
[검증] 시장(market/) · AI(eval) · 법률(research/의료관광) · 사용자 테스트
  ↓
[목표] 12/4 최종 발표: 챗봇으로 병원 찾기 → 상담 예약 → 병원 확정 → 사후관리 시연
```

## 2. 서비스 프레임 (환자 여정 × 기능)

| 산업 단계 | 환자가 하는 일 | 메디대구 기능 | 병원이 하는 일 |
|---|---|---|---|
| 1 수요·동기 | 한국 의료 관심 | 유입 마케팅 (대만 최종안): 병원·시술 광고 없는 정보 계정 — 인스타그램(릴스·캐러셀) + Dcard 정보 글 → 메디대구 링크 — [marketing/](../marketing/README.md) | 예약 링크·QR을 자기 채널에 붙임 |
| 2 정보·비교 | 병원·가격·진료시간 확인 | **AI 챗봇**, 병원 찾기·지도·상세, 가격 가이드 | 입점·정보 입력 |
| 3 상담·유치 | 상담 예약 요청 | **상담 예약** (채팅 원스톱 / 달력 예약) | **대시보드**에서 확인·확정·시간 제안 |
| 4 비자·이동 | 서류·일정 준비 | 절차 안내만 (RAG) | — |
| 5 진료·체류 | 진료 | (미포함) | 진료 |
| 6 정산 | 진료비 지불 | **건당 중개수수료 발생 지점** | 수수료 정산 |
| 7 사후·환류 | 방문 후 문의 | **사후관리 채팅** + AI 요약·키워드, 마이페이지 | 후속 대응, 대시보드 집계 |

## 4. AI 프레임 (챗봇 오케스트레이션)

```
사용자 메시지 → safety(응급 차단·개인정보 가림·의료 판단 부분 거절)
 → 의도 판단 → 하위 에이전트(도구) 호출 → 대화 상태 갱신
 → 사용자 언어로 답 + 카드 + "AI 생성" 표시
```

| 에이전트 | 역할 | 경계 |
|---|---|---|
| 오케스트레이터 | 의도 판단·위임·통합 | 스스로 의료 판단 X |
| 병원 탐색·추천 | 조건 검색, 추천 최대 3곳 + 이유 + 수수료 관계 고지 | "최고"·비교·후기 X |
| 정보 Q&A (RAG) | 절차·비자·공공 가격, 출처·기준일 | 학습 지식만으로 답 X |
| 가격 안내 | 공공 비급여 금액을 코드가 그대로 | 숫자 생성 X |
| 상담 예약 | 빈칸 채우기 → 동의 → 요약 카드 → **환자가 제출** | 대신 제출 X |
| 예약 상태 · 사후 문의 | 마이페이지 상태, 사후 비의료 문의를 병원 채팅으로 | 의료 상담 X |
| 병원 쪽 정리 · 인사이트 | 요약·번역·답장 초안(직원 승인), 비식별 집계 | 자동 확정·식별정보 X |

- 검증: 안전 문장 70/70, 의도 27/27, 원스톱 시나리오 10/10 (11/10 기준, ai/agent/eval/results/)
- 근거: subject/plan.md 12-2~12-5 · docs/agent-spec.md
