## 4. 알게 된 것
1. **API 진료시간은 4곳 중 1곳만** 채워져 있음 (전체 26.1%, 피부과 21.4%, 성형외과 14.1%)
2. **비급여 API는 병원급만** (의원급 0곳), **보톡스·필러·쌍꺼풀 등 미용 시술 코드 없음**
3. 등록된 홈페이지 주소 58곳 중 32곳(55%) 못 씀
4. 홈페이지에 외국어 상담을 명시한 병원 없음 → 다국어 안내가 차별점 근거
5. 카카오맵 "영업정보"와 "병원정보" 시간이 10곳 넘게 서로 다름
6. 좌표는 위도·경도 형식이라 지도에 바로 사용 가능
7. 수성구 유치 등록 기관은 한의원 비중이 큼(18/47)
8. (10/29) **서비스 경계**: 공공데이터 열람·연락처 링크·공식 등록 표시는 O / 병원 수수료·예약 대행·순위·이벤트가는 X
9. (10/29) 정부·대구 문서가 "수도권 편중", "정보 플랫폼 부족"을 과제로 적음 → 정책 근거
10. (10/29) **메디컬코리아 대구**: 등록 145곳 중 상세정보 13곳, 인증 1곳, 진료시간·가격 없음
11. (10/29) **공공 가격은 쓸모가 제한적**: 가격 있는 224곳 중 223곳이 제증명수수료 포함, 의료관광 관련은 임플란트 22곳·도수치료 127곳 정도. 외국인(건보 미가입자)에게 같은 금액인지 미확인 → 가격 숫자 대신 "예상 진료비를 서면으로 받을 권리"(해외진출법 제8조 제2항) 안내
12. (10/29) **사후관리 Q&A는 불가** (멘토 판단 + 해외진출법 제16조는 의사 → 국외 의료인만 허용)
13. (10/29) 국내에 외국인등록을 한 사람은 법상 "외국인환자"가 아님 (시행규칙 제2조) → 일반 알선 금지 적용
14. (10/29) Nemotron 3 무료 API: 공식 지원 언어에 베트남어·태국어 없음, 무료 엔드포인트는 입력이 기록됨 → 데모는 가상 데이터만

## 5. 정리한 결정
- API로 받을 수 있는 것은 직접 수집하지 않고, 빈칸만 직접 채움 (칸마다 출처·확인일)
- 수성구 목록에서 제외: 베러미의원 범어점(지도에 없음), 심신한방신경정신과한의원(시간 정보 없음 + 수요 낮다고 판단, 근거는 미확인)
- 한 곳에서 못 찾아도 다른 플랫폼 확인 후 삭제
- 공개 저장소에 팀원 실명·대표자명·API 키 올리지 않음 (`.env`는 .gitignore)
- (10/29) 대표자 실명 원본 2개, 강남언니·모두닥 크롤링 3개는 `.gitignore`로 제외
- (10/29) **기술 스택**: 프론트 React + TypeScript, 백엔드 FastAPI (DB·캘린더·i18n·지도 라이브러리는 제안 단계)
- (10/29) **MVP 범위**: 공공정보 제공 + 예약 요청 → 병원 캘린더 (가상 데이터로 시연). 제외: 사후관리 Q&A, 이벤트가·할인, 1:1 실시간 상담(확장), 크롤링 가격
- (10/29) **수익 모델**: 병원용 예약 에이전트 월 고정 구독료 + 정보 웹 애드센스 (의료 관련 광고 카테고리 차단, 요청서·동의 화면엔 광고 X)
- (10/29) **데모 언어 제안**: 영어·중국어 간체·베트남어·중국어 번체 (대구 외국인환자 국적 상위 4개, 68.9%) — 팀 확정 필요
