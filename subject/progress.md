## 4. 알게 된 것
1. **API 진료시간은 4곳 중 1곳만** 채워져 있음 (전체 26.1%, 피부과 21.4%, 성형외과 14.1%)
2. **비급여 API는 병원급만** (의원급 0곳), **보톡스·필러·레이저·쌍꺼풀 등 미용 시술 코드 없음** → 피부·성형 가격은 직접 수집 필요
3. **등록된 홈페이지 주소 58곳 중 32곳(55%) 못 씀** (도메인 없음·다른 사이트·주소 없음)
4. **홈페이지에 외국어 상담을 명시한 병원 없음** → 다국어 안내가 차별점 근거
5. 카카오맵에는 "영업정보"와 "병원정보(심평원 계열)" 두 시간이 있고 10곳 넘게 서로 다름
6. 좌표는 위도·경도 형식이라 지도에 바로 사용 가능
7. 수성구 유치 등록 기관은 한의원 비중이 큼(18/47) → 한방 의료관광 연계 가능성

## 5. 정리한 결정
- API로 받을 수 있는 것은 직접 수집하지 않고, 빈칸만 직접 채움 (칸마다 출처·확인일)
- 수성구 목록에서 제외: 베러미의원 범어점(지도에 없음), 심신한방신경정신과한의원(시간 정보 없음 + 수요 낮다고 판단, 근거는 미확인)
- 범어봄 한의원은 카카오에 없었지만 모두닥에서 확인해 유지 → 한 곳에서 못 찾아도 다른 플랫폼 확인 후 삭제
- 공개 저장소에 팀원 실명·대표자명·API 키 올리지 않음 (`.env`는 .gitignore)
