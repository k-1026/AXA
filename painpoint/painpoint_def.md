## P1 (Top 1) — 진료시간 정보 없음

**진술문:** 짧은 일정으로 대구에서 피부 시술을 받으려는 대만 단기 방문객이 / **비교·결정 단계에서** / 일정에 맞는 병원을 고르려다 / 대구 병원 대부분의 진료시간이 공개 자료에 비어 있고 플랫폼마다 표시 기준이 달라 / 진료 가능한 날을 미리 확인하지 못한다.

| 항목 | 내용 |
|---|---|
| 여정 단계 | ② 비교·결정 (감정 최저점) |
| 근거 | E01 진료시간 채움 26.1% (피부 21.4%, 성형 14.1%) · E04 트립닥 진료시간 기준 섞임 — 데이터 1 · 공식 1 |
| 점수 | 빈도 5 × 강도 4 × 해결 가능성 4 = **80** |
| 측정 신호 | **대상 병원 진료시간 채움률** (지금 26.1%) — journey_3actors H0 |
| 밸류체인 연결 | 병목 B1 → 고객 쪽에서 확인됨 · 우선 기회 O1(공공데이터 + 출처·확인일)과 같은 자리 |
| 결정 이유 | 근거가 가장 강하고(대구 전체 데이터), 감정 최저점 단계이며, 밸류체인 우선 기회 O1과 이어져 MVP 핵심 가설로 바로 쓸 수 있음 |
