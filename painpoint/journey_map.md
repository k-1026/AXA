## 읽는 법

- **감정 최저점은 ② 비교·결정** — 근거 있는 불편(E01·E02·E07)이 가장 많이 몰린 단계. 11/9 기존 지도의 결론("② 비교·결정이 결정적 순간")과 같음
- ①과 ②는 **같은 뿌리(공개 정보 부족)**지만 원인이 다름: ①은 "등록 병원 상세·외국어 정보", ②는 "진료시간"과 "가격" → 진술문 3개로 나눔 (원인 하나당 진술문 하나)
- ③ C-4는 **환자 쪽 근거가 가정뿐** → 병원 쪽 근거(E10·E11)는 [journey_3actors.md](journey_3actors.md) 코디 여정에서 보완
- 밸류체인 마커 대조: B1 → C-1로 고객 쪽에서 확인됨 · B2 → C-4 (가정) · C1·C2는 고객 쪽에서 안 보임 → 회사 내부 문제

## 감정 점수 매긴 방법 (VOC 대신)

수업 기준은 "같은 단계 VOC의 긍정·부정 건수 비율"인데, 우리는 VOC가 없어서 **그 단계 근거의 순 강도**(불편 근거 강도 합 − 강점 근거 수, 가정 G.. 제외)로 매김. 그래서 감정 칸 전체가 **[가정]**.

| 순 강도 | 감정 |
|---|---|
| 6 이상 | −2 |
| 2~5 | −1 |
| 1 이하 | 0 |
| 강점만 있음 | +1 |

- 생각 칸은 VOC 원문 인용 대신 페르소나 걱정(G03)과 근거에서 뽑은 질문형 문장 — 전부 **[가정]**
- 확인 방법: 대구 체류 대만인 2~3명 인터뷰, 데모에서 ② → ③ 넘어가는 비율 측정
