## 1. 시장 규모 → 월 방문 완료 건수 (v2 · log #2)

```
연 대상 환자     = 대구 대만 환자 × 미용·외래 비중
연 메디대구 경유 = 연 대상 환자 × 경유율
월 방문 완료     = 연 메디대구 경유 ÷ 12
```

## 2. 플랫폼 수익 (v4 · 11/18 등급형 회원)

> **v4 (11/18 팀 결정)**: 기본 회원 무료 + 수수료 **13%** / 프리미엄 회원 **월 ₩150,000** (연납 ₩1,800,000, 첫 3개월 ₩69,000 제안) + 수수료 **8%** — 근거·비교: [요금안-or-검토.md](요금안-or-검토.md) 결정 v4 · 2-4절 (업계 공개 요율 15~25%)

```
월 수익 = Σ기본 병원 (월 건수 × 1건 진료비 × 13%) + Σ프리미엄 병원 (₩150,000 + 월 건수 × 1건 진료비 × 8%)
1건 공헌이익: 기본 1,000,000 × 13% − 5,000 = 125,000원 · 프리미엄 1,000,000 × 8% − 5,000 = 75,000원 (+ 병원당 월 ₩150,000)
```

| 경우 (월 고정비 271만 원, 11/19 호스팅 확인 — 11/18까지 275만, 결과 건수 같음) | 손익분기 |
|---|---|
| **기본 회원만** | 2,710,000 ÷ 125,000 ≈ 21.7 → **월 22건** (예상 월 10건의 2.2배) |
| 프리미엄 병원(월 5건)만 | 병원당 150,000 + 5 × 75,000 = 525,000원 → 2,710,000 ÷ 525,000 ≈ 5.2 → **6곳** |
| 기본 회원만, 1건 50만 원 | 2,710,000 ÷ 60,000 ≈ 45.2 → 월 46건 |
| 팀 4명 최저임금 포함 (월 약 884만 원 = 최저임금 월 2,156,880원 × 4 + 호스팅·보증보험·수작업 21만, 11/18까지 888만) | 기본만 8,837,520 ÷ 125,000 ≈ 70.7 → 월 71건 · 프리미엄(월 5건)만 ≈ 16.8 → 17곳 · 1건 50만 원이면 기본만 월 148건 |
| 예시: 입점 10곳 = 기본 7곳(월 1건) + 프리미엄 3곳(월 5건) [가정] | 월 245만 원 → 271만 원에 약간 못 미침 |

- 병원 1곳 한 달 (대시보드 시안, 결제 21건, 프리미엄): 21 × 1,000,000 × 8% + 150,000 = **₩1,830,000 = 진료비의 8.7%** (같은 24명을 광고로 받으면 약 ₩4,800,000)

## 2-v3. 플랫폼 수익 (v3 기록 · 11/18 요금안 v3.1)

> v3: 요금안 v3.1 (11/16 팀 결정, 병원 대시보드 시안 적용) — **수수료 10% + 월 구독료 ₩69,000/₩99,000 (첫 3개월 무료)** 둘 다 받음. 근거: `docs-dashboard-integration` 브랜치 research/company/가격산정-경쟁사분석.md 3-3절 · v2(지정 % 7%, 구독은 선택·합계 제외)는 아래 표의 "v2" 열

```
월 수수료 수익 = 월 방문 완료 × 1인 진료비 × 10%
월 구독 수익   = 입점 병원 수 × 월 구독료 (사후관리 이용 ₩69,000 / 미이용 ₩99,000, 입점 4개월째부터)
월 광고 수익   = 월 배너 노출 ÷ 1,000 × 1천 회당 단가
상한 확인 (병원마다) = (그 병원 월 수수료 + 구독료) ≤ 그 병원 경유 진료비 × 종별 상한 (의원 30%, 확인값) — 구독료 합산 여부 [U]
```

**계산 (v3, 입점 4개월째부터)**
- 수수료: 10 × 1,000,000 × 10% = **월 100만 원**
- 구독: 10 × 69,000 = **월 69만 원** (미이용이면 99만 원)
- 광고: 20,000 ÷ 1,000 × 3,000 = 월 6만 원
- **합계 월 175만 원** (계산값, 153만 원 기준일 때 228만 원) · v2는 월 41만 원(구독 제외)
- 병원 1곳 기준(시안, 방문 24명 · 결제 21건 × 100만 원): 수수료 ₩2,100,000 + 구독 ₩69,000 = ₩2,169,000 = **진료비의 10.3%** → 상한 30%의 약 1/3. 단 **환자가 0명인 달엔 구독료만** 내므로 그 달 비율은 계산이 안 됨 → 상한 합산 여부 질의 필요 (C2)

## 4. 병원 코디 업무 절감 — 월 구독료의 **가설** (v2 · log #4: 결론이 아니라 확인할 가설)

```
월 절감 시간 = 월 외국어 상담 건수 × (기존 1건 처리 시간 − AI 초안 후 처리 시간)
월 절감액   = 월 절감 시간 × 코디 시급
```

| 변수 | 값 | 표시 | 근거·확인 출처 후보 |
|---|---|---|---|
| 월 외국어 상담 건수 (병원 1곳) | 60건 | 가정값 | 병원 인터뷰 |
| 기존 1건 처리 시간 | 25분 | 가정값 | 상담지 수기 작성(서식 2-1·2-2), 견적서 USD·환율·유효기간(서식 1-2) — 서식 종류는 확인값 |
| AI 초안 후 처리 시간 | 10분 | 가정값 (**아직 안 잼**) | 데모에서 직접 재기 (자체 테스트 기록) |
| 코디 시급 | 15,000원 | 가정값 | 고용 통계·채용 공고 |

**계산 (가정값 기반):** 60 × (25 − 10)분 = 15시간 → × 15,000 = **병원 1곳 월 22.5만 원 절감** — **v4 프리미엄 회원비 월 ₩150,000을 빼면 병원에 월 약 7.5만 원이 남음** (기본 → 프리미엄으로 바꾸면 수수료도 13% → 8%로 내려가 진료비 월 300만 원 이상이면 이득) · (기록) v3 월 구독료 ₩69,000~99,000일 땐 12.6만~15.6만 원, v2 20만 원일 땐 2.5만 원. 처리 시간을 재기 전까지는 구독료 근거로 쓰지 않음
