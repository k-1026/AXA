# data/

팀 데이터 통합 폴더. 2026-10-29에 정리했어요. 기존 `data_대구병원목록/`과 공유 드라이브 다운로드를 합친 뒤 raw/interim/processed로 나눴어요.

## 구조

| 폴더 | 규칙 |
|---|---|
| `raw/` | 받은 그대로의 원본 (공공데이터, API JSON·캐시, 크롤링, PDF). **수정 금지** |
| `interim/` | 원본을 가공한 중간본, 수동 입력 시트 |
| `processed/` | 새로 만들 최종 데이터 |

## raw/

| 폴더 | 내용 |
|---|---|
| `영업정보/` | 심평원 API 원본 JSON 5개 (`meta` 포함), 진료시간 API 캐시 `.hours_cache.jsonl` |
| `비급여진료/` | 심평원 진료비 통계, 보훈병원·W병원 비급여, 공공데이터(비급여수가) xlsx, 강남언니·모두닥 가격 |
| `다국어/` | 외국인환자 유치실적 통계분석 보고서 PDF (2022~2025), 유치지역별 국적 CSV |
| `유입/` | 한류 소비액·소비건수 (비율·추이) 4개 |
| `비자데이터/` | 법무부 의료관광 우수 유치기관 공고문, C-3-3 체류 현황 |
| `유치기관/` | 수성구 유치 등록 의료기관, 연도별 지역별 유치의료기관, 메디컬코리아 사이트 목록 |
| `의료기관/` | 대구 의료관광 선도의료기관, 타 지역(서울·부산·대전) 의료관광 기관, 대구 남구·서구 뷰티·이미용업 |

### 여러 데이터를 합쳐 만든 파일 (2026-10-29 확인)

| 파일 | 합친 데이터 | 방식 |
|---|---|---|
| `raw/영업정보/daegu_hospital_hours.json` → `interim/영업정보/daegu_hospital_hours.csv` | 심평원 병원정보서비스(기본목록·진료과목 14 피부과, 08 성형외과) + 의료기관별상세정보서비스(`getDtlInfo2.8` 진료시간) | 요양기호(`ykiho`)로 결합 |
| `raw/영업정보/suseong_foreign_patient_facilities.json` → `interim/…csv` (45곳) | 수성구 유치 등록 기관 파일데이터 + 심평원 3종(기본·진료과·진료시간·비급여 여부) + 병원 홈페이지·지도 직접 확인 | 병원명·주소로 `ykiho` 매칭(39곳), 진료시간 직접 입력. 대표자명 제외, 2곳 삭제 |
| `interim/영업정보/manual_fill_junggu_suseonggu.csv` (263곳) | 심평원 기본목록·진료과목 + 메디컬코리아 등록 병원 여부 + 홈페이지 직접 확인 | 중구·수성구 피부과·성형외과 빈칸 작업표 |
| `interim/영업정보/suseong_manual_input.csv` | 수성구 등록 기관 + 네이버·카카오 지도·모두닥 확인 | 수동 입력 시트 |
| `interim/유입/01~08_*.csv` | 진흥원 외국인환자 유치실적 보고서 PDF 4개(2022~2025) | PDF 표를 뽑아 주제별로 합침 (`표번호`·`원문쪽` 열) |

- 단일 원본 변환만 한 파일: `daegu_hospitals.csv`, `daegu_nonpay_prices.csv`, `nonpay_item_codes.csv` (JSON → CSV), `interim/유치기관·의료기관/` (대표자 열 삭제)
- 메디컬코리아 원본 CSV는 저장소에 없음 → `manual_fill`의 `medicalkorea_registered` 열은 다시 만들 수 없음 (원본 다시 받기)
- 변환·결합 스크립트는 저장소에 없음 → `data/etl/`에 옮겨야 함

기준 = 심평원 대구 병원 목록 4,242곳 (`ykiho`)

| 파일 | 결합 | 결과·이유 |

| `비급여진료/한국보훈복지의료공단_…대구보훈병원` (1,695행) | 가능하나 **우선순위 낮음** | API는 240행, 공단 파일은 수가코드 단위로 더 상세. 같은 병원(`한국보훈복지의료공단 대구보훈병원`, 달서구 종합병원). 단 선도의료기관 목록에 없고, 홈페이지 첫 화면에 외국인·국제진료 안내 없음 → 의료관광 대상 병원으로 보기 어려움. 유치 등록 여부는 메디컬코리아 등록 목록으로 확인 필요 |
| `비급여진료/W병원_비급여진료비용_전체` (317행) | **보류** | API에 `W여성병원`(54행)·`더블유병원`(116행) 둘 다 있음 → 어느 병원인지, 어디서 받았는지 확인 필요 |
| `비급여진료/공공데이터(비급여수가)` xlsx | **보류** | 병원명 없음, 출처 미확인 |
| `비급여진료/강남언니_*`, `모두닥_*` | **X** | 크롤링·광고 가격 (규제 결론) |

| `유치기관/연도별 지역별 유치의료기관 현황` | X (통계) | 배경 자료 |
| `유치기관/메디컬코리아 유용한 사이트 목록` xlsx | X | 챗봇 참고 링크 후보 |
| `의료기관/대전·부산진구·서울` | X (다른 지역) | 비교·벤치마킹 자료 |
| `의료기관/남구 뷰티업종`, `서구 이미용업` | X (의료기관 아님) | 이용·미용업소 → 병원 목록과 섞지 않음 (관광 연계 확장 시 별도) |
| `비자데이터/법무부 C-3-3 체류 현황`, `다국어/유치지역별 국적` | X (통계) | 국적·언어 근거 자료 |

→ `processed/`에 만들 후보: **대구 병원 마스터** = 심평원 기본 + 진료시간(API·직접 채움) + 수성구 유치 등록 + 선도의료기관 + 가격 유무 (+ 메디컬코리아 등록 여부는 원본 다시 받은 뒤)
