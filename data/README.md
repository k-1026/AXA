# data/

팀 데이터 통합 폴더. 2026-10-29에 정리했어요. 기존 `data_대구병원목록/`과 공유 드라이브 다운로드를 합친 뒤 raw/interim/processed로 나눴어요.

## 구조

| 폴더 | 규칙 |
|---|---|
| `raw/` | 받은 그대로의 원본 (공공데이터, API JSON·캐시, 크롤링, PDF). **수정 금지** |
| `interim/` | 원본을 가공한 중간본, 수동 입력 시트 |
| `processed/` | 새로 만들 최종 데이터 |

## raw/

| 폴더 | 내용 |
|---|---|
| `영업정보/` | 심평원 API 원본 JSON 5개 (`meta` 포함), 진료시간 API 캐시 `.hours_cache.jsonl` |
| `비급여진료/` | 심평원 진료비 통계, 보훈병원·W병원 비급여, 공공데이터(비급여수가) xlsx, 강남언니·모두닥 가격 |
| `다국어/` | 외국인환자 유치실적 통계분석 보고서 PDF (2022~2025), 유치지역별 국적 CSV |
| `유입/` | 한류 소비액·소비건수 (비율·추이) 4개 |
| `비자데이터/` | 법무부 의료관광 우수 유치기관 공고문, C-3-3 체류 현황 |
| `유치기관/` | 수성구 유치 등록 의료기관, 연도별 지역별 유치의료기관, 메디컬코리아 사이트 목록 |
| `의료기관/` | 대구 의료관광 선도의료기관, 타 지역(서울·부산·대전) 의료관광 기관, 대구 남구·서구 뷰티·이미용업 |
