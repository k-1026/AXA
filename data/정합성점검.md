# 데이터 정합성 점검 (2026-10-30)

> 이전 점검: [중복점검.md](중복점검.md) (중복 파일·중복 행) · 결합 현황: [README.md](README.md)

## 결론

**심평원 데이터(병원·진료시간·가격)는 내부 정합성 확인 완료.** 외부 기준과 맞춰야 하는 데이터(메디컬코리아 등록 목록, 직접 채운 진료시간, 출처 미확인 파일)는 **아직 확인되지 않음**.

## 1. 확인된 것 ✅

| 항목 | 결과 |
|---|---|
| 원본 JSON ↔ 가공 CSV 행 수 | 5개 모두 일치 — 병원 4,242 · 진료시간 4,242 · 비급여 15,940 · 비급여 코드 943 · 수성구 45 |
| 병원 키(`ykiho`) 중복 | 병원 목록·진료시간 각 4,242개 모두 고유 |
| 키 연결 | 진료시간·가격 데이터의 `ykiho`가 모두 병원 목록에 있음 (고아 행 0) |
| 통계 CSV ↔ 원본 PDF | `유입/07`의 표 3.48(베트남)을 2025 보고서 PDF 84쪽과 대조 → 일치. 발표자료에 쓴 국적별 숫자·증가율·대만 지역 순위·성형외과 비중·상급종합 순위도 CSV로 재계산해 일치 |
| 통계 CSV ↔ 다른 원본 | 대구 실환자 2009~2022가 `유입/03` 표 2.13과 `다국어/…유치지역별 국적` CSV에서 같음 ([중복점검.md](중복점검.md)) |

## 2. 확인 안 된 것 / 불일치 ⚠️

| 항목 | 상황 | 할 일 |
|---|---|---|
| 메디컬코리아 등록 목록 | 대구 등록 병원 사이트 **161** vs CSV **145**, 유치업체 사이트 **53** vs CSV **54** (2026-10-30). 원본 CSV가 `data/`에 없음 | 원본 다시 받아 `raw/`에 저장, 사이트 숫자와 기준일 비교 |
| 비급여 금액 0·빈값 | 15,940행 중 **15행** | 통계 계산 시 제외 (현재 계산은 제외함) |
| 비급여 금액 단위·조건 | 같은 항목에 단위가 다른 값 섞임 (예: 도수치료 최저 4,000원) | 통계는 중앙값·사분위로, 이상값 기준 정하기 |
| 수성구 유치 등록 기관 | 45곳 중 `ykiho` 매칭 **39곳** (병원명·주소 매칭) | 미매칭 6곳 수동 확인 |
| 선도의료기관 매칭 | 42곳 중 자동 34곳(이름 매칭은 오매칭 검수 필요), 8곳 미매칭 | 수동 확인 |
| 직접 채운 진료시간 | 칸마다 출처·확인일은 있음. 재검증은 안 함. 카카오맵 시간과 심평원 시간이 10곳 넘게 다름 | 시연 대상 병원부터 재확인 |
| 휴진 표기 | "전부 휴무"·"전부휴진" 등 표기 제각각 | `휴진/진료/응급실만/미확인` 4개 값으로 통일 (팀원 1 할 일) |
| `유입/01~06, 08` 원본 | README는 "보고서 PDF 4개(2022~2025)"라고 적음. 07은 **2025 보고서 1개**에서만 나온 것 확인 | 나머지 파일의 원본 보고서 확인 후 README 수정 |
