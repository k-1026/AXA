# SEO × 병원 영업 — 검색으로 모은 숫자를 들고 병원을 만나기

## 한 줄 요약

**병원 페이지를 검색에 잘 나오게 만들면(SEO), 그 페이지를 외국인이 몇 번 봤는지가 숫자로 남아요. 그 숫자를 들고 병원에 가면 "한번 써 볼게요"라는 말을 듣기 훨씬 쉬워요.**

161곳을 다 찾아가는 대신, **검색이 먼저 일하고 → 반응이 있는 병원부터 만나는** 구조예요.

## 왜 둘을 묶나요?

| 따로 할 때 | 묶어서 할 때 |
|---|---|
| 병원에 가서 "외국인 환자가 늘 거예요"라고 **말로만** 설득 | "지난달 외국인이 구글에서 **원장님 병원 페이지를 n번** 봤어요"라고 **숫자로** 설득 |
| 161곳 중 어디부터 갈지 감으로 정함 | **페이지를 많이 본 병원부터** 연락 |
| 병원이 우리를 검색하면 아무것도 안 나옴 | 병원이 검색해도 **이미 자기 병원 페이지가 나옴** → 믿음이 생김 |
| 병원 정보가 공공데이터 그대로라 비어 있는 칸이 많음 | 병원이 정보를 직접 채우면 **페이지가 좋아져 검색에 더 잘 나옴** → 다시 숫자가 늘어남 |

## 돌아가는 순서 (한 바퀴)

```
① 병원 161곳 페이지를 검색에 잘 나오게 만든다 (SEO)
        ↓
② 외국인이 구글에서 찾아본다 → 병원별로 "몇 번 봤는지" 숫자가 쌓인다
        ↓
③ 숫자가 많은 병원부터 연락한다 ("이번 달 외국인이 n번 봤어요")
        ↓
④ 병원이 무료 계정으로 "우리 병원 정보 확인·보완"을 한다
        ↓
⑤ 정보가 채워진 페이지는 검색에 더 잘 나온다 → ②로 돌아가 숫자가 더 커진다
        ↓
⑥ 상담 요청이 실제로 들어오면 → 파일럿 → 3개월 무료 뒤 유료
```

**④ → ⑤ → ②가 계속 도는 게 핵심이에요.** 병원이 참여할수록 검색이 좋아지고, 검색이 좋아질수록 다음 병원을 설득하기 쉬워져요.

## 단계별로 하는 일

### ① 병원 페이지를 검색에 잘 나오게 (SEO 1·2단계)

| 할 일 | 쉽게 말하면 | 누가 |
|---|---|---|
| 병원 161곳 페이지를 언어별 주소로, 미리 완성된 페이지로 | 구글이 읽을 수 있는 책으로 만들기 ([SEO-쉽게-설명.md](SEO-쉽게-설명.md) 1단계) | 프론트 |
| 페이지마다 제목: "{병원 이름} — Hours, Location, Languages" | 책 제목 붙이기 | 프론트 |
| 페이지 아래에 **"이 병원 관계자이신가요? 정보 확인·수정하기"** 버튼 | 병원이 먼저 연락해 올 수 있는 문 | 프론트 |
| 병원 정보는 공공데이터 + 출처·기준일, 광고·순위·후기 없음 | 믿을 수 있는 페이지 | 프론트 · 마케팅 |

### ② 숫자 모으기

| 숫자 | 어디서 보나 | 쉽게 말하면 |
|---|---|---|
| 병원 페이지별 **노출 수**·**클릭 수** (나라별) | 구글 서치 콘솔 — 페이지마다 따로 볼 수 있음 | "외국인이 검색 결과에서 이 병원을 몇 번 봤고 몇 번 눌렀나" |
| 병원 페이지별 **"상담 요청" 버튼 누른 수** | 웹 분석 (버튼 클릭 기록) | "실제로 상담하고 싶어 한 사람이 몇 명인가" |
| 병원별 **상담 요청 건수** | 메디대구 백엔드 (요청 기록) | "실제로 요청서를 보낸 사람이 몇 명인가" |

이 숫자를 **병원별 한 줄 표**로 매달 정리해요 → 이게 영업 순서표가 돼요.

### ③ 숫자가 많은 병원부터 연락하기

| 병원 상태 | 어떻게 연락하나 |
|---|---|
| **상담 요청이 이미 들어온 병원** | 가장 먼저 — 전화·방문. "이번 달 외국인 n명이 원장님 병원에 상담을 요청했어요. 요청서를 받아 보시겠어요?" |
| **많이 봤지만 요청은 없는 병원** | 이메일·팩스로 한 장 리포트: "외국인이 n번 봤어요. 진료시간·외국어 상담 정보를 채우면 더 잘 보여요" + 무료 계정 초대 |
| **아직 거의 안 본 병원** | 이번 달은 연락 안 함 — 다음 달 숫자를 다시 봄 |

### ④ 병원이 정보를 채우게 하기 (무료)

- 병원은 무료 계정으로 **외국어 상담 가능 여부, 진료시간, 사진** 등을 확인·보완
- 이 단계에서는 돈을 받지 않아요 → 병원 쪽 부담이 거의 없음
- 대시보드에서 "이번 달 우리 병원 페이지를 본 외국인 수"를 바로 보여 주면 계속 들어오게 됨 `[추정]`

### ⑤·⑥ 페이지가 좋아지고 → 파일럿으로

- 정보가 채워진 페이지는 검색에 더 잘 나오고, 상담 요청도 늘어나요 `[추정 — 실제 효과는 측정해서 확인]`
- 상담 요청이 꾸준히 오는 병원에 **파일럿(3개월 무료) → 유료** 제안 ([B2B-병원-마케팅.md](B2B-병원-마케팅.md) 3-4)

## 언제 무엇을 (12/4 발표 기준)

| 시기 | 검색(SEO) 쪽 | 병원 영업 쪽 |
|---|---|---|
| **발표 전** | 계획·시연만 (웹 주소가 아직 없어서 실제 검색 숫자는 없음) | 1순위 20곳에 소개 자료 + 「대구 외국인 환자 한눈에」 리포트 → 답한 곳 인터뷰 3~5곳 ([B2B-병원-마케팅.md](B2B-병원-마케팅.md) 3-6 ①) |
| **배포 직후** | 병원 페이지 공개 · 서치 콘솔 등록 · "정보 확인하기" 버튼 | 인터뷰한 병원에 "페이지가 열렸어요, 정보 확인해 주세요" |
| **배포 1~2달 뒤** | 병원별 노출·클릭·상담 요청 숫자가 쌓임 | **숫자 많은 병원부터** 연락 (③) |
| **그 뒤 매달** | 숫자 갱신 | 순서표 갱신 → 파일럿 → 유료 |

- 구글이 페이지를 읽고 올리는 데 **보통 몇 주** 걸려요. 그래서 발표 전에는 검색 숫자 대신 우리가 가진 공공 통계로 리포트를 만들어요

## 지켜야 할 것

| 하지 않음 | 이유 |
|---|---|
| "돈을 내면 검색·목록에서 위로 올려 드려요" | 병원 목록 순서에 구독·제휴 반영 금지 (서비스 원칙). 우리 약속 "No rankings"와도 충돌 |
| "환자 n명을 보내 드릴게요" 약속 | 숫자를 보장할 수 없고, 환자 유인으로 보일 수 있음 → **이미 본·요청한 숫자만** 보여 주기 |
| 병원 페이지에 후기·전후 사진·할인가 | 의료법 제56조 |
| 개인정보가 들어간 숫자 공유 | 병원에는 **건수만** 보여 주고, 누가 봤는지는 보여 주지 않음 |

## 용어 풀이

| 용어 | 뜻 |
|---|---|
| 노출 수 | 검색 결과에 우리 페이지가 **보인** 횟수 |
| 클릭 수 | 검색 결과에서 우리 페이지를 **누른** 횟수 |
| 서치 콘솔 | 구글이 무료로 주는 "내 사이트 검색 성적표" — 페이지별·나라별로 볼 수 있음 |
| 파일럿 | 정식 계약 전에 병원이 **3개월 무료로 써 보는 것** |
