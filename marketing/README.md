# marketing — 유입 마케팅

메디대구(MediDaegu) 유입 마케팅 자료. 방향: **병원·시술 광고 없이 "대구에서 외국인이 피부과를 예약하는 법"을 알려 주는 정보 계정** (의료법 제56조, 팀 원칙). 타깃 **영어권·대만·중국·일본·베트남**, 진료과 **피부과·성형외과·안과·내과**, 채널 **인스타그램·유튜브 쇼츠·페이스북**(+대만 Dcard), 짧은 세로 영상만(긴 영상 없음). 계정 이름 MediDaegu.
