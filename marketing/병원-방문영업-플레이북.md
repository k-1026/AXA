## 1. 정직하게 소개하기 (가장 먼저 지킬 것)

메디대구는 **아직 등록 외국인환자 유치사업자가 아니고**, "등록 유치사업자라는 가정"으로 설계한 팀 프로젝트예요 (CLAUDE.md 전제). 그래서:

| 해야 함 | 하면 안 됨 |
|---|---|
| "AX 부트캠프에서 대구 외국인 환자 예약 서비스를 만드는 팀이에요. 출시 전이라 병원 의견을 듣고 있어요"라고 처음에 밝히기 | 이미 운영 중인 회사처럼 말하기 |
| "지금은 계약이 아니라 의견을 듣는 단계예요" | 계약서·수수료 약정에 서명받기, 환자를 보내 주겠다고 약속하기 |
| 인터뷰 내용을 어디에 쓰는지 말하고 동의받기 (녹음은 동의할 때만) | 동의 없이 녹음, 원장·직원 실명을 저장소에 올리기 (팀 규칙: 공개 저장소에 실명 X) |

| 기준 | 점수 | 이유 |

| 진료과: 피부과·성형외과 | 3 | 외국인 환자가 가장 많이 오는 과 (대구 성형 5,786명 · 피부 3,333명, 2025) [S1] |
| 진료과: 안과 | 2 | 대만 환자 질환 1위 '눈' `[추정]` [S2] |
| 진료과: 내과 | 1 | 거주 외국인 검진 위주 [S2] |
| 종별: 의원 | 2 | 원장이 바로 결정 → 빠름 |

## 4. 순서 — 전화 → 방문 → 후속

### 4-1. 전화 (방문 약속 잡기)

```
안녕하세요, 대구에서 외국인 환자 예약 서비스를 만들고 있는 메디대구 팀입니다.
AX 부트캠프 프로젝트로, 아직 출시 전이라 병원 의견을 듣고 있어요.
외국인 환자 상담을 맡고 계신 분(원장님 또는 상담 실장님)께 15분만 여쭤보고 싶은데,
이번 주에 잠깐 들러도 될까요? 대구 외국인 환자 통계 자료도 한 장 드리려고 해요.
```

- 진료 시간 중 바쁜 시간(오전 시작·점심 직후)을 피해 **오후 3~5시**에 전화 `[추정]`
- 거절하면: "자료만 메일이나 팩스로 보내 드려도 될까요?" → 기록 단계 "자료 발송"

### 4-2. 방문 동선

- 1차 20곳은 모두 **중구** → **하루 6~7곳 × 3일**, 2인 1조
- 약속 없이 들르는 건 원칙적으로 하지 않음. 약속이 잡힌 곳 사이에 같은 건물·근처 병원이 있으면 **자료만 두고 오기**
- 지도 순서는 목록 CSV의 주소로 정함 (같은 건물에 여러 병원이 있는 경우가 많음)

### 4-3. 방문 15분 흐름

| 시간 | 할 일 | 말 예시 |
|---|---|---|
| 0~1분 | 소개 (정직하게) | "출시 전 팀 프로젝트라 의견을 듣고 싶어 왔어요" |
| 1~8분 | **질문 7개** (5절) | 듣기 위주, 메모 |
| 8~11분 | 데모 3분 | "외국인이 이렇게 요청서를 보내면, 병원에서는 이 화면으로 받아요" |
| 11~13분 | 다음 약속 | "출시하면 무료로 먼저 써 보실 의향이 있으세요?" (서명 X, 의향만) |
| 13~15분 | 리포트 전달 · 감사 | 리포트 두고 오기 |

### 4-4. 후속 연락

| 언제 | 무엇을 |
|---|---|
| 당일 | 감사 문자·메일 (팀 공용 연락처로) + 오늘 들은 내용 한 줄 확인 |
| 1주 뒤 | 인터뷰에서 나온 요청을 반영했으면 알려 드리기 |
| 출시 때 | "무료 계정 열렸어요" 안내 → 파일럿 제안 |

## 5. 질문 7개 (인터뷰)

| # | 질문 | 확인하려는 것 |
|---|---|---|
| 1 | 외국인 환자 문의는 **한 달에 몇 건 정도**, **어떤 경로**(전화·카톡·LINE·인스타·유치업체)로 오나요? | 문의량 · 채널 |
| 2 | 어느 나라 환자가 많고, 주로 어떤 진료를 원하나요? | 우리 타깃(대만·일본·영어권 등)과 맞는지 |
| 3 | 외국어 문의는 **누가, 어떻게** 답하나요? 답하기 어려운 점은? | 응답 부담 · 놓치는 문의 |
| 4 | 문의했다가 **예약까지 안 오는 경우**가 있나요? 이유는? | VOC "연락했는데 답이 없다"의 병원 쪽 사정 |
| 5 | 진료 뒤 **사후관리**(귀국 뒤 질문 등)는 어떻게 하나요? | 사후관리 기능 수요 |
| 6 | 이런 서비스에 비용을 낸다면 **① 체결 건마다 수수료 ② 월 정액 ③ 둘 다** 중 무엇이 받아들이기 쉬운가요? | 가격 가정 검증 (수수료 10% + 구독료) [S7] |
| 7 | 데모를 보시고, **꼭 있어야 할 것 / 없어도 될 것**은? | 기능 우선순위 |

- 질문 6에서 구체적인 금액을 먼저 말하지 않기 → 병원 쪽 생각을 먼저 듣기

## 6. 자주 나올 반론과 답

| 병원 말 | 답 (정직하게) |
|---|---|
| "다른 데(트립닥 등)는 무료라던데요" | "맞아요, 무료인 곳도 있어요 [S8]. 저희는 첫 3개월 무료로 써 보시고, 실제 방문·완납한 건에만 비용을 받는 방식을 생각하고 있어요. 그래서 원장님 의견이 필요해요" |
| "외국인 환자 별로 없어요" | "그럼 어떤 경로로 오면 늘어날 것 같으세요?" (질문 1·2로 돌아가기) — 무리하게 설득하지 않기 |
| "유치업체랑 이미 일해요" | "그 업체와 어떻게 일하시는지 여쭤봐도 될까요?" → 경쟁이 아니라 **불편한 점**을 듣기 |
| "개인정보는요?" | "환자 건강 정보는 동의를 받은 것만 다루고, 병원은 자기 병원 요청만 볼 수 있게 설계하고 있어요" [S9] (구현 상태는 데모 수준이라고 함께 말하기) |
| "바빠요" | "자료만 두고 갈게요. 편하실 때 메일 한 번 주세요" → 단계 "자료 발송" |
| "계약하면 환자 몇 명 보내 줘요?" | "숫자는 약속드릴 수 없어요. 출시 뒤 실제 요청 건수를 그대로 보여 드릴게요" |
