# 대만 SNS 이용 현황 — 틱톡을 많이 쓰나?

> 작성 2026-11-19 · 왜: 유입 마케팅([유입마케팅-틱톡-인스타.md](유입마케팅-틱톡-인스타.md))의 1순위 대상이 대만이라 플랫폼 선택을 확인

## 결론

**대만에서 틱톡은 주력 플랫폼이 아니에요.** 최근 3개월 사용 25%, "가장 많이 쓰는 SNS"로 꼽은 사람은 4%예요. 대신 **짧은 영상 자체는 78%가 봐요** (틱톡·IG 릴스·FB 짧은 영상·유튜브 쇼츠 포함). → 영상은 만들되 **인스타 릴스를 주 채널**로, 같은 영상을 틱톡·유튜브 쇼츠에도 올리는 게 맞아요.

## 숫자 (2025 台灣網路報告, TWNIC)

조사: 2025-07-28 ~ 09-01, 표본 2,142명(만 12세 이상, 가중치 적용), 공식 등급

| 항목 | 값 | 기준 |
|---|---|---|
| SNS 사용률 | 76.86% | 전체 |
| **짧은 영상 시청 (최근 3개월)** | **78.46%** (매일 58.04%) | 전체 · 틱톡·릴스·FB 짧은 영상·쇼츠 포함 |
| **틱톡 사용 (최근 3개월)** | **25.16%** (2024 21.67%, 2023 22.21%) | 전체 |
| 틱톡 사용자 중 매일 사용 | 45.51% | 틱톡 사용자 538명 |
| 틱톡 연령별 사용률 | 18~29세 **37.98%** (최고) · 40대 28.54% · 50대 28.00% · 70세 이상 12.18% | 전체 |
| "가장 많이 쓰는 SNS" (단일 선택) | **Facebook 51.38% · Instagram 21.07%** · Threads 4.57% · 틱톡 4.19% | 인터넷 사용자 1,901명 |
| "가장 많이 쓰는 메신저" (단일 선택) | **LINE 90.26%** · Messenger 5.87% · WeChat 1.42% | 인터넷 사용자 |

- 교차 확인: 대만 국가통신방송위원회(NCC) 보고서는 "인구의 거의 절반이 틱톡 콘텐츠를 본 적 있다", 16~25세에서 가장 빠르게 늘었다고 함 (언론 보도, 원문 미확인). 틱톡 영상이 다른 플랫폼으로 퍼져 보는 경우까지 포함한 것으로 보여 TWNIC 25%와 기준이 달라요. **방향(틱톡은 늘고 있지만 아직 소수, 젊은 층 중심)은 같음**
- 정부 기관 기기에서는 틱톡 사용이 제한돼 있다는 보도가 있으나, 일반 이용자 제한은 아님 (이 노트에서는 원문 미확인)

## 메디대구 유입 마케팅에 주는 뜻

| 플랫폼 | 역할 (대만 기준으로 수정) | 이유 |
|---|---|---|
| **Instagram (릴스 + 캐러셀)** | **주 채널** — 발견과 저장 모두 | 가장 많이 쓰는 SNS 2위(21%), 피부·여행 정보 저장 문화 |
| Facebook | 보조 — 페이지 + 여행 커뮤니티 공유 | 1위(51%)지만 연령대가 높음 (연령 분포는 이 노트에서 미확인) |
| 틱톡 · 유튜브 쇼츠 | 같은 영상 재업로드 | 틱톡 25%, 18~29세 38% → 젊은 층 보조 채널 |
| Threads | 글 위주 Q&A 실험 | 3위로 급성장 (4.57%) |
| **LINE 공식 계정** | 상담 연결 채널 | 메신저 90% — 예약·상담 문의는 LINE으로 받는 게 자연스러움 (VOC의 "LINE 예약"과도 맞음) |

- 틱톡 썸네일·대본은 그대로 **인스타 릴스 표지·대본**으로 쓰면 돼요 (같은 9:16)
- ~~LINE 예약 안내~~ → **메디대구에 LINE 상담 연결 없음** (2026-11-19 팀 확인). 상담은 메디대구 웹의 상담 요청으로만

## Facebook·LINE을 빼면 무엇으로? (2026-11-19 팀 질문)

> **이후 변경 (2026-11-19)**: 팀이 페이스북을 다시 넣기로 함 → 대만은 인스타·Dcard 주, 페이스북·유튜브 쇼츠 보조 ([유입마케팅-국가별-진료과별.md](유입마케팅-국가별-진료과별.md)). 아래 표는 그 전 검토 기록이에요

Facebook은 1위(51%)지만 팀 판단으로 젊은 층 비중이 애매하고, LINE은 메신저라 유입 채널에서 제외. 남는 후보:

| 순위 | 플랫폼 | 쓰는 방법 | 근거 | 등급 |
|---|---|---|---|---|
| 1 | **Instagram** (릴스 + 캐러셀) | 주 채널. 릴스로 발견, 캐러셀로 저장 | "가장 많이 쓰는 SNS" 2위 21.07% (TWNIC) | 공식 |
| 2 | **Threads** | 짧은 글 Q&A ("대구 피부과 궁금한 것 물어보세요"), 인스타 계정 그대로 사용 | 3위로 급상승 4.57%, X·틱톡·PTT 추월 (TWNIC) | 공식 |
| 3 | **Dcard** (醫美板·韓國板·旅遊板) | 광고가 아닌 **정보 글**: 예약 절차, 가격 보는 법, 대구 일정. 커뮤니티 규칙(홍보 표시) 확인 필요 | 사용자 약 80%가 18~35세(Dcard 측 발표, 언론 보도) · 醫美板에 시술 후기·분쟁 글이 활발 | 언론 (원문 미확인) |
| 4 | **YouTube** (쇼츠 + 긴 영상) | 릴스 영상 재업로드 + "대구 2박 3일 피부과 예약부터 귀국까지" 긴 영상 1개 | 짧은 영상 시청 78.46% (쇼츠 포함, TWNIC). **YouTube 단독 사용률은 이 노트에서 미확인** (TWNIC의 14.67%는 '뉴스를 보는 곳' 기준이라 다른 숫자) | 공식 / 미확인 |
| 5 | 틱톡 | 같은 영상 재업로드만 | 최근 3개월 25.16%, 18~29세 37.98% | 공식 |

**쓰지 않음**
- **샤오훙수(小紅書)**: 대만 내정부가 2025-12-04 **1년 접속 차단** 발표 (사기 피해·보안 점검 불합격 이유). 차단 전 대만 사용자 300만 명 이상이라는 보도. → 지금 쓰면 안 됨
- PTT: 3위권 밖으로 밀림 (TWNIC 문장), 이용자층이 메디대구 대상(20~30대 피부 관심층)과 덜 맞음 (이용자층 숫자는 미확인)

**정리**: **인스타 릴스(주) + Threads(Q&A) + Dcard(정보 글)** 세 곳을 기본으로, 같은 영상을 유튜브 쇼츠·틱톡에 다시 올리는 구성. Dcard는 대만 젊은 층이 시술 정보를 찾는 곳이라 "광고 아닌 정보"라는 우리 방향과 가장 잘 맞지만, 홍보 글 규칙을 먼저 확인해야 해요.
