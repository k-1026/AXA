## 한 줄 요약

**지금 메디대구 웹은 구글이 내용을 제대로 읽지 못해요.** 세 가지만 고치면 외국인이 구글에서 "Daegu dermatology"를 검색할 때 우리 웹이 나올 수 있어요.

## SEO가 뭐예요?

**구글을 도서관 사서라고 생각해 보세요.** 누가 "대구 피부과 예약"이라고 물으면, 사서는 도서관에 있는 책(웹페이지)을 미리 읽어 두었다가 알맞은 책을 꺼내 줘요.

**SEO**는 사서가 **우리 책을 쉽게 찾고, 읽고, 꺼내 줄 수 있게** 책을 잘 만들어 두는 일이에요.

> GEO는 비슷한 일을 ChatGPT 같은 AI를 상대로 하는 거예요. AI도 결국 구글처럼 웹페이지를 읽고 답하기 때문에, **SEO를 먼저 하면 GEO에도 도움이 돼요.**

## 지금 문제 3가지

| 문제 | 도서관으로 비유하면 | 그래서 생기는 일 |
|---|---|---|
| ① **언어마다 주소가 따로 없음** | 한 권의 책이 손님 국적에 따라 글자가 바뀌는데, 도서관 목록에는 **한 언어로만** 올라가 있음 | 대만 사람이 중국어로 검색해도 우리 중국어 페이지가 안 나옴 |
| ② **페이지가 비어서 도착함** | 책을 펼치면 **빈 종이**고, 조립 설명서대로 직접 맞춰야 글자가 나타남. 바쁜 사서는 안 읽고 넘어가기도 함 | 구글이 내용을 늦게 읽거나 못 읽음. 카카오톡·SNS에 링크를 붙여도 미리보기가 안 나옴 |
| ③ **모든 페이지 제목이 똑같음** | 도서관의 모든 책 제목이 **"메디대구"** | 검색 결과에서 어느 병원·어느 페이지인지 구분이 안 됨 |

## 고치는 방법 3단계

### 1단계 — 구글이 읽을 수 있게 만들기 (가장 먼저)

| 할 일 | 쉽게 말하면 | 예시 |
|---|---|---|
| **언어별 주소 만들기** | 언어마다 **책을 따로** 꽂고, "이 책의 영어판·중국어판은 저기 있어요"라고 서로 알려 주기 | `medidaegu…/en/hospitals` (영어) · `/zh-tw/hospitals` (번체) · `/vi/hospitals` (베트남어) |
| **페이지를 미리 완성해 두기** | 빈 종이 + 설명서 대신, **글자가 다 인쇄된 책**으로 꽂아 두기 | 병원 161곳 페이지를 미리 완성된 상태로 저장 |
| **페이지마다 제목 붙이기** | 책마다 **제목과 한 줄 소개**를 따로 쓰기 | "Daegu Dermatology Clinics — Hours & Booking Guide" |
| **사이트맵 만들기** | 사서에게 **"우리 책 목록"**을 건네기 | 공개 페이지 전체 목록 파일 |
| **로그인 페이지는 숨기기** | 직원 전용 방에는 "출입 금지" 표시 | 마이페이지·예약 화면은 검색에 안 나오게 |

### 2단계 — 읽을 만한 내용 넣기

| 할 일 | 쉽게 말하면 |
|---|---|
| **병원 페이지 채우기** | 병원마다 주소·진료시간·진료과·외국어 상담 여부를 **출처와 함께** 적기 (광고·후기·순위는 안 씀) |
| **진료과 안내 글 4개** (영어 먼저) | "대구에서 피부과 예약하는 법"처럼 **외국인이 실제로 궁금해할 질문에 답하는 글** — 피부과·성형외과·안과·내과 |
| **"이건 병원 정보예요" 표시하기** | 구글이 알아보는 형식으로 "이 페이지는 병원이고, 주소는 여기, 진료시간은 이거예요"라고 꼬리표 붙이기 |
| 피할 말 | "대구 최고 병원", "가장 싼 곳" — 의료법상 쓰면 안 돼요 |

### 3단계 — 등록하고 결과 보기

| 할 일 | 쉽게 말하면 |
|---|---|
| **구글 서치 콘솔에 등록** | 구글에 "우리 도서관 생겼어요" 신고하고, 책 목록(사이트맵)을 제출 |
| **결과 보기** | 몇 개 페이지가 구글에 올라갔는지, 어느 나라 사람이 무슨 검색어로 몇 번 봤고 몇 번 눌렀는지 확인 |
| **상담까지 이어졌나** | 검색으로 들어와서 "상담 요청"까지 누른 사람이 몇 명인지 |

## 누가 · 언제

| 단계 | 누가 | 언제 |
|---|---|---|
| 1단계 | **프론트 개발** | 일본어 화면 작업(PR #52) 끝난 뒤 순서 맞춰서 |
| 2단계 | **마케팅**(글) + 프론트(페이지) | 1단계 뒤 |
| 3단계 | 배포 담당 | 웹 주소(도메인)가 정해진 뒤 — **아직 미정** |

- 백엔드는 할 일 없음 (병원 정보가 이미 파일로 있음)
- 결과는 바로 안 나와요. 구글이 페이지를 읽고 올리는 데 **보통 몇 주** 걸려요

## 용어 풀이

| 용어 | 뜻 |
|---|---|
| SEO | 검색엔진(구글 등)에서 우리 페이지가 잘 나오게 만드는 일 |
| GEO | AI(ChatGPT 등)의 답변에 우리 내용이 인용되게 만드는 일 |
| URL (주소) | 웹페이지 주소. 예: `…/en/hospitals` |
| hreflang | "이 페이지의 다른 언어판은 여기 있어요"라고 구글에 알려 주는 표시 |
| 미리 그리기 (SSG) | 페이지를 방문할 때 만들지 않고, **미리 완성해서 저장해 두는 것** |
| 사이트맵 | 우리 웹의 모든 페이지 목록 파일 |
| robots.txt | "이 페이지는 검색에 넣지 마세요"라고 알려 주는 파일 |
| 구조화 데이터 | 구글이 알아보는 꼬리표 (예: "이건 병원, 주소는 여기") |
| 서치 콘솔 | 구글이 무료로 주는 "내 사이트 검색 성적표" 도구 |
