아래 값은 제공된 시장규모 문서의 숫자·팀 가정이다. 이 문서에서 원천 통계 전체를 다시 검증한 것은 아니다.[1]

기존 연간 매출을 단순히 4등분하면 신규 병원 확보·유료 전환·해지를 반영할 수 없다. 연간 값은 대조용으로 유지하고 분기별 실제 활동 병원 수로 매출을 계산한다. 시장 점유율 방식과 병원 수 방식은 교차 확인용이며 두 결과를 합산하지 않는다.

## 3. 팀 단위 인건비 적용 원칙

팀 인건비는 월 총액 L원이라는 단일 변수로 둔다. 4명이라는 이유로 L에 4를 곱하지 않는다.

| 항목 | 계산·처리 |
|---|---|
| 월 팀 인건비 | L원: 팀 전체 활동에 책정한 금액 |
| 분기 팀 인건비 | L × 3개월 |
| 2년 팀 인건비 | L × 24개월. 기간별 금액 변경 시 분기별 합계 |
| 개인별 인건비 | 별도 4인 급여 모델은 작성하지 않음 |
| L의 확정 상태 | 금액 미정. 임의의 확정 급여를 넣지 않음 |
| 결과 표시 | “팀 전체 인건비 월 L원 가정”을 결과와 함께 기재 |
| 지원 인력 | 외주 통역·일회성 작업 등 실제 추가 지출은 별도 비용으로 반영 |

**월 고정비 271만 원과의 중복을 먼저 확인한다.**

- 271만 원에 팀 인건비가 포함됐다면 해당 금액을 분리해 교체한다.
- 인건비가 제외됐다면 비인건비 고정비 271만 원에 L을 추가한다.
- 내역을 모르는 상태에서 “271만 원 + 인건비”를 확정 총비용으로 제시하지 않는다.
- L을 줄이면 적자가 감소하는 것은 산술적 결과이며, 사업 자체의 수익성이 개선됐다는 근거와 구분한다.
- 본 분석은 초기 팀의 비용 책정 조건에 따른 손익이며, 4명 전원에게 시장 급여를 지급하는 사업의 수익성을 입증하지 않는다.

## 6. 계산 구조

### 매출

월별 정밀 자료가 없을 때 아래 분기 근사를 사용한다. 신규 가입 시점이 중요하면 월별로 내부 계산한 뒤 분기로 합산한다.

- 분기 기본 거래 수 = 분기 평균 활동 기본 병원 수 × 병원당 월 성사 건수 × 3
- 분기 프리미엄 거래 수 = 분기 평균 활동 프리미엄 병원 수 × 병원당 월 성사 건수 × 3
- 기본 수수료 매출 = 기본 과금 대상 거래액 × 13%
- 프리미엄 수수료 매출 = 프리미엄 과금 대상 거래액 × 8%
- 구독료 매출 = 프리미엄 유료 이용 병원·개월 수 × 150,000원
- 플랫폼 매출 = 두 수수료 매출 + 구독료 매출

병원 진료비 전액은 플랫폼 매출로 잡지 않는다. 거래가 없는 프리미엄 병원도 실제 유료 계약을 유지하면 구독료가 발생할 수 있다. 계약상 할인·환불·면제는 별도 반영한다.

### 비용과 손익

- 분기 직접 운영비 = 문의 수 × 문의당 AI·번역 등 비용 + 완료 거래 수 × 거래당 추가 지원비 + 병원 수에 따른 추가 서비스비
- 공헌이익 = 플랫폼 매출 - 직접 변동비
- 분기 운영손익 = 공헌이익 - 팀 인건비 - 기타 고정비 - 영업·마케팅비
- 분기 현금흐름 = 실제 현금 유입 - 실제 현금 지출
- 필요 초기자금 = 24개월 누적 현금흐름의 최대 부족액 + 별도 설정한 예비자금

초기 구축비는 현금흐름에 반영하고 운영손익에서의 처리는 비용·자산 구분에 따라 별도로 정의한다. 부가세는 매출·이익에 혼합하지 않고 자금 흐름에서 필요 시 구분한다. 본 문서의 운영손익은 시뮬레이션용 관리 지표이다.

### 요금제의 전환 기준

같은 거래액을 기준으로 하면 월 15만 원 ÷ (13% - 8%) = **월 거래액 300만 원**에서 두 요금제의 병원 부담이 같다.

평균 73만 원을 적용하면 300만 ÷ 73만 ≈ **4.11건**이다. 동일 금액의 정수 거래라면 월 5건부터 프리미엄이 더 저렴하다. 기존 가정 월 4건에서는 기본 379,600원, 프리미엄 383,600원으로 프리미엄이 4,000원 높다.

따라서 “월 3건이 넘으면 자동 전환”을 확정 행동으로 사용하지 않는다. 추가 기능 가치도 전환 이유가 될 수 있으므로 실제 유료 전환율을 별도 변수로 둔다. 요금안 자체는 바꾸지 않는다.

## 7. 시나리오·민감도 설계

| 구분 | 보수 | 기준 | 낙관 |
|---|---|---|---|
| 병원 확보 | 목표 지연·활동률 하락 | 기존 연간 목표와 맞춘 확보 경로 | 목표 조기 달성 |
| 거래량 | 낮은 유입·전환 | 기존 병원당 성사 가정 | 유입·전환 개선 |
| 비용 | 사람 개입·획득비 증가 | 출처 또는 명시된 가정 | 자동화로 직접비 감소 |
| 팀 인건비 | 동일한 팀 총액을 우선 적용 | 동일 | 동일 |
| 목표 | 감당 가능한 손실·자금 확인 | 운영 지속 가능 조건 | 확대 시 추가 비용 확인 |

시나리오별 구체 값은 근거표에 명시한다. 낙관 시나리오만 인건비를 낮춰 흑자를 만드는 방식은 사용하지 않는다.

민감도는 팀 인건비, 평균 거래액, 병원당 성사 건수, 환자 확보비, 문의당 비용, 유료 전환율을 하나씩 ±20% 바꿔 본다. 수수료율은 고정한 본 분석과 분리해 별도 참고 분석으로만 둔다. 거래량 50% 감소 스트레스도 추가한다. 상한이 있는 비율은 0~100% 범위를 지킨다.

LTV는 비교기업 매출에서 추정하지 않는다. 유지율을 모르면 24개월 내 누적 공헌이익과 CAC 회수기간을 우선 사용한다.

## 8. 비교기업 1: 케어랩스

### 확인한 자료

케어랩스 2025년 1분기 공식 공시의 외부고객 매출을 사용했다. 단위 천원을 원으로 환산했다.[3]

| 사업부문 | 2025년 1분기 매출 | 비중 |
|---|---:|---:|
| 플랫폼 | 약 98.48억 원 | 42.69% |
| 마케팅 | 약 89.64억 원 | 38.87% |
| 솔루션 | 약 42.53억 원 | 18.44% |
| 합계 | 약 230.65억 원 | 100% |

플랫폼에는 굿닥·바비톡 등, 솔루션에는 병원 CRM 등이 포함된다. 분기·부문 기준이며 굿닥 단독 또는 의료관광 매출이 아니다. 사용 자료는 최신 연간 실적이 아닌 사업구조를 확인할 수 있는 역사적 분기 공시다.

### 우리 모델에 대한 분석

| 해석 | 적용 |
|---|---|
| 병원 연결과 병원 운영 도구는 매출 성격이 다름 | 수수료와 구독료를 별도 행으로 관리 |
| 여러 서비스가 합쳐진 회사 실적 | 그룹 매출÷입점 병원 수를 우리 병원당 매출로 사용하지 않음 |
| 공개 매출만으로 서비스별 비용·CAC를 알 수 없음 | 우리 상담·영업 비용은 별도 가정·측정 |
| 장기 비교에는 동일 회계 범위가 필요 | 연간·분기 자료를 섞어 성장률 계산하지 않음 |

핵심 활용은 매출 규모 복제가 아니라 **수익원 분리 설계**이다. 이번 확인 범위에서 부문별 이익률이나 병원별 구독 단가를 확보했다고 주장하지 않는다.

| 정보·예약 서비스 매출 | 4억 9,970만 위안 | 우리 플랫폼 기능과 비교 가능한 사업 묶음 |
| 해당 서비스 매출원가 | 6,300만 위안 | 해당 사업의 직접 원가 |
| 매출총이익 | 4억 3,670만 위안 | 위 두 금액의 차이 |
| 매출총이익률 | 약 87.4% | 계산값. 영업이익률 아님 |
| 해당 매출 전년 대비 | -32.2% | 회사는 정보 서비스 구독 의료기관 감소를 원인으로 설명 |

회사는 직접 미용시술 등 다른 사업도 운영한다. 전사 마케팅·관리·연구개발 비용을 위 사업에 전부 귀속시키거나, 전사 방문자를 정보·예약 사업의 유료 고객으로 간주하지 않는다.

### 우리 모델에 대한 분석

| 해석 | 적용 |
|---|---|
| 직접 원가가 낮아도 영업비용이 추가됨 | 매출총이익과 최종 운영손익을 분리 |
| 구독 병원 감소가 매출에 영향을 줄 수 있음 | 신규 입점뿐 아니라 해지·활동률을 변수화 |
| 높은 매출총이익률은 초기 소규모 팀을 보장하지 않음 | 87.4%를 우리 가정에 복사하지 않음 |
| 중국 미용의료 시장의 사업구조가 다름 | 수수료율·CAC·전환율의 직접 대입을 피함 |

핵심 활용은 **유료 병원 유지와 영업비용 반영의 중요성**을 확인하는 것이다.

## 10. 두 기업을 활용하는 방법

| 항목 | 활용 가능 | 직접 활용하지 않을 것 |
|---|---|---|
| 매출 항목 | 중개·구독 등 수익 구분 | 매출 규모를 우리의 목표 매출로 대입 |
| 원가·비용 | 직접 원가와 영업비용의 구분 | 대기업·해외기업 이익률 복사 |
| 고객 기반 | 유료 병원 유지의 중요성 | 입점 수를 모두 유료·활동 병원으로 간주 |
| 판단 | 무엇을 측정해야 하는지 정함 | 공개되지 않은 CAC·전환율의 임의 생성 |

우리 숫자에서 아직 필요한 것은 팀 인건비 L, 월 고정비 내역, 분기별 확보 경로, 광고비·유입·전환, 문의·거래당 지원 비용, 초기 구축비와 정산 조건이다. 확보하지 못한 값은 ‘미확정’ 또는 범위를 둔 ‘가정’으로 남긴다.

## 11. 시뮬레이션 완성 시 판단할 항목

1. 기본·프리미엄에서 각각 남는 공헌이익.
2. 8분기 중 운영 흑자가 처음 발생하는 분기.
3. 24개월 누적 현금이 플러스로 전환하는지.
4. 최대 현금 부족액과 필요한 초기자금.
5. 팀이 처리 가능한 문의·업무량 안에서의 손익분기 거래 수.
6. 결과를 가장 크게 바꾸는 미확정 가정.

프리미엄 구독료와 비용 구조가 함께 있으므로 ‘고정비÷평균 수수료’만으로 정확한 손익분기를 계산하지 않는다. 요금제 구성과 직접비를 고정한 조건에서 거래 수를 변화시켜 찾는다.

## 12. 문서 활용과 후속 산출물

이번 파일에는 합의 범위, 8분기 설계, 산식, 인건비 처리와 비교기업 분석을 정리했다. 분기별 매출·이익 숫자는 미확정 입력값이 남아 있으므로 완료된 결과로 제시하지 않았다.

후속 계산표는 가정·자료·병원확보·8분기손익·현금흐름·시나리오·민감도·비교기업으로 구성할 수 있다. 기존 시장규모 문서와 시장 계산은 유지하며 수익성 검증을 별도 연결한다.
