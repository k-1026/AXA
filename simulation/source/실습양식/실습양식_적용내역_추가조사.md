# 메디대구 — 실습 양식 적용 및 추가 조사 안내

작성일: 2026-11-20

## 이번 파일의 범위

첨부한 `market_model_case_student.xlsx`의 학습 흐름을 의료관광 플랫폼에 맞게 새 엑셀로 구성했다. 원본 실습 파일은 수정하지 않았다. 기존에 확보한 케어랩스·So-Young의 2024·2025년 재무 데이터를 옮기고, 메디대구의 기존 요금안과 시장규모 문서를 계산식으로 연결했다.

이 파일은 **추정 수익 모델**이다. 비교기업 실적, 팀 확정 요금, 기존 문서의 추정치, 새 모델 가정을 구별했다. 비교기업의 비용률을 우리 회사의 비용률로 자동 적용하지 않았다. 새 원문 다운로드 묶음을 의미하지 않으며, 자료 시트에 재무 원문 URL을 기록했다.

## 유지한 조건과 새로 둔 가정

| 항목 | 반영 내용 | 상태 |
|---|---|---|
| 기본 요금 | 진료 거래금액의 13% | 팀 확정 요금 |
| 프리미엄 요금 | 월 150,000원 + 거래금액의 8% | 팀 확정 요금 |
| 분석 기간 | 운영 개시 후 24개월, Q1~Q8 | 사용자 지정 |
| 인건비 | 팀 전체 월 총액 한 개 × 3개월 | 금액 미정, 4명 배수 없음 |
| 평균 과금 대상 금액 | 기준 730,000원 | 기존 환자당 지출 추정치를 거래당 금액으로 잠정 사용 |
| 병원당 월 완료 거래 | 기본 0.5건, 프리미엄 4건 | 기존 팀 가정 |
| 초기 병원 | 기본·프리미엄 모두 0곳 | 이번에 둔 가정 |
| Q1~Q8 전체 병원 | 6 / 12 / 18 / 25 / 30 / 35 / 40 / 46곳 | 새 확보 경로 |
| Q1~Q8 프리미엄 병원 | 0 / 0 / 1 / 2 / 3 / 4 / 5 / 6곳 | 새 확보 경로 |
| 연간 목표 해석 | 25곳·46곳을 각 연도 말 병원 수로 해석 | 팀 검토 필요 |
| 분기 평균 병원 수 | (분기 초 + 분기 말) ÷ 2 | 분기 내 균등 확보 가정 |
| 활동·이탈 | 확보한 병원 전부 활동, 별도 이탈률 없음 | 활동 병원 수 경로로 직접 수정 가능 |
| 보수·낙관 | 거래 빈도와 거래 금액을 각각 기준 대비 ±20% | 검증용 새 범위, 실측 신뢰구간 아님 |
| 부가세 | 요금·매출은 부가세 제외로 가정 | 계약상 포함 여부 확인 필요 |

보수·낙관에서 거래량과 거래금액을 동시에 바꾸므로 수수료 매출의 변화는 단순 ±20%와 다르다. 별도의 민감도 시트는 한 변수씩 바꿔 영향을 확인한다.

## 계산 방법과 현재 결과

- 완료 거래 = 분기 평균 활동 병원 × 병원당 월 완료 거래 × 3개월
- 거래금액 = 완료 거래 × 건당 과금 대상 진료비
- 수수료 매출 = 기본 거래금액 × 13% + 프리미엄 거래금액 × 8%
- 구독 매출 = 평균 프리미엄 병원 × 150,000원 × 3개월
- 건당 직접비 = 문의당 AI·번역비 × 완료 거래당 전체 문의 + 추가 지원비 + 결제·정산비
- 운영손익 = 수수료·구독 매출 − 직접비 − 팀 총인건비 − 기타 고정비 − 환자 마케팅비 − 병원 영업비

현재 입력한 **새 병원 확보 경로**에서 기준 매출은 다음과 같다. 이 금액은 기업의 실적이나 검증된 매출 예측이 아니다.

| 기준 경로 | 1년차 | 2년차 |
|---|---:|---:|
| 연말 전체 병원 | 25곳 | 46곳 |
| 연간 완료 거래 기대값 | 93.75건 | 378.75건 |
| 플랫폼 매출 | 8,920,875원 | 36,135,375원 |
| 운영손익 | 비용 미입력 | 비용 미입력 |

거래 수 소수는 기대값이다. 기존 연간 계산에 연말 병원 수를 연초부터 일 년 내내 적용한 경우와는 결과가 다르다. 분기 중 순차 확보를 반영한 결과를 기존 SOM 수치와 동일하다고 보면 안 된다. 시장 환자 수와 모델의 완료 거래 수도 단위가 달라, 거래÷SAM 환자는 확정 시장점유율이 아니다.

운영손익은 세금·금융비용·감가상각 등을 완전하게 반영한 회계 순이익이 아니다. 현금 부족액, 투자 회수 시점은 초기 지출·보유현금·수금 조건을 확보한 뒤 별도 현금흐름표가 필요하다. 관련 입력란은 후속 분석용이며 현재 자동 산출하지 않는다.

**271만 원은 내역이 확인되기 전 새 비용 항목에 더하지 않았다.** 인건비·광고비 등을 두 번 차감할 위험이 있기 때문이다. 비용이 실제로 발생하지 않는다는 근거가 있으면 0을 입력할 수 있지만, 모르는 값은 빈칸으로 남긴다. 미입력 값은 손익·손익분기·민감도에도 미입력으로 전파된다.

CAC는 기업의 광고비율로 대신할 수 없다. 자체 광고 실험에서 신규 완료 고객 수와 지출을 함께 확보해야 한다. 반복 거래·해지 자료가 없어 LTV도 이번 파일에서 확정 계산하지 않았다.

## 사용 순서와 검증

1. 가정 시트의 노란 칸에서 기준 시나리오 D열의 비용을 먼저 채운다. 보수·낙관도 각각 입력해야 해당 시나리오의 손익이 계산된다.
2. 병원 확보 경로와 환자당 금액의 거래당 금액 적용을 검토한다.
3. 손익에서 8분기·연간 합계, 단위경제에서 건별·구독별 공헌을 확인한다.
4. 계단표와 민감도에서 기준 Q8의 거래량·비용 변화 영향을 확인한다. 계단표는 병원 수·구독료·고정비가 고정되며, 처리 능력 확대에 따른 추가 고정비는 반영하지 않는다.
5. 실제 수집한 문의·거래·계약 데이터로 가정을 교체하고 매 분기 갱신한다.

파일 생성 시 수식 오류를 검사했고, 비용 공란이 손익에서 미입력으로 유지되는지 확인했다. 임시 비용을 입력한 검사에서는 팀 월 인건비를 10만 원 올릴 때 분기 운영손익이 30만 원 감소했다. 검사 뒤 임시 비용은 제거했다.
