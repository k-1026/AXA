## B. 내 제안 — 검토 받을 것 ❓

### B-1. 광고 범위 (Step 1) — 제안: 광고 상품 두지 않음 → **팀 결정으로 대체: 광고 배너 둠 (E-1)**

| 선택지 | 장점 | 문제 |
|---|---|---|
| CPC 광고 (강남언니형) | 매출이 큼 (강남언니 매출 78.8%) | ① 유치업자가 광고비까지 받으면 **유치 대가로 합쳐 수수료 상한을 넘을 수 있음** [U] (C2와 같은 쟁점) ② 유료 노출 = 사실상 **순위** → 11/12 "순위 제외" 결정과 충돌 |
| **광고 없음, 건당 수수료만 (추천)** | 수익 구조가 하나라 상한 계산이 간단, "광고 없는 공공데이터 플랫폼"이 차별점이 됨 (O1) | 초기 매출 작음 |

- 특구 옥외 광고 특례는 **병원 옥외 광고**용이라 우리에게 직접 해당 없음. 대신 특구 안 병원 간판·안내물에 **메디대구 QR을 넣는 제휴**를 초기 유입 경로 후보로 둠 [I]

### B-2. 과금 기준 + 실적 확인·정산 (Step 4) ← 핵심

**문제:** 수수료는 진료비 기준(상한 30·20·15%)인데, 진료 여부와 결제 금액은 병원만 앎.

**방식 비교**

| # | 방식 | 어떻게 | 장점 | 문제 |
|---|---|---|---|---|
| ① | 병원 자진 입력 | 병원이 대시보드에 "방문 완료 + 진료비" 입력 → 월 정산 | 기존 유치업 관행 그대로 (서식집: 매월 정산, 완납 건만) | 병원이 덜 입력해도 알 수 없음 |
| ② | 환자 영수증 인증 | 환자가 마이페이지에 영수증 사진 업로드 → 금액·날짜·병원 확인 | 병원 입력을 **교차 확인**할 수 있음, 사후관리 연결에도 씀 (B-4) | 환자가 귀찮아함. 보상(포인트 등)을 주면 **의료법 제27조 제3항 금품 유인** 위험 [U]. 영수증의 진료 항목 = 건강정보 |
| ③ | 플랫폼 결제 (트립닥형) | 예약금·진료비를 메디대구에서 결제 | 금액을 **확실히** 앎 | PG·환불·진료비 수납 대행 부담, 법적 검토 필요 [U]. MVP 범위 초과 |
| ④ | 정액 건당 | 방문 완료 1건당 고정 금액 | 진료비를 몰라도 됨 | 상한이 **진료비 비율**이라, 진료비가 작은 건은 정액이 상한을 넘을 수 있음 → 결국 진료비 확인 필요 |

**추천안 (MVP): ① + ② 교차 확인, 정률 수수료**

```
예약 확정 → 방문일
  → [병원] 대시보드에 "방문 완료 + 진료비(완납)" 입력   ← 방문일 +7일까지, 없으면 알림
  → [환자] 마이페이지 "방문 확인" 요청: 금액이 맞는지 1번 누르기 (+ 영수증 업로드는 선택)
  → 일치 → 정산 대상 / 불일치·환자 무응답 → 병원 입력값으로 처리하되 "미확인" 표시
  → [메디대구] 매월 정산 내역서 자동 생성 (서식집 정산서 양식) → 병원 확인 → 익월 청구
```

- **과금 시점:** 진료비 **완납 확인 뒤** (예약 확정 시점에는 과금하지 않음 = 노쇼·취소 분쟁 없음)
- **요율:** 정률, 상한보다 낮게. 구체 숫자는 미정 (팀이 정해야 함)
- **미입력 방지:** ① 확정 예약인데 방문 완료 입력이 없으면 7일 뒤 병원·환자 양쪽에 확인 ② 입점 계약에 "정산 자료 열람 요청권" 조항 ③ 환자 확인과 다른 건이 반복되면 입점 재검토
- **환자 보상은 주지 않음** (금품 유인 위험) — 대신 "확인하면 사후관리 채팅이 열린다"처럼 **서비스 연결**로 동기 부여 [I]

### B-3. 사후관리 건당 비용 (Step 0)

- "건" 정의 제안: **환자 1명의 방문 1회에 대한 사후관리 기간** (예: 방문 후 일정 기간 채팅). 기간은 미정
- 2027-05 무렵부터 **외국인 환자 비대면 진료가 법으로 가능**해짐 (의료해외진출법 개정, 언론 2곳) → 그 전까지 사후관리 채팅은 **진료가 아닌 안내·상담**만. 그 뒤에는 사후관리가 진료비가 생기는 단계로 바뀔 수 있음 (로드맵)

### B-4. 영수증 인증 → 사후관리 연결 (Step 5)

```
방문 완료 → 환자가 영수증 촬영 → AI(OCR)가 날짜·병원·금액·항목 읽기 → 환자가 확인
  → 받은 시술·진료 등록 → 그 병원 사후관리 채팅방 자동 개설 (지원 병원만)
  → 병원이 올린 시술별 안내문을 채팅방에 고정
```
- 영수증 원본 이미지는 **확인 후 삭제**, 금액·날짜·항목만 보관 (건강정보 별도 동의 필요)
- 병원 입력(B-2 ①)과 같은 데이터를 쓰므로 정산 교차 확인과 한 흐름으로 만듦

### E-1. 광고 배너 — 비의료 일반 광고주 (11/12 정정)

광고 배너는 **한국 화장품·관광 등 일반 상품** 광고이고 **병원 광고가 아님** → 의료광고 규제(국내광고 금지·심의·비교 금지)와 유치 수수료 상한 합산 문제는 **해당 없음**. 돈은 일반 광고주 → 메디대구.

| # | 주의 | 설계 |
|---|---|---|
| 1 | **건강정보로 타깃팅하지 않기** — 관심 시술·진료과는 민감정보 | 배너는 언어·국가 정도로만 고름 |

| 3 | 의료 효과를 말하는 광고 거르기 — 화장품도 의약품처럼 오인되게 표시하면 안 됨 (화장품법) [U] | 게시 전 검수 |

### E-2. 과금: ④ 정액 vs "월 합계 × 지정 %" vs 확인 흐름 — 어느 게 나은가 → **요금제 B의 정산 방식** (E-3)

**먼저 정리:** 말한 "월 토탈 × 지정 %"는 ④ 정액이 아니라 **정률**이에요. 그리고 이 둘은 하나를 고르는 관계가 아니라:
- **"월 합계 × 지정 %" = 얼마 받을지 (공식)**
- **확인 흐름(병원 입력 → 환자 확인 → 월 정산서) = 그 "월 합계"를 어떻게 알지 (방법)**

→ **둘 다 쓰는 게 답.** 공식만 있으면 "월 합계"를 병원 말로만 알게 되고, 흐름만 있으면 얼마 받을지가 없음.

**상한 문제 — 있나?**

| 경우 | 상한 문제 |
|---|---|
| 지정 % ≤ 그 병원 종별 상한 (의원 30%·병원 20%·상급종합 15%) | **없음.** 합계 × % 는 환자 한 명씩 × % 를 더한 것과 같아서, 환자 한 명 기준으로도 상한 안 |
| 진짜 정액 (방문 1건 × 고정 금액) | **있음.** 진료비가 작은 환자는 그 건만 상한을 넘을 수 있음. 월 합계로 맞춰도 고시가 **환자별로** 보는지 **월 합계로** 보는지 [U] |

**그래도 남는 주의 3가지**
1. **월 합계에 들어가는 것:** 메디대구 상담 예약으로 온 환자 + **완납 건만** (서식집 관행). 통역·숙박 같은 비의료서비스는 진료비에서 뺌 (고시 제2조)
2. **월 입점료와 합치면** 상한을 넘을 수 있음 [U] → C2 (배너는 병원이 내지 않으므로 해당 없음)
3. **"월 합계"를 결국 병원이 알려줌** → 확인 흐름이 필요한 이유

**추천 (최종)**
```
[병원] 방문 완료 + 건별 진료비 입력 (방문일 +7일, 없으면 알림)
  → [환자] 마이페이지 금액 확인 1번 (선택: 영수증 → 사후관리 채팅 열림)
  → [메디대구] 월말: 완납 건 진료비 합계 × 지정 % → 정산 내역서 자동 생성 → 병원 확인 → 익월 청구
```
- 지정 %는 **병원 종별 상한보다 낮게** (숫자는 팀이 결정)
- 환자 확인이 없거나 금액이 달라도 정산은 하고 "미확인" 표시만 → 반복되면 입점 재검토

### E-3. 요금제 2개 선택형 (11/12 결정) — 주의할 점

| | **A 월 구독료** | **B 건당 중개수수료** |
|---|---|---|
| 계산 | 매월 정액 | 병원 결제내역 → 그 달 경유 진료비 합계 × 지정 % (E-2 흐름) |
| 맞는 병원 [I] | 외국인 환자가 꾸준히 많은 병원 (비용 예측 쉬움) | 처음 들어오는 병원·환자가 적은 의원 (온 만큼만 냄) |
| 메디대구 입장 | 매출 안정 | 결제내역 확인 부담, 매출 들쭉날쭉 |
| 상한 위험 | ⚠️ **있음 [U]** — 환자가 적게 온 달엔 구독료 ÷ 경유 진료비가 상한(30·20·15%)을 넘을 수 있음 | 지정 % ≤ 상한이면 없음 |

**주의 [I]**
1. **A의 상한 문제 (C2·T1)** — 출시 전에 복지부·진흥원 질의. 답이 오기 전까지 안전장치: **그 달 구독료가 "경유 진료비 합계 × 상한"보다 크면 차액을 돌려주거나 다음 달에서 뺌.** 이 계산 때문에 **A 병원도 방문 완료·진료비 합계는 입력해야 함** (건별 영수증까지는 불필요)
2. **두 요금제 병원을 똑같이 노출** — A 병원에 환자를 더 보내거나 위로 올리면 순위가 생김 → 병원 목록·챗봇 추천은 요금제와 무관하게
3. **B 결제내역은 최소한으로** — 예약번호·방문일·진료비(완납 여부)만. 진료 항목·진단명은 받지 않음 (건강정보 최소화)
4. **유치 실적 기록은 두 요금제 공통** — 등록 유치업자는 유치 실적을 관리·보고해야 함 (조문 번호 [U]) → 어느 요금제든 방문 완료 기록은 남김
