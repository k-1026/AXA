## 단계별 설명

### STEP 0 · 분석 대상 정의
- **왜:** 분석할 "서비스"의 경계가 흐리면 나중에 "이건 우리 기능이냐 아니냐"가 계속 흔들림
- **하는 일**
  1. 서비스 한 줄 정의 (예: 외국인 환자용 다국어 대구 병원 정보 + 병원용 예약 요청 도구)
  2. 기능 목록: 정보 웹(지도·진료시간·가격 가이드), 챗봇, 예약 요청서, 병원 대시보드(AI 답장 초안) …
  3. 타겟: 이용자(무료) / 구매자(돈 내는 쪽) 구분 — 팀 노트 `research/11.09/고객층-고객여정지도.md` 활용
  4. 진행 현황: 완료 / 진행 중 / 예정
- **결과물:** 1장짜리 정의 표

### STEP 1 · 산업 구조 분석 ← "우리가 어떤 산업인지"는 여기서 정함
- **하는 일**
  1. **산업 이름 정하기:** 의료 서비스·관광·헬스케어 플랫폼(정보·예약 중개) 중 어디에 걸치는지 → 한 줄로
  2. **네 질문 표:** 무엇을 팔고 · 어떻게 돈을 벌고 · 누가 움직이고 · 지역(대구)과 어디서 만나나
  3. **산업 간 연결:** 어느 산업이 수요를 만들고, 어디에 상품이 얹히고, 무엇이 실어 나르는지
  4. **구조적 특징 5개 [I]:** 각 특징이 병목·비용·기회 중 무엇이 되는지 표시
  5. **기업 원페이지:** 산업의 대표 플레이어(강남언니·모두닥·트립닥·메디컬코리아·유치사업자 등)를 **사업 모델 6질문**(누구에게·무엇을·어떻게 전달·어떻게 돈·무엇으로·얼마나 들어)으로 1장씩. 칸마다 사실 한 줄 + 출처, 없으면 "미기재"
- **결과물:** 산업 구조 노트 + 기업 원페이지 여러 장

### STEP 2 · 밸류체인 작성 절차 (만드는 방법)
1. 활동 동사 추출: 우리 기능에서 동사 뽑기 (찾다·비교하다·문의하다·확정하다·답하다 …)
2. 단계 5개 내외로 합치기: **돈이 바뀌지 않는 단계는 합침**
3. 이해관계자 배치: 하는 사람(굵게) · (영향 주는 사람) / 돈 더 떼는 쪽이 먼저
4. 돈·데이터 흐름: 돈은 **소비자 → 원천 역방향**(금액은 원문 확인분만), 데이터는 생성 지점·보유자·피드백
5. 마커: 병목 2 · 비용 2 · 기회 3, 단계당 최대 2개 → 영향 × 실현 가능성으로 **우선 기회 1개**
6. AI 초안 → 사람 검증: 일반론 단계, 이름 없는 상자, 숫자 환각, 지역 맥락 빠짐, 마커 남발 점검

### STEP 3 · 산업 수준 밸류체인
- 의료관광 산업 전체를 7단계 내외로 (예: 수요·동기 → 정보·비교 → 상담·유치 → 비자·이동 → 진료·체류 → 결제·정산 → 사후)
- 행: 주요 플레이어 / 돈 ⇐ / 데이터 ⇢ / 우리 기능 매핑
- 위에 지원활동 2줄: 공공·정책, 인프라·데이터

### STEP 4 · 우리 서비스 네 층 맵 v1
- STEP 3에서 우리 서비스가 닿는 구간만 잘라 5단계
- 네 층: ① 활동 ② 이해관계자 ③ 돈 ④ 데이터 + 마커
- Mermaid: `-->` 상품·활동 · `==>` 돈 · `-.->` 데이터 · `classDef` bottleneck / cost / opp

### STEP 5 · 기능 매핑 + 시사점
- 기능 → 단계 매핑 표, "산업 7단계 기준 핵심/부분/입력/미포함"
- 비어 있는 단계가 말해주는 것 (예: 결제가 없으면 돈의 시작점이 서비스 밖 → BM 쟁점)
- 쟁점 5개, 우선순위 매트릭스 → 다음 일정(페인포인트 · AX 기회 · BM · spec)으로 넘김
