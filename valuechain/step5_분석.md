## 5-1. 메디대구 기능 6개는 체인 어디에 있나

| 기능 (STEP 0) | 체인 단계 (STEP 4) | 산업 단계 (STEP 3) | 역할 (Day10 용어) |
|---|---|---|---|
| **AI 챗봇** (오케스트레이터·탐색·추천·가격·절차 안내) | 2 탐색·비교 ← 1 데이터를 입력으로 | 2 정보·비교 | 주활동의 **유통·판매** — 환자를 병원 1곳으로 좁혀 줌. 1단계 공공데이터(O1★)가 답의 근거 |

| **사후관리** (채팅 + AI 요약·키워드) | 5 사후관리·정산 | 7 사후·환류 | 주활동의 **서비스(A/S)** — 귀국 후 단절(STEP 1 특징 4)을 메움 |
| **마이페이지** | 3 · 5 | 3 · 7 | 환자 쪽 **상태 확인** — 예약 진행·사후 대화 |
| **회원가입 구분** | 1 입점 (병원) · 2 (환자) | 지원활동 (인프라) | 권한 분리 — 등록 유치의료기관만 입점, 국내 거주자는 정보 열람만 |

## 5-3. 비어 있는 단계가 말해주는 것 [I]

- **5 진료·체류가 없다 = 돈의 시작점(진료비)을 메디대구가 보지 못한다.**
  - 건당 중개수수료는 진료비가 기준인데(상한 30·20·15%), 실제 진료비·완납 여부는 **병원만 안다** → 정산은 **병원이 알려준 값**에 기댐
  - 기존 유치업도 같은 구조: 매월 병원 ↔ 유치사업자 정산, 완납 건만 수수료 (서식집)
  - → 대시보드·마이페이지에 **"방문 완료" 표시를 병원이 입력**하게 하고, 그 건수를 정산 기준으로 삼는 설계가 필요 → 구체안은 [검토요청_2026-11-12.md](검토요청_2026-11-12.md) B-2
- **4 비자·이동이 없다** = 팀 결정(11/12)으로 공개 정보 안내·연결만. 예약 확정 뒤 서류는 병원·환자 몫
- **1 수요·동기가 없다** = 환자를 데려오는 마케팅 채널(SNS·현지 에이전시)은 서비스 밖 → 초기 유입 경로는 별도 과제 [U]

## 5-8. 기능 보완 (11/12 팀 검토 반영, 과금·정산 방식은 별도 검토 중)

### ① 이용 인증 → 사후관리 연결
```
방문 완료 → 환자가 영수증 촬영 → AI(OCR)가 날짜·병원·금액·항목 읽기 → 환자가 확인
  → 받은 시술·진료 등록 → 그 병원 사후관리 채팅방 자동 개설 (사후관리 지원 병원만)
  → 병원이 올린 시술별 안내문을 채팅방에 고정
```
- 영수증 원본 이미지는 확인 후 삭제, 날짜·병원·금액·항목만 보관 (건강정보 별도 동의)
- 환자에게 포인트 등 보상은 주지 않음 (의료법 제27조 제3항 금품 유인 위험 [U]) → "인증하면 사후관리가 열린다"로 동기 부여

### ② 사후관리 범위
- "건" = 환자 1명의 방문 1회에 대한 사후관리 기간 (기간 미정), 비용은 병원
- **2027-05 무렵 전까지** 채팅은 진료가 아닌 **안내·상담**만 (복약·주의사항 확인, 재방문 예약, 불편 접수). 외국인 환자 비대면 진료 법제화(2026-05 공포, 1년 뒤 시행 보도) 뒤에는 진료가 붙는 사후관리로 확장 가능 [U]

### ③ 가격 위치 표시 (가격 비교 수정안, 11/12 확정)
- 병원 이름·순위 없이, **심평원 공개 비급여 가격 범위(대구 최저~최고·중간값) 안에서 내 금액이 어디쯤인지만** 본인에게 표시
- "○○보다 싸다" 같은 병원 간 비교 표현 금지 (의료법 제56조 제2항 제4호 유형)
- 인증 금액은 표본이 충분할 때만 범위 집계에 반영
- 한계: 심평원 비급여 API에 의원급 미용 시술 코드가 없음 → 피부·성형 기준 가격은 직접 수집 필요 (subject.md)

### ④ 대시보드 지표 (무료 제공, 병원이 계속 쓰게 할 가치)

| 지표 | 병원의 의사결정 |
|---|---|
| 메디대구 경유 매출 ÷ 낸 수수료 (ROI) | 수수료만큼 벌었나 |
| 국가·언어별 문의 추이 | 통역·외국어 안내문 준비 |
| 관심 진료과·시술 (챗봇 질문) | 외국인용으로 안내할 시술 |
| 문의 → 확정 전환율, 평균 응답 시간 (대구 평균과 비교, 병원 5곳 이상일 때만, 이름 없이) | B2 병목 직접 확인 |
| 놓친 문의 (진료시간 외·미응답) | 응답 체계 개선 |
| 사후관리 키워드 (불편 유형) | 안내·응대 개선 |
| 내 병원 정보 완성도 (진료시간·가격 빈칸) | B1 빈칸을 병원이 채움 → O1 강화 |
