## 3장 시장 — "충분히 큰가?"  △ 일부

**있는 것**: 대안 5개 포지셔닝 맵과 DART 강남언니 숫자(영업수익 752억, 성과형 광고 78.8%). "누가 이미 하나"에는 잘 답하고 있어요.

**빠진 것**: **"우리가 얻을 몫(SOM)"**이에요. 기준표의 근거 산출물에 "SOM"이 명시되어 있는데, 덱에 시장 규모 숫자가 하나도 없어요.

**SOM 계산 틀** (✔ = 덱에 있는 값, ? = 확인 필요)

| 층 | 정의 | 값 |
|---|---|---|
| TAM | 전국 외국인환자 (진흥원 2025) | ? 진흥원 통계에서 확인 |
| SAM | 대구 대만 환자 | ✔ 1,495명 (2025) |
| SAM' | 그중 피부과 | ✔ 80.3%는 *전국* 대만 기준 → 대구값 ? |
| SOM | 첫해 메디대구로 방문 완료 | 점유 목표 ?% |

**예시 계산** (점유 10%로 가정했을 때)
- 1,495명 × 80.3% × 10% ≈ **연 120건** → 수수료 120 × ₩153,000 ≈ **₩1,836만**
- 구독료: 입점 10곳 × ₩69,000 × 9개월(3개월 무료) ≈ ₩621만
- 합계 연 약 ₩2,460만
- **손익분기 연 168건(월 14건)보다 적어요.** 대만만으로는 부족하니, 다음 국적(일본 등)이나 다른 지역 확장 계획이 SOM 장에 함께 있어야 "충분히 큰가"에 답할 수 있어요.

이 계산을 숨기지 말고 보여 주는 게 오히려 설득력이 있어요 (요청사항과 연결됨).

**차별점 문구 보완**: DART를 확인해 보니 등록 사업자는 3곳이라 "등록 사업자"는 우리만의 차별점이 아니에요. 차별점은 **"공공 출처 + 대구 집중 + 병원 응답 도구"** 세 가지로 말해야 해요.

## 5장 MVP — "보여 줄 수 있나?"  ❌ 없음 (가장 중요)

9~10장 흐름도는 **설계**예요. 평가 기준은 "MVP 동작", 근거 산출물은 "v1 URL 라이브 데모 · 가설 판정"이에요.

**이미 동작하는 것** (로컬에서 확인됨)
- 환자 웹: 5개 언어 · 지도 · 병원 정보·상세 · 가격 가이드 · 챗봇 · 달력 예약 요청
- 병원 대시보드: 상담 요청 목록 → 확정/날짜 제안 · 사후관리 채팅·해결 처리 · 사후관리 지원 스위치 · 요금·정산 (백엔드 API 연결, PR #28)
- 챗봇 평가 기록: `ai/agent/eval/results/` (11/10~11 의도·안전·시나리오)

**막힌 것**
1. **배포 URL 없음.** 전부 localhost예요. 환자 웹은 정적 배포(Vercel·Netlify 등)로 바로 가능해요. 대시보드는 백엔드까지 올려야 해요.
2. **환자 → 병원이 한 줄로 이어지지 않음.** 환자 쪽 예약 API 라우터 연결이 A의 작업으로 남아 있어서, 환자가 보낸 요청이 대시보드에 뜨는 장면을 아직 시연할 수 없어요. 데모 전에 꼭 연결해야 해요.
3. Supabase 마이그레이션이 SSL 인증서 문제로 멈춰 있어요. 그래서 지금은 로컬 SQLite 데모예요.

**데모 동선 초안 (90초)**
1. 언어를 繁體中文으로 → 지도에서 피부과
2. 병원 상세: 진료시간과 출처·확인일
3. 가격 가이드: 보톡스 범위와 출처
4. 챗봇에 "退稅 돼요?" 같은 질문 → 출처 붙은 답 / 못 하면 '직접 상담 요청'
5. 예약 요청서 (날짜 2개)
6. **화면 전환** → 병원 대시보드에서 AI 요약·번역 초안 → 코디가 확정
7. 환자 예약 관리에서 상태가 "확정"으로 바뀜

**가설 판정표 초안**

| 가설 | 판정 | 근거 |
|---|---|---|
| H1 가격 정보가 없어서 결정을 못 한다 | **지지** | VOC 가격 299건 1위 |
| H2 대만 환자는 대구 병원 정보를 못 찾는다 | **지지 (표본 작음)** | 대구 병원 정보 1위 25/51건 |
| H3 병원 답 대기가 이탈을 만든다 | **미검증** | 병원·코디 인터뷰 0건 |
| H4 병원이 10% + 구독료를 낼 의향이 있다 | **미검증** | LOI 0곳 |
| H5 외국인이 우리 화면만으로 예약 요청까지 간다 | **미검증** | 사용성 테스트 필요 (대만인 3~5명) |

"반응이 있는가"까지 답하려면 H5 테스트를 최소 몇 명이라도 해 두는 게 가장 효과가 커요.

## 7장 요청사항 — "그래서 무엇을 해 주면 되나?"  ❌ 없음

규칙: **마지막 장은 "감사합니다"가 아니라 요청 한 문장 + MVP URL.** 근거 산출물은 `results.md`의 '계획' 칸과 민감도 1위 가정이에요.

**민감도 1위 가정 = 1인 진료비(객단가)**
- 153만 원 → 손익분기 월 14건, 50만 원 → 46건 (**3.3배**). 다른 어떤 가정보다 결과를 크게 흔들어요.
- 그런데 153만 원은 진흥원 보고서를 인용한 *보도* 1곳뿐이고, 대구 피부과 단기 시술이라면 실제로는 더 낮을 가능성이 커요.
- 그래서 요청은 이 가정을 확인하는 쪽으로 가는 게 논리적이에요.

## 표지와 구조 규칙

- 표지 다음 바로 문제 → ✅ 지금도 지켜요 (팀 소개로 시작하지 않음).
- 표지는 **제목 + 한 줄 + URL**만 남기기. 지금 표지의 요약 5칸은 목차 역할이라 피치에서는 빼요. 페르소나·대만 이유는 1장으로 옮기기.
- 마지막 장 → ❌ 지금은 프로세스 플로우예요. 요청사항으로 바꾸기.
- 흐름도 2장, 레드팀 상세, VOC 검수 방법은 **부록**으로. 질문이 나오면 꺼내 보여 주기.
