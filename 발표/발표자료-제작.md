## 2. 숫자 쓰는 규칙

1. **출처 없는 숫자 X** — 각 장 아래 출처 줄에 보고서 표번호·데이터셋·수집일
2. **원 자료로 다시 계산** — 노트나 다른 문서의 숫자를 그대로 옮기지 말고 `data/interim/유입/*.csv`·`data/raw/` 원본으로 재확인
3. **비중·증가율은 실제 수와 같이** — 비율만 쓰면 방향이 반대로 읽힐 수 있음 (3장 사례)
4. **사이트 숫자는 확인일 함께** — 메디컬코리아처럼 바뀌는 값은 "(사이트, 10/30 확인)"
5. **전국/대구 기준 구분** — 전국 통계를 대구 이야기에 쓸 때는 "(전국)" 표시
6. **추정은 추정이라고** — "~일 가능성 (추정)", 확인 안 된 것은 "미확인"
7. **보고서 쪽 번호** — CSV `원문쪽`은 PDF 쪽 순서. 인쇄 쪽 번호와 다름(2025 보고서는 18쪽 차이) → 출처는 **표번호** 기준으로
8. 정부 문서 인용은 **원문 표현**에 가깝게, 줄이면 "요약"이라고

## 3. 내용 규칙 (규제)

- 가격은 **병원별 비교·정렬 X**, 지역 통계(중앙값·범위·기관 수·기준일)만 → [가격-표시-방식.md](../research/의료관광/가격-표시-방식.md)
- "추천", "최저가", 순위, 후기, 이벤트가, 전후 사진 표현 X
- 시연 화면은 **가상 병원·가상 환자 데이터**만 (실제 병원명·환자 정보 X)
- 서비스 경계 표는 [docs/compliance.md](../docs/compliance.md)와 같게 유지

## 4. 만드는 방법

| 단계 | 방법 |
|---|---|
| 작성 | HTML 한 파일, 16:9(1280×720) 슬라이드, ←/→로 넘김. 이전 자료(`발표자료-10.30.html`)를 복사해서 시작 |
| 글꼴 | Pretendard(인터넷에서 불러옴). 오프라인이면 맑은 고딕으로 대체됨 → 발표 PC에서 미리 확인 |
| 넘침 확인 | 브라우저에서 각 장을 열어 카드가 아래 출처 줄과 겹치지 않는지 확인 (넘치면 문구를 줄이거나 카드 간격 축소) |
| PDF 변환 | Edge 헤드리스 인쇄. **한글 경로에서 실패**하므로 영문 임시 폴더에 복사 후 변환:<br>`msedge --headless=new --no-pdf-header-footer --virtual-time-budget=8000 --print-to-pdf=deck.pdf file:///.../deck.html` |
| 저장 | `발표/발표자료-날짜/`에 HTML·PDF 함께, 커밋 전 실명·API 키 없는지 확인 |

## 5. 질문 대비로 준비할 것

- 대구 환자는 늘었는데 왜 "문제"인가 → 전국은 8배, 서울 쏠림 87.2%
- 공공 가격이 피부·성형에 없는데 가격 비교가 되나 → 지역 통계 + "예상 진료비 서면 요청 권리"(해외진출법 제8조 제2항)
- 예약 요청 기능은 유치업(등록 필요)이 아닌가 → 환자가 고른 병원에 요청서만 전달, 확정은 병원, 건당 수수료 없음 + 복지부 질의 중
- 미국·베트남 환자는 실제 관광객인가 → 미확인, 확인 계획 제시
