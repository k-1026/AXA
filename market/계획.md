## 2. 포지셔닝 맵 → `market/positioning.html`

축 후보 3쌍 (세 조건 채점 후 1쌍 선택)
1. 가로 **정보만 제공 ↔ 예약·사후관리 연결** / 세로 **광고 노출 순위 ↔ 공식·검증 정보** ← 추천
2. 서울 중심 ↔ 지역(대구) 특화 / 한국어·영어 ↔ 현지어 다국어
3. 병원이 돈 냄(광고) ↔ 성과 기반 수수료 / 단발 ↔ 방문 후 관리

- 빈 자리 "검증 정보 + 예약 연결"이 비어 있는 이유를 근거 한 줄로: 수익 구조상 광고형은 검증보다 노출을 팔고, 공식 포털은 예약·유치를 하지 않음 (병원과금-비교.md · 메디컬코리아.md)

## 3. 시장 규모 → `market/verify.md` + `market_model.xlsx` '시장규모'

**주의: 매출 = 진료비 × 수수료율.** 진료비 총액(거래액)을 우리 매출처럼 쓰지 않기.

| 방법 | 계산 | 숫자 상태 |
|---|---|---|
| 하향식 TAM | 전국 외국인환자 201만 명 × 1인당 진료비 | 환자 수 확인, **1인당 진료비 미확인** |
| 하향식 SAM | 대구 19,243명 × 1인당 진료비 × 피부·성형·외래 비중 | 대구 진료과 비중 미확인 |
| 하향식 SOM | SAM × 첫해 점유 가정 × 수수료율 | 가정 |
| 상향식 SOM | 161곳 × 입점 전환율 × 병원당 월 예약 × 12 × 건당 진료비 × 수수료율 | 161곳 확인, 나머지 가정 |

- 가장 먼저 찾을 숫자: **외국인환자 1인당 진료비** — BM 문서의 153만 원은 보도 인용이라 원문 미대조 (한국보건산업진흥원 외국인환자 유치실적 보고서의 진료수입 표) — 시트 전체가 이 값에 걸림
- 보조: 대구 방문 외국인 관광객 수 (`data/raw/유입/daegu_visitors_daily.json`)로 환자 측 상향식 교차 확인

## 4. 단위 경제·손익 → '단위경제' 시트 + `market/pnl_sim.md`

데이터·서비스 트랙 과제(주문량·재고·배송비)를 우리 구조로 바꿈

| PDF 항목 | 메디대구 버전 |
|---|---|
| 주문 1건 | 확정·내원한 예약 1건 |
| 객단가 | 건당 평균 진료비 |
| 전환율 | 챗봇 상담 → 예약 요청 → 병원 확정 → 내원 (깔때기 4단계) |
| 재고·폐기율 | **노쇼율·취소율** (수수료가 안 생기는 예약) |
| 배송비 | 건당 통역·AI API·결제 수수료·CS 시간 |
| CAC | 환자 CAC(SNS·검색 광고) + 병원 CAC(영업) — 두 개 |
| 월 고정비 | 서버·인력·유치사업자 등록·보험 |

- 수수료율: 요금안 v4 기준 기본 무료 + 13% / 프리미엄 연 ₩1,800,000 + 8% (bm/요금안-or-검토.md) → 시나리오는 1인 진료비(50만·153만 원)와 전환율로 나눔
- 민감도 후보: 상담→내원 전환율, 수수료율, 1인당 진료비 → 1위가 11/17 이후 MVP 검증 가설
- 대시보드 지표 후보 3개 = 입점 병원 대시보드 지표: 상담→내원 전환율, 노쇼율, 언어별 문의 수
