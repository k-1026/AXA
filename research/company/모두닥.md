> 산업 내 위치: 산업 **바깥 인접**(국내 내국인용) — **국내 병원 정보·리뷰 플랫폼 (광고형)**. 외국인 유치 산업의 직접 플레이어는 아님 [I]
> 표기: 칸마다 사실 한 줄 + 출처 번호, 없으면 "미기재" · [I] 해석 · [U] 미확인

## 한 줄 요약
비급여 진료 **가격 비교 + 영수증 인증 후기**를 내세운 국내 병원 정보 플랫폼. 수익은 **병원 광고**에서 나오는 것으로 보인다 [1][2].

## 사업 모델 6질문

| 질문 | 사실 | 출처 |
|---|---|---|
| 누구에게 | 국내 소비자 (비급여 진료를 알아보는 사람). **외국어 지원 [U]** | [1][3] |
| 무엇을 | 비급여 가격 비교, 실제 방문자 리뷰(영수증 인증), 온라인 예약. 안과 중심 → 치과·성형외과로 확대 | [1][2] |
| 어떻게 전달 | 앱·웹 | [1] |
| 어떻게 돈 | 병원 광고 — 채용 공고에 병원 광고 영업·광고 상품 기획·광고 성과(노출·유입·예약·전환) 분석이 핵심 업무로 적혀 있음. 매출 구성 비율은 미기재 | [2] |
| 무엇으로 (핵심 자원·파트너) | 제휴 병원(광고주), 영수증 인증 후기 데이터 | [1][2] |
| 얼마나 들어 (비용) | 미기재 | — |

## 메디대구와 비교 [I]

| | 모두닥 | 메디대구 |
|---|---|---|
| 이용자 | 내국인 | 단기 방문 외국인 |
| 돈 내는 쪽 | 병원 (광고) | 병원 (건당 중개수수료, 확장 시 + 월 입점료) |
| 가격 정보 | 병원 비급여 가격 비교 | 공공 비급여 기준 지역 가격 범위 (병원별 나란히 비교 X) |
| 후기 | 영수증 인증 후기가 핵심 | 후기 없음 (팀 규제 판단) |
| 참고할 점 | 국내에서 병원이 "광고비를 내는 이유"를 성과 지표(노출·예약·전환)로 보여줌 → 메디대구 대시보드 설계에 참고 | |
