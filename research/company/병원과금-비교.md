# 플랫폼별 병원 과금 방식 비교 (STEP 4 비용 마커 C1·C2 근거)

> 작성 2026-11-10 · 질문: "다른 앱·플랫폼은 병원에게 어떻게 돈을 받나? 입점료 + 건당 수수료를 같이 받는 곳이 있나?"
> 표기: [I] 해석 · [U] 미확인 · 금액은 공식 안내 문서에 있는 것만

## 한 줄 결론
찾은 곳 중 **월 입점료 + 건당 수수료를 함께 받는 곳은 없었다.** 광고형(강남언니·바비톡)은 **조회·클릭당 광고비만**, 중개형(Bookimed)은 **입점 무료 + 환자당 수수료**, 트립닥은 **병원 무료**(회사 설명)다.

## 비교표

| 플랫폼 | 병원이 내는 것 | 월 입점료 | 건당(환자당) 수수료 | 법적 성격 | 출처 |
|---|---|---|---|---|---|
| **강남언니 / UNNI** | 이벤트 광고 **CPV**(페이지 조회당, 10~4,000원 변동 단가) + 부가광고 **CPC**(클릭당, 입찰 550~100,000원). 상담 신청·결제·내원과 무관하게 과금 | 공식 안내 없음 | **없음** — 외국인 서비스도 유치 수수료가 아니라 광고비만 받는다는 회사 입장 | 광고 매체 | [1][2][3] 공식 / [4] 언론 |
| **바비톡** (국내) | 이벤트 광고 **CPV** + 상위 노출 입찰. 앱에서 시술권을 팔면 결제 금액에서 **PG 수수료만** 빼고 월 2회 정산 | 공식 안내 없음 | 없음 (PG 수수료만) | 광고 매체 + 결제 대행 | [5][6] 공식 |
| **모두닥** (국내) | 병원 광고 (채용 공고 기준) | 미기재 | 미기재 | 광고 매체 | [7] |
| **트립닥** | 병원 입점비·월 이용료·유치 수수료 **없음** (회사 설명), 앱 결제 있음 | 없음 | 없음 | [U] (등록 여부 미확인) | [8] 공식 |
| **Bookimed** (해외 중개) | **입점 무료**, 플랫폼으로 온 환자 **1명당 수수료**(국가별 요율). 일부 국가는 **1회 셋업비**. 광고 노출은 문의당 **별도 과금** | 없음 (멤버십·리드 비용 없음) | **있음** | 해외 의료관광 중개 | [9][10] 회사 공식 |
| **등록 유치사업자** (법정) | 진료비 대비 **유치 수수료**(상한 의원 30%·병원·종합병원 20%·상급종합 15%), 통역·교통·숙박 등 비의료서비스 대가는 상한 밖 | 법에 정함 없음 | **있음** (상한 내) | 유치사업자 | [11] 공식 |
| **메디대구 (11/10 결정)** | 초기: **입점 무료 + 건당 중개수수료** → 확장: **월 입점료 + 건당 중개수수료** | 초기 없음 → 확장 시 있음 | 있음 | 유치사업자 (직접 등록 또는 제휴) | STEP 0 |

## 메디대구에 주는 뜻 [I]

### C1 · 병원 중개비용 중첩
- 병원은 광고형(강남언니·바비톡, 조회·클릭당)과 수수료형(유치업체·Bookimed, 환자당)을 **동시에** 쓸 수 있음 → 메디대구 비용까지 더해지면 병원 입장에서 외국인 환자 1명의 획득 비용이 겹침
- 근거 보강: 강남언니 CPV 차감이 병원에 "사실상 가입비"처럼 느껴진다는 원장들의 불만 보도 [12] (2024, 현재 구조와 다를 수 있음)
- → 대시보드에서 **"메디대구를 통해 온 환자·확정 건수"**를 보여줘야 병원이 다른 채널과 비교해 비용을 판단할 수 있음

### C2 · 월 입점료 + 건당 수수료
- 같은 구조를 쓰는 곳을 **찾지 못함** → 선례가 없어 상한 계산에 입점료가 합쳐지는지 판단할 근거도 없음 [U]
- 가장 가까운 모델은 **Bookimed**: 입점 무료 + 환자당 수수료 + (일부) 1회 셋업비 + 광고는 별도 상품
- 선택지 (팀이 정할 것, STEP 0 T1과 연결)

| 안 | 구조 | 장점 | 남는 문제 |
|---|---|---|---|
| A. Bookimed형 | 입점 무료 + 건당 수수료(상한 내) | 선례 있음, 상한 계산이 단순 | 초기 매출이 환자 수에 달림 |
| B. 분리형 | 건당 수수료(상한 내) + **대시보드 이용료**를 별도 상품으로 | 고시가 비의료서비스 대가를 상한 밖으로 둠 | 대시보드가 "비의료서비스"에 들어가는지 [U] → 질의 필요 |
| C. 확장안 | 월 입점료 + 건당 수수료 | 고정 매출 확보 | 선례 없음, 합산 여부 [U] |

- **팀 결정 (2026-11-10): 초기 A안 → 규모가 커진 뒤 C안.** C안으로 넘어가기 전에 입점료 합산 여부를 질의로 확인
