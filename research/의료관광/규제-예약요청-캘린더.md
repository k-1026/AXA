# 규제 Q5. 정보 웹에서 예약 요청 → 병원 캘린더에 들어가는 구조는 괜찮나?

> 작성 2026-10-29 · 근거: 법령 원문 [1][2][3], 판례 [4][5], 복지부 해석 보도 [6] · 법적 판단이 아니라 조문·판례에 비춘 정리
> 이어지는 노트: [규제-예약에이전트-B2B.md](규제-예약에이전트-B2B.md) (Q4의 "B 구조"를 구체화)
> 결론 등급: **프로토타입(가상 데이터)은 문제없음 / 실제 운영은 아래 조건 + 복지부 질의 후**

## 한 줄 결론

"우리가 예약해 준다"가 아니라 **"환자가 고른 병원에 환자가 직접 요청서를 보내고, 병원이 확정한다"**로 설계하면 유치(예약 대리)·알선 위험을 가장 줄일 수 있다. 남는 쟁점은 **개인정보(건강정보·국외 이전)**와 **유료 병원 우대**다.

## 1. 흐름별 판단

| 단계 | 설계 | 판단 | 근거 |
|---|---|---|---|
| ① 병원 찾기 | 공공정보 목록, 중립 정렬. "온라인 요청 가능" 여부로 순서를 바꾸지 않음 | ✅ | 특정 병원 유도 = 알선 [4] |
| ② 요청서 작성 | **환자가 직접 고른 병원 1곳**에 보내는 "○○병원 상담·예약 요청서". AI는 **입력 도우미**(번역, 빠진 칸 안내)만 | ⚠️ 조건부 | 우리가 병원을 고르거나 환자 대신 계약하면 "진료예약 대리" = 유치 [2] |
| ③ 전송·저장 | 요청서는 병원 캘린더에 **"대기"** 상태로 들어감 (확정 아님) | ✅ | 계약 성립 여부는 병원이 결정 |
| ④ 병원 확정 | 병원 직원이 확정·거절·다른 시간 제안. 확정 시 **진료계약서·예상 진료비** 안내 | ✅ | 유치의료기관의 안내 의무 (해외진출법 제8조 제2항) [2] |
| ⑤ 병원 쪽 AI | 요청 요약·번역·답장 초안 → **직원이 승인 후** 발송 | ✅ 조건부 | 의료 판단 X (의료법 제27조 제1항) [1] |
| ⑥ 돈 | 병원에서 **예약 건당 수수료 X**. 수익은 공공 위탁 또는 병원 고정 이용료(추후) | ✅ | 건당·진료비 비례 대가 = 알선 대가 [4][5] |

## 2. 추가로 걸리는 법

| 쟁점 | 조문 | 설계 |
|---|---|---|
| **건강정보 = 민감정보** | 개인정보보호법 제23조: 건강 정보는 **다른 동의와 별도로 동의**받아야 처리 가능, 안전조치 의무 [3] | 요청서의 "희망 진료·증상" 칸은 선택 입력 + 별도 동의 체크. 최소 수집 |
| **누가 개인정보처리자인가** | 제26조: 처리 업무 위탁 시 문서 계약, 수탁자는 위탁 범위 밖 이용 금지 [3] | 요청서는 **병원 명의**(병원 = 처리자, 우리 = 수탁자). 우리가 요청 데이터를 다른 병원·마케팅에 쓰지 않음 |
| **국외 이전** | 제28조의8: 국외 제공·처리위탁·보관은 별도 동의 등 요건 필요 [3] | 해외 LLM API·해외 서버에 요청서 내용을 보내면 해당 → 프로토타입은 **가상 데이터만** |
| **특정 앱으로만 접수** | 의료법 제15조 제1항 진료 거부 금지 [1]. 복지부는 특정 유료 앱으로만 접수받는 것을 진료 거부로 본다는 해석을 냄 (2023, 보도) [6] | 우리 요청서는 **여러 접수 경로 중 하나**. 병원이 전화·이메일 접수를 유지 |
| **등록 여부** | 해외진출법 제6조 제1항: 외국인환자를 유치하려는 의료기관은 등록 [2] | 요청 기능은 **등록 유치의료기관만** 켤 수 있음 |
| **원격 상담** | 의료법 제34조의2 비대면진료 [1] | "상담 예약" = **병원 방문 상담 일정** 잡기. 화상·채팅 진료 아님 |

## 3. 프로토타입에서 보여줄 "규제 안전장치" (발표 포인트)

1. 요청서 상단: "이 요청은 ○○병원에 직접 전달됩니다. 예약 확정·진료비 안내는 병원이 합니다."
2. 동의 화면 2개: 개인정보 수집·병원 전달 / 건강정보(선택) 별도 동의
3. 병원 캘린더 상태값: 대기 → 확정·거절·시간 제안 (확정은 병원 직원만)
4. AI 답변 거절 예시: "어떤 시술이 맞나요?" → "의료진 판단이 필요합니다. 요청서에 적어 병원에 물어보세요."
5. 목록 정렬은 거리·가나다순, "온라인 요청 가능"은 필터일 뿐 순위 아님

## 4. 남은 의문
- 정보 사이트 → 병원 요청서 연결(B 구조)을 해외진출법상 "유치 편의 제공"으로 볼지 → **보건복지부·한국보건산업진흥원 질의** (Q2·Q4와 같은 질문으로 묶어서)
- 병원 고정 이용료가 의료법 제27조 제3항 "영리 목적"과 무관하다는 공식 해석 → **미확인** (예약 앱 관련 복지부 유권해석은 2026-07 기준 의협 질의에 미답변이라는 보도 [7])
