# 한방 진료과 — 병원·시술·가격 근거와 출처

> 작성 2026-11-23 · 대상: 메디대구 웹에 새로 넣은 **한방** 진료과 (`korean-medicine` 브랜치, 커밋 8e2dfc1)
> 원칙: 피부과·성형외과·내과·안과와 **같은 방법**으로 모음 — 병원은 등록 유치기관 명단 + 심평원 요양기관 정보, 가격은 심평원 비급여 공개 금액

## 한 줄 요약

**대구 등록 외국인환자 유치기관 중 한의원·한방병원 40곳을 지도·목록에 넣고, 심평원 비급여 공개 금액(2026-08)으로 한방 시술 9개의 가격 범위를 계산했어요.** 근거 없는 시술·숫자는 넣지 않았어요.

## 1. 병원 — 누가 "한방"으로 들어가나

| 단계 | 방법 | 결과 | 출처 |
|---|---|---|---|
| ① 등록 유치기관 명단 | 한국보건산업진흥원 「외국인 자주 찾는 병원」 파일에서 콘텐츠타입 `REGISTERD_HOSPITALS`·사용 중·대구만 | 대구 등록 기관 161곳 | [1] |
| ② 심평원 요양기관과 맞추기 | 전화번호 뒤 8자리가 1곳과만 같을 때 요양기관 기호(ykiho) 연결 (`data/etl/registered_institutions.py`) | 명단 ↔ 심평원 종별·주소·좌표 | [1][2] |
| ③ 폐업 제외 | 심평원·행안부 영업상태 교차검증에서 "정상"이 아닌 곳 제외 | — | [3] |
| ④ 한방 분류 | 심평원 **종별(clCdNm)이 한의원·한방병원**인 곳 → `korean_medicine` (전엔 "기타") (`apps/web-platform/scripts/build-hospitals.mjs`) | **40곳** = 한의원 34 · 한방병원 6 | [2] |

- 구·군: 수성구 22 · 중구 6 · 달서구 5 · 동구 3 · 달성군 2 · 북구 1 · 서구 1
- 종합병원 안의 한방과는 종별로 구분되지 않아 들어가지 않음 (한계)
- 웹에는 **등록 유치의료기관만** 노출 (팀 결정 21, `docs/compliance.md`)

## 2. 시술 종류 — 무엇을 보여 주나

다른 진료과는 팀 문서 「병원별 시술 모음.docx」의 분류를 썼지만, **한방은 그런 팀 문서가 없어서 공공 비급여 항목만** 골랐어요. 신고 기관이 **20곳 이상**인 항목만 넣었어요.

| 웹 묶음 | 웹 항목 | 심평원 분류 (대분류 "한방") | 신고 기관 수 |
|---|---|---|---|
| 추나요법 | 단순추나 | 한방 시술 및 처치료 › 추나요법 › 단순추나 | 255 |
| | 복잡추나 | 〃 › 복잡추나 | 174 |
| | 특수추나 | 〃 › 특수(탈구)추나 + 특수(내장기, 두개천골)추나 | 61 |
| 약침 | 약침술 | 한방 시술 및 처치료 › 약침술 › 경혈 | 600 |
| 한방물리요법 | 경근간섭저주파요법 | 한방 시술 및 처치료 › 한방물리요법 › 경근간섭저주파요법 | 96 |
| | 경피전기자극요법 | 〃 › 경피전기자극요법 | 37 |
| | 한방 향기요법 | 한방 시술 및 처치료 › 한방 향기요법 | 24 |
| 한방 검사 | 경피온열검사 | 한방 검사료 › 경피온열검사 › 전신 | 44 |
| | 사상체질검사 | 한방 검사료 › 사상체질검사 › QSCCII 설문지 (심성검사 / 심성검사 및 상담) | 27 |

**넣지 않은 것**
- 침·뜸·부항·첩약: 이번 비급여 공개 자료에 항목이 없음 → 가격 근거가 없어 제외
- 신고 기관 20곳 미만: 자율훈련법(11) · 혈맥어혈검사(9) · 경근무늬측정검사(7) · 골도법검사(4) · 경피온열검사 부분(36곳이지만 전신과 중복이라 전신만)

## 3. 가격 — 어떻게 계산했나

| 항목 | 내용 |
|---|---|
| 자료 | 심평원 누리집 **비급여 진료비 정보** 대구 전체 내려받기 (`data/raw/비급여진료/대구_비급여진료비_전체.csv`, 65,306행 · 공개기준 2026-08) [4] |
| 고른 행 | 대분류 "한방" 1,442행 (폐업 판정 9곳 제외 후) |
| 기관별 값 | 같은 기관에 같은 항목이 여러 줄이면 그 기관의 **최소금액 중 가장 낮은 값** 1개 |
| 웹 표시 | 기관별 값의 **하위 10% ~ 상위 10%** (최근접 순위 백분위) |
| 왜 10%~90% | 최소값에 0원·100원 같은 값(이벤트·입력 오류로 보임)이 섞여 최소~최대가 오해를 줌 |
| 같은 방법 | 내과·안과 가격 `data/etl/nonpay_price_stats.py`와 입력·폐업 제외·기관별 최저 규칙이 같음. 다른 점은 웹 표시 구간(10~90%)뿐 |
| 스크립트 | `data/etl/korean_medicine_price_stats.py` (표준 라이브러리만) → `data/processed/daegu_korean_medicine_price_stats.csv` + 웹용 `apps/web-platform/src/features/price-info/koreanMedicinePrices.ts` |

## 4. 해석할 때 조심할 것

| 주의 | 내용 |
|---|---|
| 내국인 기준 금액 | 병원이 심평원에 신고한 **공개 금액**이라 외국인 환자 실제 진료비와 다를 수 있음 → 가격 가이드 공통 고지("내국인 기준 공개 금액, 병원에 확인")가 한방 카드에도 붙음 (복지부·진흥원 회신 2026-11-17, `docs/compliance.md`) |
| 추나요법과 건강보험 | 추나요법은 건강보험 환자에게 급여로 적용되는 경우가 있다고 알려져 있음 — **미확인** (공식 출처로 확인 전). 여기 금액은 **비급여로 신고된 경우** |
| 표본 크기 | 사상체질검사(27)·한방 향기요법(24)은 기관 수가 적어 범위가 넓음 |
| 단위 | 대부분 "1회". 약침은 약제·부위에 따라 달라질 수 있음 (자료의 특이사항 칸 미반영) |
| 기준 시점 | 2026-08 공개분 — 심평원 공개 갱신 때 스크립트를 다시 돌려야 함 |

## 5. 사진

- 한방 병원 카드의 **병원 대표사진**은 이번 작업이 아니라 앞선 사진 PR(k-1026/AXA#73)로 들어간 것 — 팀 수집 파일의 **네이버 플레이스 대표사진** 주소 [5]
- 외부 주소를 그대로 불러오는 **시연용**이고, 정식 공개 전 **병원 동의 사진으로 교체** 필요 (`docs/compliance.md`)
- 한방 **시술 카드 그림은 없음** (다른 진료과는 `public/procedures/` 그림 사용)
