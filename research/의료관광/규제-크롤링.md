# 규제 Q6. robots.txt가 없으면 크롤링해도 되나?

> 작성 2026-10-29 · 계기: 리브의원(체인 사이트 ppeum26.com) robots.txt 확인 → 사이트 전체 점검 중(HTTP 503)이라 **있는지 없는지 확인 불가**
> 법적 판단이 아니라 판례·보도에 비춘 정리

## 결론

**robots.txt가 없다 ≠ 크롤링 허락.** robots.txt는 로봇 접근에 대한 사이트의 의사 표시(관례)일 뿐이고, 없다고 해서 이용약관·저작권·부정경쟁 문제가 사라지지 않는다. 팀 규칙("자동 크롤링은 약관 확인 전 금지")을 유지한다.

## 판단 근거

| 쟁점 | 내용 | 출처 |
|---|---|---|
| 크롤링 형사 사건 | 대법원 2022. 5. 12. 선고 **2021도1533**(여기어때·야놀자): 정보통신망 침입, 데이터베이스제작자 권리 침해, 업무방해 모두 **무죄** 확정 | [1][2] |
| 무죄 이유(DB 부분) | 수집 정보가 이미 알려진 정보이고, 앱으로도 확보 가능했으며, 상당한 투자로 만든 DB의 "상당한 부분" 복제로 보기 어려움 | [1][2] |
| 그러나 민사는 별개 | 같은 사건의 민사(서울고등법원 2021나2034740)는 무단 데이터 수집의 **민사책임을 인정**한 판결로 함께 논의됨 | [3] |
| robots.txt의 의미 | 사이트가 로봇 접근에 대해 밝히는 의사 표시(관례). 판결에서 robots.txt를 어떻게 봤는지는 판결문 원문 **미확인** | — |

## 우리 프로젝트에 적용

| 수집 대상 | 판단 | 이유 |
|---|---|---|
| 병원 홈페이지의 **진료시간** (사실 정보, 소량, 사람이 확인·출처 기록) | 지금 방식 유지 가능 | 사실 정보는 저작물이 아니고, 소량·수동은 서버 부담·DB 복제 문제 작음 |
| 같은 정보를 **자동 프로그램으로 대량** 수집 | 약관 확인 전 X | 약관 위반 시 민사 책임 가능 [3], 서버 부담 |
| 병원 홈페이지의 **가격·이벤트·전후 사진** | 수집해도 **쓰지 않음** | 병원 광고를 우리가 다시 싣는 셈 → 의료광고 위험 ([규제-가격노출-의료광고.md](규제-가격노출-의료광고.md)) |
| 강남언니·모두닥 등 **플랫폼** 데이터 | X (이미 `.gitignore`) | 플랫폼이 투자해 만든 DB + 약관 → 민사 위험 가장 큼 |

- 리브의원: 점검 끝나면 robots.txt·이용약관 재확인 → 진료시간만 수동으로 채움

### 리브의원 동성로점 robots.txt 확인 (2026-10-29)

- 심평원 등록 홈페이지(`ppeum26.com`)와 **다른 실제 사이트** `dongseongro.reevclinic.com` 확인 → 작업표 홈페이지 주소 갱신 필요
- `https://dongseongro.reevclinic.com/robots.txt` → **있음 (HTTP 200)**. (`robot.txt`는 표준 파일명이 아니라 404)

| 대상 | 규칙 |
|---|---|
| 일반 로봇 (`User-agent: *`) | `Allow: /` — 이벤트·예약·소개·의료진·오시는 길·공지 경로 명시 허용 |
| 막은 경로 | `/api/`, `/login`, `/signup`, `/auth/`, `/admin/`, 정렬·필터·페이지 파라미터 |
| AI 크롤러 (GPTBot, ClaudeBot, anthropic-ai, CCBot, PerplexityBot 등) | **`Disallow: /` (전부 차단)** — 주석은 "explicitly allowed"라고 적혀 있지만 실제 규칙은 차단 |
| 본 도메인 `reevclinic.com`·`www.reevclinic.com` | `Disallow: /` (전부 차단) |

- 해석: 사람이 진료시간을 보고 적는 것은 문제없음. **자동 수집은 일반 로봇 기준 소개·오시는 길 페이지는 허용**, 단 이용약관 확인 전 X. **AI(LLM) 학습·수집 용도는 명시적으로 거부** → 챗봇 RAG용으로 이 사이트를 긁어 넣지 않음
- 이벤트 경로가 허용돼 있어도 **이벤트 가격은 쓰지 않음** (의료광고 기준)
- **원래 가격(비급여 고지 가격)은 이벤트가와 다름**: 의료법 시행규칙 제42조의2 제4항 — 홈페이지를 운영하는 의료기관은 비급여 항목·가격(제1항)과 제증명수수료(제3항)를 **홈페이지에 따로 표시해야 함** (의원급 포함, 시행 2026-06-12 기준 조문)
  - 법이 공개를 의무로 정한 **고지 가격** → 사람이 보고 출처·기준일과 함께 적는 것은 조건부 가능 (표시 시 "병원 고지 기준, 외국인 진료비와 다를 수 있음")
  - 리브의원 동성로점: 고지 페이지 경로를 못 찾음(`/nonpay`, `/price` 등 404, 사이트맵에 없음) → 사이트 메뉴에서 사람이 직접 확인 필요
- 이벤트 페이지(`/events`) HTML에는 가격이 없음("0원" 자리표시만). 가격은 화면이 **`/api/`에서 불러옴** → robots.txt가 막은 경로라 자동 수집 X
