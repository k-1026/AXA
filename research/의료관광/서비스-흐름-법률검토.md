# 서비스 흐름: 외국인에게 무엇을 어떤 순서로 보여줄까 (법률 검토 포함)

> 작성 2026-10-29 · 근거: 법령 원문 [1][2][3], 메디컬코리아 공식 안내 [4], 멘토 피드백(2026-10-29) · 법적 판단이 아니라 조문·공식 안내에 비춘 정리
> 이어지는 노트: [규제-가격노출-의료광고.md](규제-가격노출-의료광고.md) · [규제-병원연결-유인알선.md](규제-병원연결-유인알선.md) · [규제-1대1상담.md](규제-1대1상담.md)

## 한 줄 결론

공식 절차는 **상담·예약 → 예약 서류(초청장) → 비자 → 입국·진료**다 [4]. 우리는 이 중 **"예약 전까지 스스로 알아보는 단계"만** 맡는다. 순서는 **내 상황 → 병원 찾기 → 공공 가격 참고 → 병원에 직접 문의(확인할 것 체크리스트) → 비자·방문 준비 → 문제 생기면**. 예약·상담·사후관리는 병원과 공식 기관으로 넘긴다.

## 1. 먼저 갈라야 할 것: 이 사람이 법상 "외국인환자"인가

| 사용자 | 법상 지위 | 의미 |
|---|---|---|
| 해외에 살면서 치료받으러 오는 사람 | **외국인환자** | 의료법 제27조 제3항 유치 예외 적용 대상 → 유치는 **등록 기관만** [1][2] |
| 관광 등으로 와 있는 단기 체류자 (외국인등록 안 함) | **외국인환자** | 위와 같음 |
| 외국인등록을 한 사람 (G-1 제외), 국내거소신고 외국국적동포 | **외국인환자 아님** (시행규칙 제2조) [3] | 유치 예외 적용 X → 의료법 제27조 제3항 **일반 금지**(영리 목적 소개·알선 금지)를 그대로 받음 [1]. 내국인과 같은 기준 |

→ 어느 쪽이든 **"병원에서 돈 안 받고, 특정 병원으로 보내지 않는 공공정보 안내"**는 같은 판단. 차이는 비자 안내와 "등록 유치의료기관" 필터가 필요한지 여부

## 2. 추천 흐름 (화면 순서)

| 단계 | 보여줄 것 | 판단 | 근거 |
|---|---|---|---|
| **0. 시작** | 언어 선택, "공공정보 안내 서비스 · 광고·추천·예약 아님 · 의료 상담 아님" 고지 | ✅ | 역할 경계 표시 |
| **1. 내 상황** | 해외 / 국내 단기 체류 / 국내 등록 거주 선택 → 이후 안내 분기. 비자 필요 여부 개요(C-3-3 최대 90일, G-1-10 1년 이내) | ✅ 공식 정보 링크 | [3][4] |
| **2. 병원 찾기** | 지도 + 필터: 지역·진료과·진료시간·휴진일·**등록 유치의료기관/인증 여부**(공식 목록). 정렬은 **거리순·가나다순** 같은 중립 기준 | ✅ | 등록 목록은 시·도 게시 공개정보 [2]. 인증마크는 실제 인증 기관만 (제14조 제3항 사칭 금지) [2] |
| **3. 병원 상세** | 주소·전화·홈페이지·진료시간(출처·확인일 표시), 등록·인증 사실 | ✅ 사실 정보 | 병원 홈페이지에서 **진료시간 같은 사실**만 옮김. 홍보 문구·이벤트·전후 사진은 옮기지 않음 |
| **4. 가격 참고** | 공공 비급여 고지 금액 (아래 3절 표시 규칙) | ✅ 조건부 | 의료법 제45조의2: 복지부가 비급여 현황을 공개(병원급은 의무) [1] |
| **5. 병원에 직접 문의** | 병원 공식 연락처·채널 링크 + **"문의할 때 받아야 할 것" 체크리스트**: 진단명·치료방법·부작용, 진료계약서·예상 진료비, 분쟁해결절차 | ✅ | 유치의료기관은 이 3가지를 외국인환자에게 안내할 **의무**(해외진출법 제8조 제2항) [2] → 법이 정한 권리를 알려주는 것 |
| **6. 비자·방문 준비** | C-3-3/G-1-10 요건, 직접 신청 서류(진단서, 예약 확인서, 재정 보증) vs 병원·유치업체 대리 신청 [4]. 공식 사이트 링크 | ✅ 링크·요약만 | 초청장 발급·대리 신청은 **병원·등록 유치업체 몫** — 우리가 하면 유치 [2] |
| **7. 방문 당일** | 지도 길찾기, 진료시간·휴진 재확인 안내, 병원 게시물에서 볼 것(등록증, 영어 권익 안내문) | ✅ | 등록증 게시·권익보호 사항 영어 게시 의무 (제8조 제1항, 시행규칙 제7조) [2][3] |
| **8. 문제 생기면** | 병원 분쟁해결절차 → 메디컬코리아 연락처 → 한국의료분쟁조정중재원 링크 | ✅ 링크만 | 메디컬코리아 공식 연락처 [4]. 외국인도 조정 신청 가능하다는 보도 [6] (**법 원문 미확인**) |

## 3. 가격 참고 화면 표시 규칙 (멘토 피드백 반영)

| 항목 | 표시 방법 | 우리 데이터 상황 |
|---|---|---|
| 비교 조건 | 시술명·부위·용량·횟수·재료 | 공공 데이터는 **항목명만** 있음 (`npayKorNm`, 병원별 명칭 `yadmNpayCdNm`) → 항목명 그대로, 조건은 "병원 확인" |
| 포함 항목 | 마취·검사·약제·사후관리·부가세 포함 여부 | 공공 데이터에 없음 → "포함 여부는 병원에 확인" 고정 문구 |
| 통계 조건 | 지역, 기관 수, 기준일, 평균·중앙값·범위 산출 방식 | 기준일(`adtFrDd`) 있음 → 기관 수·중앙값·범위를 **우리가 계산해 산식과 함께** 표시 |
| 적용 한계 | 외국인 통역·코디네이션 비용 포함 최종 견적과 다를 수 있음 | 고정 문구 |

- 지켜야 할 것: **"최저가"·순위·할인율·이벤트가 X** ([규제-가격노출-의료광고.md](규제-가격노출-의료광고.md))
- 한계: 공공 비급여는 **병원급만**, 보톡스·필러 등 **미용 시술 코드 없음** ([progress.md](../../subject/progress.md) 4절) → 피부·성형은 "공공 가격 정보 없음 → 병원에 견적 요청(5단계)"으로 안내. 크롤링·이벤트 가격으로 채우지 않음

## 4. 챗봇 답변 범위

| 질문 유형 | 답 | 근거 |
|---|---|---|
| "수성구 피부과 토요일 진료하는 곳?" | 조건에 맞는 병원 **여러 곳을 중립 순서로**, 출처·기준일 표시 | 지역 내 의료기관 종합 안내는 비대면진료 중개업자에게도 허용되는 범위(의료법 제34조의9 제1항 제5호 괄호) [1] |
| "C-3-3 비자 서류는?" | 공식 문서 검색 → 요약 + 링크 + 기준일 | 변경 잦은 정보는 학습 대신 **최신 문서 검색** (멘토 피드백) |
| "이 증상이면 무슨 시술 받아야 해?", "부작용 괜찮을까?" | **답하지 않음** → "의료진 판단이 필요합니다" + 병원 문의(5단계) 연결 | 비의료인 의료행위 금지 (의료법 제27조 제1항) [1] |
| "어디가 제일 잘해? 추천해줘" | 추천하지 않음 → 필터 조건 안내 | 특정 병원 유도 = 알선 위험 [1][5] |

## 5. 넣지 않는 것

| 기능 | 이유 |
|---|---|
| **사후관리 Q&A** | 멘토 판단 "구현 불가". 해외진출법 제16조 사전·사후관리는 **유치의료기관 의사 → 국외 의료인**(의사 대 의사)만 허용 [2]. 환자와 직접 하면 비대면진료(의료법 제34조의2) 요건·중개매체 신고(제34조의8) 문제 [1] |
| 예약 대행·초청장·통역 동행·픽업 | 유치 활동 = 등록 필요 [2] |
| 병원 순위·"추천"·후기·전후 사진·이벤트가 | 의료광고·알선 위험 |
| 병원에서 받는 입점비·광고비·수수료 | 의료법 제27조 제3항 [1][5] |
| 1:1 실시간 상담 | MVP 제외, 확장 시 [규제-1대1상담.md](규제-1대1상담.md) 조건 |

## 6. 남은 확인
- 미용성형 부가세 환급 특례 현행 여부 (6~8단계에 넣을지) → **미확인**
- 의료분쟁조정법상 외국인 신청 조문 원문 → **미확인**
- 외국인등록 의무 기준(출입국관리법 제31조) 원문 → **미확인** (1단계 분기 문구에 필요)
- 공공 비급여 금액이 외국인환자에게도 같은 금액인지 → **미확인** (적용 한계 문구로 대응)
