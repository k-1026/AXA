# 환자용 웹사이트 법적 점검 (현재 구현 기준)

> 작성 2026-11-05 · 대상: `apps/web-platform` (`frontend` 브랜치, 1627258 기준)
> 법적 판단이 아니라 팀 규제 노트와 조문에 비춘 정리. 조문·판례는 팀 노트(2026-10-29 확인)를 옮긴 것으로 이번에 원문을 다시 확인하지 않음. 정식 공개 전 전문가 검토 필요

## 결론

- 서비스 뼈대(공공데이터 안내, 병원에서 돈 안 받음, 중립 정렬)는 팀 기준에 맞음
- **팀 기준과 어긋나는 것 4개**: 병원 대표사진, 임시 가격, 메인 광고 배너, "광고·배너 문의"
- 앞의 2개는 프로토타입용 임시로 팀이 결정한 것 → 정식 공개 전 교체 필요

## 1. 팀 기준과 어긋남 (정식 공개 전 해결)

| 구현 | 쟁점 | 관련 근거 | 할 일 |
|---|---|---|---|
| 병원 대표사진 1,109곳 (네이버 플레이스 주소) | 홍보 포스터·"우수등급" 이미지 포함, 병원 광고를 대신 싣는 구조로 보일 수 있음. 사진 저작권·이용 조건 미확인 | 의료법 제56조 제1항, 제2항 제8호·제14호 유형 [1], 팀 규칙 [5] | 병원 동의 사진 또는 기본 이미지로 교체 |
| 가격 범위 6개 (피부과 홈페이지 수집 통계) | `docs/compliance.md`의 "크롤링 가격" 금지와 충돌 가능. 수집 방법 미확인. 6개 중 5개는 기관 5곳 미만 | 의료법 제56조 제2항 제13호 유형 [1], 가격-표시-방식 [6], 규제-크롤링 [7] | 수집 방법 확인, 병원 고지가·공공 자료로 다시 산출 |
| 메인 광고 배너 "한방 스킨케어" | 건강·미용 카테고리 차단 규칙과 충돌. 메인 지도 화면에 있음 (규칙은 목록·상세 옆만) | `docs/compliance.md` [5] | 배너 교체 또는 삭제 |
| 푸터 "광고·배너 문의" | 병원이 광고비를 내면 "병원에서 돈을 받지 않는다"는 전제가 깨짐 | 대법원 2018도20928, 2021도10046 [3][4] | 의료기관 광고는 받지 않는다고 명시 |

## 2. 조건을 지키면 괜찮은 것 (관련 있음)

| 구현 | 쟁점 | 지금 상태 |
|---|---|---|
| 병원 목록·지도·상세 | 제3자의 정보 제공이 의료광고인지 (제56조 제1항, 직접 다룬 판례 못 찾음) | 가나다순, 모든 병원 같은 형식, 고지 문구 있음 |
| 다국어 병원 안내 전체 | "진료정보 제공"이 외국인환자 유치에 해당하는지, 유치사업자 등록이 필요한지 (의료해외진출법 제2조 제3호) | **미확인**. 기관 질의 회신 대기 |
| 병원 홈페이지 링크 | 연락처·홈페이지 링크는 팀 기준에서 허용 | 블로그·네이버 제외 |
| 인스타그램 링크 | 팀 기준에 명시 없음. 링크 너머에 전후 사진·이벤트가 있을 수 있음 | 팀 판단 필요 |
| 시술 카드·일러스트 | 전후 사진 금지. 일러스트라 전후 비교는 아니지만 체형 변화 화살표가 있음 | 규정 담당 검토 권장 |
| 가격 환산 | 참고용 환산이라고 표시, 원화 금액이 기준 | 원 가격이 임시라는 점은 그대로 |
| 찜 | 사용자가 직접 고른 목록, 순위·추천 없음 | 문제 낮음 |
| 방문 기록 | 공개 시 치료경험담(제56조 제2항 제2호 유형). 건강정보(개인정보 보호법 제23조) | 비공개, 브라우저 저장. 공용 기기 노출·탈퇴 후 잔존은 확인 필요 |
| 챗봇 | 증상·시술 판단은 의료행위 위험(제27조 제1항). 입력 내용 국외 이전(개인정보 보호법 제28조의8) | 데모 답변 단계. 실제 LLM 연결 시 거절·마스킹 시험 필요 |
| 회원가입·탈퇴 | 개인정보 수집 동의, 파기 (개인정보 보호법 제15조 등) | 동의·즉시 삭제 구현 PR 있음. 처리방침은 법률 검토 전 초안 |
| 처리방침 내용 | 브라우저 저장 설명에 찜·방문 기록이 없음 | 내용 맞추기 필요 |

## 3. 데이터 수집

| 자료 | 쟁점 | 할 일 |
|---|---|---|
| 홈페이지·인스타 링크, 대표사진 주소 (네이버 기반 팀 수집) | 형사 무죄 판례가 있어도 민사 책임은 별개 (2021도1533, 서울고법 2021나2034740) [7] | 수집 방법·약관 확인. 원본 엑셀은 저장소에 올리지 않음 |
| 방문자·블로그 리뷰 사진 | 영수증 등 개인정보, 올린 사람 동의 없음, 치료경험담 유형 | **쓰지 않기로 함** (표본 12장 중 영수증 2장 확인) |

## 미확인

- 제3자 플랫폼에 제56조 제1항을 적용한 판례·유권해석
- 다국어 정보 제공의 유치사업자 등록 필요 여부 (기관 질의 회신 전)
- 네이버 사진 주소를 직접 불러 쓰는 것의 약관·저작권 판단
- 기관 수 5곳 기준의 법적 근거 (팀이 정한 값)
