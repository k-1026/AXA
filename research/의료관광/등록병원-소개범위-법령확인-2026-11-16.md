# 유치의료기관 등록 병원만 소개할 수 있나 — 법령 원문 확인 (2026-11-16)

> **법률 자문이 아니다.** law.go.kr 현행 원문을 직접 열어 팀 설계와 대조한 1차 확인
> 질문: 메디대구는 유치의료기관으로 등록된 병원만 소개할 수 있나? 미등록 병원도 목록에 보여 줘도 되나?

## 1. 결론

| 하는 일 | 팀 설계 | 원문 확인 결과 |
|---|---|---|
| 상담 예약 요청 연결·조건 맞춤 제안 (진료계약 소개·알선) | **등록 병원만** | ✅ **맞음, 오히려 더 강함.** 유치사업자가 미등록 의료기관에 진료계약을 소개·알선하면 **등록 취소 사유**로 명시 (해외진출법 제24조 제1항 제3호). 병원도 외국인환자를 유치하려면 등록해야 함 (제6조 제1항) |
| 병원 목록·지도·상세 열람 (공공데이터) | 전체 병원 표시 | ⚠️ **조문만으로는 판단 불가.** "외국인환자 유치" 정의에 **"외국인환자에 대한 진료정보 제공"**이 들어 있음 (제2조 제3호). 정보를 주는 것만으로 미등록 병원을 "유치"한 것으로 볼 여지가 있음. 복지부 해석·판례는 찾지 못함 → **미확인** |
| 외국인 대상 광고 | 의료기관 광고 X | ✅ 외국어 의료광고 특례는 **유치의료기관만**, 정해진 장소(면세점·국제공항·무역항·지정 관광특구)에서 사전 심의를 받아야 함 (제15조). 그 밖에는 외국인환자 유치 목적 국내광고 금지 (의료법 제56조 제2항 제12호) |

## 2. 원문 요지

| 조문 | 요지 |
|---|---|
| 해외진출법 제2조 제2호 | 외국인환자 = 건강보험 가입자·피부양자가 아닌 외국인 (복지부령이 정하는 국내 거주 외국인 제외) |
| 같은 법 제2조 제3호 | 외국인환자 유치 = 국내 의료기관 이용을 늘리려고 하는 **진료예약·계약 체결 및 그 대리, 진료정보 제공, 교통·숙박 안내 등 진료 관련 편의 제공** 활동 |
| 같은 법 제6조 제1항 | 외국인환자를 유치하려는 **의료기관**은 등록: 진료과목별 전문의 1명 이상, 의료사고배상책임보험(또는 공제) |
| 같은 법 제6조 제2항 | 의료기관이 아닌 자(유치사업자)는 등록: 보증보험, 자본금, 국내 사무소. 유효기간 3년 (제6항) |
| 같은 법 제11조 제2항 (2025-11-11 신설) | 유치의료기관은 실적 보고 때 **유치사업자의 소개·알선 여부**를 포함할 수 있음 |
| 같은 법 제23조 | 등록하지 않으면 "유치의료기관"·"유치사업자" 또는 유사 명칭 사용 금지 (제31조: 500만 원 이하 과태료) |
| 같은 법 **제24조 제1항 제3호** | 유치사업자가 **유치의료기관이 아닌 의료기관**에 외국인환자와의 진료계약을 **소개·알선**한 경우 → 등록 취소 가능 |
| 같은 법 제24조 제1항 제4호 | 유치의료기관이 **유치사업자가 아닌 자**에게서 소개·알선을 받은 경우 → 등록 취소 가능 |
| 같은 법 제28조 | 등록 없이 외국인환자를 유치하면 3년 이하 징역 또는 3천만 원 이하 벌금 |
| 의료법 제27조 제3항 | 영리 목적으로 환자를 소개·알선·유인하는 행위 금지. 예외 제2호: 건강보험 가입자·피부양자가 아닌 외국인(국내 거주자 제외) 환자를 유치하기 위한 행위 |

## 3. 우리 설계에 주는 영향

1. **요청서·제안은 등록 병원만** — `compliance.md` 2-1·`agent-spec.md` 그대로 맞음. 서버에서 막고 테스트로 확인 (`backend-A-hospital` → 요청서 API)
2. **목록은 전체 표시 + 등록 여부 필터** — 지금 설계 유지. 다만 제2조 제3호 때문에 위험이 남으므로 `is_registered_facility` 필터를 서버에 두어, 회신에 따라 "등록 병원만 노출"로 바로 바꿀 수 있게 함
3. 제24조 제1항 제4호의 거울 규정: 등록 병원도 **미등록 플랫폼**의 소개를 받으면 등록 취소 위험 → 등록 전 시연에서 실제 병원에 요청이 가면 **병원 쪽도 위험**. `compliance.md` 2-6(공개 환경 제출 차단)의 근거로 추가
4. 질의서에 넣을 질문: "공공데이터 기반 다국어 병원 정보 열람(예약·제안 없음)이 제2조 제3호의 '진료정보 제공'에 해당하는가, 미등록 의료기관을 목록에 포함해도 되는가" (기존 질의 1과 묶어 확인)

## 3-1. 최신 브랜치 대조 (2026-11-16, `frontend` 2a8e2d7 · `research-data` 0408249)

| 확인 | 결과 |
|---|---|
| `frontend` 새 커밋 2a8e2d7 "병원 정보 카드에 상담하기·예약하기 버튼, 달력 예약 페이지" | ⚠️ **모든 병원 카드**(`HospitalCard.tsx`)에 "상담하기"·"예약하기"가 붙음. 프론트 병원 데이터(`hospitals.json`, 1,267곳)에는 **등록 여부 칸이 없어** 등록 병원만 거를 수 없음 → 1절 첫 줄(제24조 제1항 제3호)과 충돌 |
| 예약 페이지 `reserve/:id` | 로그인은 필요(`RequireLogin`). **국내 거주 확인·동의 화면 없음** (`compliance.md` 2-2·2-4). 제출은 브라우저 저장만(`useConsultThreads`) → 실제 병원으로 가지는 않음 |
| 예약 가능 시간 | 진료시간 안에서 30분 단위로 만든 **예시 일정**을 실제 병원 이름 위에 표시. 화면에 "예시" 문구는 있음. 팀 기준 "실제 병원에 가짜 제휴·가격을 붙이지 않음"과 같은 성격이라 시연 때 오해 위험 |
| `research-data` 새 커밋 (VOC 검수 2~6차) | 이 질문과 관련 없음 |

→ 프론트 담당에게 넘길 것: ① 버튼은 `is_registered_facility = true` 병원에만 (백엔드 `GET /hospitals`가 이 칸을 주면 연결) ② 예약 페이지에 거주 확인·동의 4개 ③ 예시 일정은 가상 병원(`is_demo`)에만, 실제 병원은 "예약 가능 시간 정보 없음"

## 4. 교차검증

- 1절 첫 줄(등록 병원만 소개): 법 원문 제6조·제24조 + 언론 [3]("의료기관은 합법적인 등록업체와만 거래") — 언론은 의료기관 쪽 방향만 확인, 유치사업자 → 미등록 병원 방향은 **원문 1개만** 확인
