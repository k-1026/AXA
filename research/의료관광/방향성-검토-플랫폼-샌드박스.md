## 한 줄 결론

방향(대구 병원 ↔ 외국인 환자 연결 + 병원 대시보드)은 정책 흐름과 맞다. 다만 **"중개수수료 + 예약 연결"을 고르면 유치사업자 등록은 선택이 아니라 전제**다. 샌드박스는 등록을 피하는 수단으로 쓰기 어렵다. 먼저 **신속확인(30일, 미회신 시 허가 불필요로 간주)**으로 유치 해당 여부를 확정하는 데 쓰는 것이 가장 실익이 크다.

## 3. 수정된 방향 문장 (제안)

> 메디대구는 **유치의료기관으로 등록된 대구 병원**과 **단기 방문 외국인 환자**를 연결하는 AI 플랫폼이다. 상담 예약 연결은 **등록 유치사업자와 제휴**해 합법 범위에서 운영하고, 병원에는 공개 데이터 + 플랫폼 데이터 기반 대시보드를 구독으로 제공한다. 서비스의 법적 성격은 **규제샌드박스 신속확인**으로 확정하고, 귀국 후 사후관리는 **2027-05-27 외국인환자 비대면진료 시행**에 맞춰 병원 도구로 연다.

| 1 | **단계로 나눠 적기**: ① 지금(정보 + 상담 요청, 수수료 X) → ② 등록·제휴 후(상담 예약 연결 + 상한 내 수수료) → ③ 2027-05-27 이후(사후관리 비대면 소통) | [../../subject/plan.md](../../subject/plan.md) 5절은 "수수료 X·사후관리 X"인데 새 방향은 둘 다 넣음 → 단계 없이 적으면 문서끼리 모순 |
| 2 | **해석과 원문을 구분**: 조문 = 확인됨, "유치 해당 여부"·"중개매체 해당 여부" = 우리 해석 + 질의 중 | 질의 회신 전이라 확정처럼 쓰면 발표 질문에 약함 |
| 3 | **시연 화면에 반영되는 것은 바로 반영**: 국내 거주 분기(#3), 채팅 "진료 상담 아님" 고지(#4·#11), 입점 = 등록 병원(#6) | 이것들은 나중 단계가 아니라 지금 시나리오 화면에 보이는 부분 |

- 발표에는 1장 요약(단계 그림 + 신속확인 계획)만, 조문·표는 부록으로

### 팀 방향 (2026-11-09): "등록·제휴 후" 기준으로 만들고 발표, 실제 서비스 때 규제 대응을 덧붙임

**판단: 좋다.** 수익모델(중개수수료)과 상담 예약 기능이 이 전제에서만 성립하므로 일관됨. 단 아래 구분을 지켜야 함

| 구분 | 항목 | 발표에서 |
|---|---|---|
| **등록·제휴로 풀리는 것** | #1 유치 활동(상담 예약 연결), #2 수수료 수취 | 첫 장에 **전제 명시**: "메디대구 = 등록 유치사업자(또는 등록 사업자 제휴) 가정" |
| **등록해도 안 풀리는 것** | #2 수수료 상한(의원 30% 등), #3 국내 거주 외국인 유치 금지, #4 2027-05-27 전 환자 직접 의료 상담, #5 민감정보 별도 동의·국외 이전, #6 등록 안 된 병원 입점, #7 국내 광고 금지, #11 중개매체 추천·대가 금지 | **시연 화면에서 이미 지키는 모습**으로 보여줌 (가입 분기, 동의 화면, "진료 상담 아님" 고지, 등록 병원만 입점, 수수료율 상한 표시) |
| **실제 서비스 때 해결** | 등록 요건(자본금·보증보험 1억 이상, 사무소), 신속확인 회신, 실제 개인정보 처리(위탁 계약·국내 서버), 2027-05 이후 비대면진료 연동 | 마지막 장 **"실제 서비스화 시 과제"** 표로 덧붙임 |

- 주의: "등록하면 다 된다"로 들리지 않게. 등록해도 남는 규칙을 **시연에서 지키고 있다**는 것이 핵심 강점
- 사후관리 채팅은 시연에서 **비의료 문의만** 보여주고, 의료 상담은 "2027-05 이후 확장"으로 표기

- 의료법 제34조의2 제2항 제1호(대면 진료 기록 있는 환자)를 귀국한 외국인에게 적용할 수 있는지 → **미확인**
- 등록 유치사업자와의 수익 배분이 제7조(명의 대여 금지)·제9조와 충돌하는지 → 민원 ⑥ 질의 13
- 강남언니 대법원 판단 → **미확인**

## 5. 등록 유치사업자면 챗봇이 병원 추천·의료 판단을 해도 되는가 (2026-11-10 확인)

> 질문: "유치 기관이라고 보면 규제가 풀려서 병원 추천도, 의료 판단도 해 줘도 되는 것 아닌가"
> 결론: **병원 추천은 가능(조건 있음), 의료 판단은 등록해도 불가**

| 항목 | 판단 | 근거 |
|---|---|---|
| **병원 추천·소개** | **가능** (등록 유치사업자, 단기 방문 외국인 대상) | 의료법 제27조 제3항 제2호가 외국인환자 유치를 위한 소개·알선·유인을 예외로 허용 [3]. "유치"에 진료정보 제공·예약 대리 포함 (해외진출법 제2조 제3호), 의료기관 아닌 자는 등록 후 가능 (제6조 제2항) [1]. 변호사 기고도 "등록 유치사업자는 해외 환자를 합법적으로 소개·알선 가능"으로 설명 [15] |
| **진단, 시술 적합성·효과·부작용 판단, 약 안내** | **불가** (등록과 무관) | 의료법 제27조 제1항 "의료인이 아니면 누구든지 의료행위를 할 수 없으며" [3]. 유치사업자 등록이 풀어 주는 것은 제3항(알선)뿐, 제1항(무면허 의료행위)은 그대로 |
| 최근 풀린 것 | **유치의료기관 소속 의사**의 외국인환자 비대면진료 (상담·진단·처방) | 해외진출법 제16조의2, 2027-05-27 시행 [1]. 유치사업자·AI에게 허용된 것이 아님 |
| 일반 건강정보 안내 | 가능 범위 있음 (공신력 있는 기관이 감수한 객관적 정보) | 보건복지부 비의료 건강관리서비스 가이드라인 2022 개정 보도 [16]. **현행 가이드라인 원문은 미확인** |

### 추천할 때 지킬 조건

| 조건 | 근거 |
|---|---|

| "최고"·실력 비교·치료 효과 보장·후기 인용·다른 병원 비방 X | 의료법 제56조 제2항 제2·3·4·5·8호(치료경험담, 거짓, 비교, 비방, 과장 광고 금지), 의료인 아닌 자는 의료광고 자체 불가(제1항) [3] → 추천 문구가 광고가 되지 않게 **사실 정보만** (우리 추천에 광고 조항이 적용되는지는 해석 미확인) |

### 서비스 반영 (ai 브랜치)

- 추천 도구 `recommend_hospitals`: 조건(언어·요일·희망 날짜·지역)에 맞는 정도로 최대 3곳 + 이유. 의료 수준 평가 아님을 함께 표시
- 체류 형태를 모르면 먼저 묻고, 국내 거주자에게는 추천 대신 중립 목록
- 안전 검사에서 "추천 요청"을 거절 대상에서 뺌. 의료 판단, 병원 평판·실력 비교 요청은 그대로 거절
