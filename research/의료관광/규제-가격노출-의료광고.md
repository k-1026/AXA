# 규제 Q1. 병원 가격을 모아 보여주는 것이 의료광고인가?

> 작성 2026-10-29 · 담당: 팀원 2 · 근거: 법령 원문 [1][2], 대법원 판례 [3][4][5]
> 결론 등급: **조건부 가능** (아래 조건을 지킬 때). 우리 서비스에 딱 맞는 판례·유권해석은 **찾지 못함**

## 한 줄 결론

우리는 의료인이 아니라서 **의료광고 자체를 할 수 없다**(의료법 제56조 제1항). 그래서 서비스가 "광고"로 보이지 않게 **공공데이터를 중립적으로 전달하는 정보 서비스**로 설계해야 한다. 병원에서 돈을 받는 순간 광고, 더 나아가 환자 알선으로 바뀔 수 있다.

## 1. 법령 원문 확인

### 의료법 제56조 제1항 — 의료인 아닌 자의 의료광고 금지 [1]
- 의료인등(의료기관 개설자·의료기관의 장·의료인)이 **아닌 자는** 의료광고를 하지 못한다.
- "의료광고" 정의: 의료인등이 신문·인터넷 등으로 "의료행위, 의료기관 및 의료인등에 대한 정보를 소비자에게 나타내거나 알리는 행위"
- 위반 시: 1년 이하 징역 또는 1천만원 이하 벌금 (제89조 제1호) [1]
- 쟁점: 정의 문장의 주어가 "의료인등"이라, **제3자가 공공 정보를 중립적으로 보여주는 행위가 여기에 들어가는지는 조문만으로 확정되지 않음** → 판례·해석 미확인

### 의료법 제56조 제2항 — 의료인등에게 금지된 광고 내용 (우리 화면 설계 기준으로 활용) [1]
우리에게 직접 적용되는 조항은 아니지만, 이 내용을 화면에 담으면 "광고처럼 보일" 위험이 커진다.

| 호 | 금지 내용 | 우리 서비스에서 피할 것 |
|---|---|---|
| 2 | 치료경험담 등 치료 효과 오인 우려 | 후기·전후 사진 노출 |
| 4 | 다른 의료인등과 비교 | "○○보다 싸다", 병원 간 우열 표현 |
| 8 | 객관적 사실 과장 | "최저가", "최고" 같은 수식어 |
| 12 | 외국인환자 유치를 위한 **국내광고** | (Q2 노트 참고) |
| 13 | 비급여 할인·면제를 속이거나 오인하게 하는 광고 | 이벤트 할인가·정가 대비 할인율 노출 |
| 14 | 인증·추천을 받았다는 표현 (공공기관 인증 등은 예외) | 자체 "추천 병원" 배지 |

시행령 제23조 제1항이 각 호를 더 구체적으로 정함 (예: 13호 → 할인 금액·대상·기간·할인 전 가격을 허위·불명확하게 표시) [2]

### 의료법 제57조 — 사전 심의 대상 매체 [1][2]
- 의료인등이 광고할 때 심의를 받아야 하는 매체에 "대통령령으로 정하는 인터넷 매체(앱 포함)"가 있음
- 시행령 제24조 제1항 제4호: **전년도 말 기준 직전 3개월 일평균 이용자 10만명 이상**인 정보통신서비스 제공자의 매체 [2]
- 심의 없이 실어도 되는 항목(제57조 제3항, 시행령 제24조 제7항): 의료기관 명칭·소재지·전화번호, 진료과목, 소속 의료인 성명·성별·면허 종류, **진료일·진료시간**, 홈페이지 주소, 전문병원 지정·의료기관 인증 사실, 전문의 자격 [1][2]
- 시사점: 병원 기본정보·진료시간은 법이 "심의 없이도 알려도 되는 사실 정보"로 분류. **가격은 이 목록에 없음** → 가격 표시는 더 조심

### 의료법 제45조·제45조의2 — 비급여 가격은 공개 대상 [1]
- 병원은 비급여 진료비용을 환자가 쉽게 알 수 있게 고지해야 함 (제45조 제1항)
- 보건복지부장관은 비급여 현황을 조사·분석해 공개할 수 있고, **병원급은 공개해야 함** (제45조의2 제2항)
- 시사점: 심평원 비급여 데이터는 **국가가 국민 선택을 돕기 위해 공개하는 정보**. 이걸 출처와 기준일을 밝혀 그대로 보여주는 것은 광고보다 "공공정보 전달"에 가깝다는 논리를 세울 수 있음 (단, 이 논리를 직접 인정한 판례·해석은 미확인)

- 보건복지부 의료광고 가이드라인(사례집)은 존재 확인 [6], 본문 플랫폼 관련 부분은 **미확인** (PDF 본문 추출 실패)

## 3. 서비스 반영 (설계 조건)

| 조건 | 이유 |
|---|---|
| **병원에서 어떤 돈도 받지 않는다** (입점비·광고비·성과 수수료 모두) | 2018도20928 / 2021도10046 — 대가가 생기면 광고·알선 판단으로 넘어감 |
| 가격은 **심평원 공개 데이터 그대로**, 항목명·금액·**기준일·출처** 표시 | 제45조의2 공개 취지와 연결, 과장·허위 소지 제거 |
| 정렬은 거리·이름순 등 **중립 기준**. "추천", "최저가", 순위 배지 없음 | 제56조 제2항 제4·8·14호 유형 회피 |
| **이벤트 할인가·할인율은 싣지 않음** (강남언니 등 크롤링 가격) | 제56조 제2항 제13호 유형, 병원 광고를 대신 실어주는 구조가 됨 |
| 후기·전후 사진 없음 | 제56조 제2항 제2호 유형 |
| 모든 병원을 같은 형식으로 노출 (특정 병원만 상세 페이지 X) | 특정 병원 홍보로 보이지 않게 |
| 화면 하단 고지: "공공데이터 기반 정보이며 광고가 아님, 실제 가격은 병원 확인" | 오인 방지 |

## 3-1. 비교: 강남언니는 이벤트가를 보여주는데 왜 되나?

**핵심: 광고를 하는 "주체"가 다르다.** 강남언니 화면의 가격은 플랫폼이 아니라 **병원(의료인등)이 돈을 내고 올린 광고**다.

| 구분 | 강남언니 | 우리 서비스 |
|---|---|---|
| 가격을 올리는 주체 | 병원 (광고주) | 우리 (제3자) |
| 법적 지위 | 병원 = 의료광고 주체, 플랫폼 = 광고 매체 | 의료인 아님 → 의료광고 자체 불가 (제56조 제1항) |
| 수익 | 병원에서 받는 **성과형 광고비**(이용자가 병원·이벤트 페이지를 열 때 과금)가 매출의 81.13% (2023년) [8] | 병원에서 받지 않음 |
| 이벤트가 책임 | 내용이 거짓·과장이면 **광고한 병원**이 제56조 제2항 위반 | 우리가 올리면 우리가 "광고"한 꼴 |
| 정부 검토 | 2021 규제샌드박스 절차에서 복지부가 앱의 비급여 가격 기재·전후 사진 사용을 합법으로 검토했다고 보도됨 [8] (원문 미확인) | 해당 없음 |

**그래도 처벌받은 적이 있다**: 운영사 대표가 2015.9~2018.11 앱에서 **시술 쿠폰을 팔아** 71개 병원에 환자 9,215명을 알선하고 약 1억 7천만 원 수수료를 받은 혐의로 의료법 위반 유죄, 징역 8월·집행유예 2년 (항소심 유지, 2023.7) [9]. 회사는 2019년 이후 광고 외 수익 모델은 운영하지 않는다고 밝힘 [8].

→ 정리: 강남언니는 **"병원이 광고하고, 플랫폼은 광고비만 받는 매체"** 구조로 바꿔서 운영 중. 쿠폰 판매·알선 수수료 시절에는 유죄였다(2018도20928 쇼핑몰 판례와 같은 논리).
→ 우리가 이벤트가를 보여주려면 병원이 직접 올리게 하고 광고비를 받는 **광고 매체**가 되어야 함 = "공공데이터 기반 중립 정보 서비스"라는 우리 콘셉트와 충돌. 그래서 이벤트가 X 결론 유지.
→ 참고: 성과형(클릭당) 광고비가 "알선 수수료"와 어떻게 다른지에 대한 법원 판단은 **미확인**. 의협은 플랫폼 의료광고 허용에 반대 입장 [8].

## 4. 남은 의문 (판단 불가 → 전문가·기관 확인 필요)

- 공공데이터 가격을 중립적으로 보여주는 제3자 서비스가 제56조 제1항의 "의료광고"인지 → 보건복지부 의료기관정책과 질의 권장
- 서비스가 커져 일평균 이용자 10만명을 넘으면 우리 매체에 병원이 광고할 때 심의 대상 매체가 됨 (우리가 광고를 안 받으면 무관)
- 외국어 화면이 국내에서도 보이는 것이 "외국인환자 유치 국내광고"(제56조 제2항 제12호) 문제와 연결되는지 → Q2 노트
