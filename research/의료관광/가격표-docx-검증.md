# 가격표 docx 검증 (2026-11-02, 11-03 의원급 추가)

> 대상: `data/raw/비급여진료/시술 종류, 가격범위 (비급여 포함).docx` (피부과·성형외과·내과·안과 33개 분류, 확인일 2026-11-02)
> 비교 1: 심평원 비급여 진료비 API 수집본 `data/interim/영업정보/daegu_nonpay_prices.csv` (대구 병원급 224곳, 2026-10-28 수집)
> 비교 2 (11-03 추가): 심평원 누리집 내려받기 `data/raw/비급여진료/대구_비급여진료비_전체.csv` (대구 **의원급 포함 4,003곳·65,305행**, 공개기준 2026-08, 적용시작 2026-09-03~10-28)
> 목적: 진료과·시술별 **최소·최대·평균** 세 값을 만들기 전에 docx가 맞는지, 다른 자료로 채울 수 있는지 확인

## 결론

- docx는 **진료과마다 병원 1곳의 공개가격 예시**(A~F)이고, 상당수가 "~원부터" 또는 "견적 필요" → **docx만으로는 최소·최대·평균을 낼 수 없음**
- 심평원 데이터와 겹치는 항목은 모두 대구 범위 안. 단 출처 병원 값과 직접 대조하면 **갑상선초음파·다초점 인공수정체 2개가 다름** (0절)
- 피부과·성형외과 시술은 **심평원 API·누리집 모두 없음** → 교차검증 불가, 미확인. 안과 라식·라섹·인공수정체는 누리집(의원급)에 있음 → 5절
- docx 출처 병원 5곳은 모두 실제로 있고 영업 중(폐업 교차검증 결과 `verdict=정상`)
- 진료과: 가격은 **피부과·성형외과·내과·안과** 기준으로 정함 (치과 대신 안과, 2026-11-02 결정). 웹 대상 진료과 변경은 프론트 담당과 협의
- 가격 필터 방식(병원을 지도에서 숨기기)은 [가격-표시-방식.md](가격-표시-방식.md)(병원별 가격 비교·필터 = 추천·유인 위험)과 충돌 → **팀과 먼저 상의**, 데이터 검증만 진행

- 인공수정체는 제품마다 값이 크게 달라(30만~500만) "기관별 최저 제품" 하나로 요약하면 실제와 다름 → 제품군별로 나누거나 범위(최소금액~최대금액)로만 보여주는 게 맞음

- 피부과·성형외과 미용 시술은 누리집에도 없음 → 팀원 홈페이지 수집으로만 채움 (남은 일 1)

### 6-2. 엑셀 요약 칸(보톡스 정가 등 14개)을 그대로 쓰면 안 되는 이유

요약 칸은 병원마다 **키워드에 걸린 항목 중 최저가 1개**라서 단위가 섞임
