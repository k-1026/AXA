# 외국인환자 서식집으로 본 병원·유치업자 업무와 AI 자동화 후보

> 작성 2026-11-04 · 근거: KHIDI 「2025 외국인환자 다국어 서식집(국문)」 62쪽 전체 [1] · 쪽 번호는 서식집 기준
> 목적: 의료기관·유치사업자 대상 AI agent BM 기능 구상의 출발점
> 한계: 서식집은 **양식 모음**이라 "무슨 일을 하는지"는 알 수 있지만 **얼마나 자주·오래 걸리는지는 알 수 없음** → 빈도·시간·비용은 전부 **미확인**

## 한 줄 결론

서식 25종을 따라가면 외국인환자 1명당 **같은 환자정보를 15번 넘게 다시 적고, 동의서마다 통역 확인을 받고, 매달 수수료를 손으로 정산**한다.
AI가 맡기 좋은 일은 **입력·변환·계산·안내**(정확히 정해진 규칙이 있는 일)이고, **설명·동의·판단**은 법적으로 사람(의사·통역사)이 해야 한다.

## 3. 판단 기준

자동화 후보는 아래 5가지로 봤다. 점수가 아니라 **서식에 적힌 사실**로만 판단했다.

| 기준 | 질문 | 서식에서 확인하는 방법 |
|---|---|---|
| A. 반복 | 같은 일을 여러 서식·여러 번 하는가 | 같은 칸이 몇 개 서식에 나오는지 셈 |
| B. 규칙 | 정답이 정해져 있는가 (계산·기한·구간) | 숫자·기한·조건이 서식에 명시됐는지 |
| C. 다국어 | 외국어로 바꿔야 하는가 | "이해할 수 있는 언어로" 문구, 통역사 서명란 |
| D. 위험 | 틀리면 의료·법적 문제가 되는가 | 의사·통역사 서명 요구, 법령 근거 조항 |
| E. 사람 필수 | 법·서식이 사람에게 맡겼는가 | "의사가 설명", "통역사 확인", "의사가 체크" |

→ **A·B·C가 높고 D·E가 낮으면 자동화 1순위**, D·E가 높으면 **AI는 초안·보조만**.

### 반복 횟수 (서식에서 직접 셈)

| 반복되는 칸 | 나오는 서식 | 개수 |
|---|---|---|
| 환자정보 블록 (이름·나이·국적·성별·연락처·SNS ID·이메일·여권번호) | 1-2, 1-3, 1-4, 1-5, 1-7, 1-8, 1-9, 1-10, 1-11, 1-12, 1-13, 2-1, 2-2, 2-3, 2-4 | **15** |
| "환자가 이해할 수 있는 언어로 정확히 통역했음" 통역사 서명 | 1-3, 1-4, 1-5, 1-7, 1-8, 1-9, 1-10, 1-11 (+1-13 통역사 서명, 1-12 통역 여부) | **8 (+2)** |
| 대리인 서명 사유 체크 (미성년·후견·위임 등) | 1-4, 1-7, 1-9, 1-10, 1-11 | **5** |
| 통역 필요 여부·언어 선택 | 2-1, 2-2, 2-3 | **3** |
| 수수료율·총진료비·수수료 표 | 3-2, 3-3 (+3-1, 4-3 조항) | **2 (+2)** |

### 우선순위 제안 (BM 관점)

1. **#8 정산·수수료 자동화** — 규칙이 가장 명확하고 병원·유치업자 **양쪽이 매달** 하는 일. 상한 초과 경고는 법령(통합고시) 근거가 서식에 적혀 있음 (p.57)
2. **#1 + #4 + #5 서식 자동 채움·견적·예약 확정** — 환자정보 15회 반복을 1회로. 계산 규칙이 서식에 다 있음
3. **#2 + #6 다국어 상담·안내** — 우리 서비스(다국어 병원 안내)와 바로 이어짐

## 5. AI가 하면 안 되는 것 (서식이 정한 경계)

| 경계 | 근거 | 쪽 |
|---|---|---|
| 수술·시술 설명은 **해당 수술에 참여하는 의사**가 해야 함 | 1-4 "설명 의사는 반드시 해당 수술(시술)에 참여하는 의료진" | 12 |
| 통역이 정확했는지는 **통역사가 서명**으로 보증 | 1-3·1-4 등 8개 서식 통역사 서명란 | 9–31 |
| 번역본과 다르면 **한국어 원본이 우선** → AI 번역은 원문 병기 필수 | 1-4, 1-7 안내사항 | 13, 22 |
| 치료 거부 시 **의사결정능력은 의사가 확인·체크** | 1-7 | 21 |
| 화상상담은 **양측 사전 동의 없이 녹화·캡처 금지** → AI 녹취·요약도 동의 필요 | 1-13 | 34 |
| 건강정보는 **민감정보 별도 동의**, 해외 이전은 **국외 이전 별도 동의** | 4-1 | 51, 53 |
| 환자는 **자동화된 결정에 이의제기·설명 요구권**을 가짐 (개인정보보호법 제37조의2) → AI가 결정하면 설명 가능해야 함 | 4-1 | 52 |
| 진료기록 10년, 진료비 기록 5년 보존 → AI 생성 문서도 보존 대상일 수 있음 | 4-1 | 52 |

추가로 우리 기존 검토와 연결: **건당·환자당 수수료로 돈을 받으면 유치업(등록 필요)**, 병원용 도구로 **고정 이용료**면 가능성 높음 ([규제 Q4](규제-예약에이전트-B2B.md), [수익 모델 선택지](비즈니스모델-선택지.md)).
