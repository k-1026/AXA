## 1. 병원 국제진료센터 — 배경지식 (주석용)

| 구분 | 국제진료센터 (병원 안) | 유치업체 (병원 밖) |
|---|---|---|
| 정체 | 등록 유치의료기관 **내부 부서**. 외국인 환자 전담 코디네이터·통역·행정 인력 | 복지부에 **유치업자로 등록**한 외부 회사. 진료는 안 하고 환자를 병원에 연결 [4] |
| 하는 일 | 상담·예약, 진료 동행(코디네이터), 통역, 전문의 연결, 보험 상담·청구 대행, 비자용 서류 발급 [1][2] | 환자 모집·상담, 병원 예약 대리, 통역·숙박·교통 등 부가 서비스, 병원과 월 정산 (서식집) |
| 돈 | 병원 매출 (진료비) | 병원에서 받는 유치 수수료 (고시 상한 안) |
| 메디대구와의 관계 | **대시보드의 1차 사용자**. 상담 예약 요청을 받고 확정하는 사람 | 직접 유치업자 방식이면 **경쟁 상대** |

- 대형병원(대학·상급종합)은 국제진료센터를 두는 경우가 많고, 피부·성형 **의원급은 별도 센터 없이 상담실장·코디네이터 1~2명이 겸하는 경우가 많다** [I] [U] — 병원 인터뷰로 확인 필요
- 대구 예: 계명대 동산의료원 영문 사이트에 의료비자 안내 페이지가 있음 [6] → 상급종합은 국제진료센터가 비자 서류까지 직접 처리 [I]
- 유치기관 평가·지정제 기준에 다국어 상담·통역·교통·숙박 연계가 포함된다는 보도 [3]

**메디대구에 주는 의미 [I]**
- 이 특례는 **병원이 특구 안에서 하는 옥외 광고**에 대한 것. 메디대구 같은 **온라인 플랫폼 광고에는 바로 적용되지 않음** [U]
- 온라인에서 **해외 거주 외국인 대상** 광고는 의료법 제56조 제2항 제12호의 "국내광고" 금지와 별개 → 기존 노트(규제-가격노출-의료광고.md) 판단 유지
- 활용 아이디어: 동성로 등 특구 안 병원 옥외 광고에 **메디대구 QR**을 넣는 제휴 → 초기 유입 경로 후보 [I]
- 남은 [U]: 특구 지정 고시 원문, 시행령 조문 원문, 대구 특구의 정확한 구역 경계

## 4. 비자 서류 처리 과정 (참고용 — 팀 결정으로 메디대구 범위에서 제외)

| 누가 | 무엇을 | 근거 |
|---|---|---|
| **환자** | 여권·사진·신청서·수수료, 진료비 지불 능력 증명, 병원이 발급한 **진료 예약 확인서**(방문 목적 증명) | 외교부·지자체 의료관광 안내 [16][17] |
| **등록 유치의료기관·유치업자 (초청자)** | 사증발급인정서 신청서, 초청 사유서, 사업자등록증 사본 — 법무부 비자포털로 사증발급인정서 신청 | 메디컬코리아 안내 [18] |
| **우수 유치기관** | 법무부 지정 시 비자 절차 간소화. 지정 기준: 사업 개시 1년 이상 + C-3-3·G-1-10 초청 50건 이상 또는 유치 500건 이상 | 법무부 자료 [19] |
| 비자 종류 | C-3-3 단기 의료관광(90일 이하), G-1-10 치료 요양(91일 이상, 최대 1년) | 외교부 [16] |

- **의사소견서**: 공식 자료에서 C-3-3 필수 서류로 확인 못 함 → [U]. 장기(G-1-10)나 체류 연장 때 요구된다는 블로그 자료는 있지만 등급 낮음
- 서류는 제출 전 3개월 안 발급분이어야 함 (외교부) [16]
- **메디대구 관점**: 상담 예약 확정 → 병원이 예약 확인서 발급. 메디대구는 비자에 **관여하지 않음** (팀 결정 11/12)

|---|---|---|---|

| 2 | 공개·고지 항목 | 이전 항목, 국가, 시기·방법, 받는 자, 목적, 보유·이용 기간, 거부 방법 | 해설 [20] |
| 3 | 건강정보 = 민감정보 | 이전 근거와 **별개로** 민감정보 처리 별도 동의 (제23조) | 기존 노트 규제-예약요청-캘린더.md [3] |
| 4 | 학습 재사용 | API 입력이 모델 학습에 쓰이지 않는 조건(데이터 미보관·학습 제외 옵션) 확인 필요 | 언론 기고 [22] |
| 5 | 2026-09 개정 | AI 개발용 개인정보 처리 특례 신설, 2027-03 무렵 시행 — 이 특례 적용 시 국외 처리위탁 제한 가능 | 로펌 해설 [20] |

**메디대구 설계 제안 [I]**
- 가입 시 **동의 3개 분리**: 서비스 이용(필수) · 건강정보 처리(상담 예약 시) · 국외 이전(해외 LLM 사용 시, 국가·업체 명시)
- LLM에는 **이름·연락처·여권번호를 보내지 않음** (가명 처리 후 전송), 대시보드는 비식별 집계만
- 사후관리 대화 요약은 병원 데이터 → **병원이 처리 주체, 메디대구는 수탁자** 구조로 계약
