# 대구 병원 폐업·미존재 교차검증 (2026-11-02)

## 결론

- 심평원 대구 목록 **4,242곳(10-28) → 4,232곳(11-02)**. 5일 사이 **10곳이 빠짐**, 새로 생긴 곳 0곳
- 빠진 10곳 = **폐업 후보**. 이 중 **7곳이 웹 대상(4개 진료과)** 이라 지금 화면에 나오고 있음
- 행정안전부 인허가(독립 출처)와 대조한 판정: **정상 4,211 · 폐업 9 · 미확인 22**
  - **폐업 9곳**: 심평원에서 빠짐 + 행안부 영업상태 '폐업' (모두 이름+주소 일치). 웹 대상 6곳(내과 2, 치과 4)
  - **미확인 22곳**: 행안부 '휴업' 13 · 행안부 매칭 안 됨 7 · '제외/삭제/전출' 1 · 출처끼리 엇갈림 1(송현내과의원)
  - 휴업 13곳은 국립중앙의료원 병·의원 찾기에서도 모두 안 나옴 → 지금 진료하지 않을 가능성 높음 (같은 방향 출처 2개지만 '휴업'이라 폐업으로 판정하지 않음)
  - 매칭 안 된 7곳 중 6곳은 부속의원·보건소(대학·교도소·소년원·회사 등 내부용), 1곳은 군위군 한의원(국립중앙의료원에는 있음)
- 송현내과의원: 심평원 11-02 목록에서 빠졌지만 행안부는 같은 주소에 '영업/정상' 1건과 '폐업(2026-08-04)' 1건이 함께 있고, 국립중앙의료원 병·의원 찾기에는 아직 나옴 → 직접 확인 필요

## 방법

1. **기준**: `raw/영업정보/daegu_hospitals.json` (심평원 `getHospBasisList`, 2026-10-28). 키 `ykiho`, 이름 `yadmNm`, 주소 `addr`, 개설일 `estbDd`, 좌표 `XPos/YPos`
2. **출처 A — 심평원 최신 재조회** (11-02): `ykiho`로 대조. 없으면 폐업 후보. 이름·주소·전화 바뀐 곳도 표시
   - 심평원은 폐업 신고가 들어오면 목록에서 뺌. 단 휴업·자진 미신고는 반영 늦음 → 같은 기관 데이터라 **단독으로 판정하지 않음**
3. **출처 B — 행정안전부 건강_병원·건강_의원 조회서비스** (지자체 인허가, 영업상태·인허가일자, 일간 갱신·약 2일 전 기준 → 아래 '갱신 주기')
   - 심평원(건강보험 청구)과 다른 계통(지자체 개설 신고·허가) → 독립 출처
   - `ykiho`가 없어서 **이름 + 도로명주소**로 매칭
4. **출처 C — 직접 확인** (빈칸만): 폐업 후보만 전화·지도·병원 홈페이지로 확인, 칸마다 출처·확인일
5. **판정**: 출처 2개 이상이 같은 방향이면 정상/폐업, 아니면 **미확인**

## 갱신 주기와 기준 시점

| 출처 | 포털 '업데이트 주기' | 실제 데이터로 확인한 것 |
|---|---|---|
| 심평원 병원정보서비스 | 실시간 | 10-28 → 11-02 사이 10곳 빠짐 → 자주 바뀜 |
| 행안부 건강_병원·건강_의원 | 일간 | 11-02 수집본의 최신 `DAT_UPDT_PNT`(데이터 갱신 시점) = **10-31**, 최신 `LAST_MDFCN_PNT`(최종 수정) = 10-30 (병원·의원 같음) → 매일 갱신, 내용은 **약 2일 전 기준** |

- "2일 간격"이 아니라 **매일 갱신 + 2일 지연**. 포털 페이지에서 "2일 전 기준" 문구는 직접 찾지 못했고, 위 갱신 시점 필드로 확인함
- 영향: 폐업 직후 1~2일은 심평원·행안부가 엇갈려 '미확인'이 될 수 있음 → 웹에서 숨겨지므로 문제 없음, 며칠 뒤 다시 돌리면 확정
  - 실제로 폐업 9곳 중 4곳은 폐업일이 10-29~10-31인데 11-02 행안부에 이미 반영돼 있었음
- 실행 주기(권장): 평소 주 1회, 발표·시연 2~3일 전 1회 + 전날 1회

## 표본 점검 (판정이 맞는지 확인)

- 대상: '정상' 중 무작위 30곳(시드 20261102, 다시 돌려도 같은 표본) + '폐업' 9곳 전부 = 39곳
- 시트: `data/interim/영업정보/hospital_status_sample.csv` — 곳마다 네이버 지도 검색 링크가 있음
- 방법: 링크를 열어 영업 중 / 폐업·영업종료 표시 / 검색 안 됨을 보고 빈칸을 채움
  - `지도결과`: 영업 / 폐업 / 없음 / 판단불가
  - `출처`: 네이버 지도 (또는 카카오맵·홈페이지 URL), `확인일`: YYYY-MM-DD
  - `일치`: 판정과 같으면 Y, 다르면 N, 판단불가면 비움
- 채운 뒤 `.venv/Scripts/python.exe data/etl/sample_hospital_status.py` 다시 실행하면 "확인 N곳 중 일치 M곳"이 나옴 (채운 칸은 유지)
- 지도는 사용자 제보 기반(등급: 개인)이라 판정을 바꾸는 근거가 아니라 **방법이 맞는지 보는 점검용**. 불일치가 나오면 그 병원만 따로 원인 확인
- 결과: 미확인 (아직 점검 전)

2. 이 기준이면 웹에서 빠지는 곳: 폐업 6곳 + 미확인 8곳 (4개 진료과 기준)
