2. 정렬 기준: 약관 "진료과·거리·지원 언어·우수유치기관 여부" / 법령 안내·compliance "거리·가나다순만" / 실제 "이름·거리"
3. 노출 대상: 약관 "등록 유치의료기관만" / 법령 안내 "요청 기능만 등록 기관, 목록은 전체"
4. 챗봇 제안 조건: 문서마다 다름. 실제(언어·요일·시간, 최대 3곳, 비거주자만)는 어디에도 없음
5. 수수료: `compliance.md` "하지 않는다: 건당 수수료" vs README 4절·AI 안내 "건당 중개수수료"
6. "추천" 용어 혼용 (compliance.md 안에서도 "하지 않는다: 추천"과 "병원 추천은…"이 같이 있음)
7. 사후관리: compliance "하지 않는다: 사후관리 Q&A" vs README·서비스 "비의료 주제 사후관리 채팅"
8. 광고 게재 사실이 약관에 없음
9. `terms.ts:1` 주석 "번역본 없음" — 실제로는 번역 파일 있음 (번역도 옛 약관 기준이라 약관을 고치면 다시 번역)

## 5. 바로 고친 확정 오류 (2026-11-12, PR #23 `frontend-review-fix`)
팀 결정과 상관없이 사실과 달랐던 문장만 고쳤다. 4개 언어 번역도 같이 바꿨다 (누락 0).

## 4. 변호사·기관 질문

**개인정보 (변호사·개인정보보호위원회)**
- P1. 환자가 고른 병원에 요청서를 보내는 것이 제3자 제공(제17조)인가, 위탁(제26조)인가? (팀 노트 `규제-예약요청-캘린더.md`는 "병원 = 처리자, 우리 = 수탁자"로 봄. 우리 계정·중개수수료 구조에서도 그런가)
- P2. Gemini·NVIDIA LLM API 전송이 처리위탁과 국외 이전에 함께 해당하는가? 근거를 1호(동의)로 할지 3호(계약 이행용 위탁·보관 + 처리방침 공개)로 할지? 건강정보가 섞이면 3호여도 제23조 별도 동의가 필요한가?
- P3. 챗봇 건강정보 별도 동의는 시작 전 1회로 충분한가? 동의하지 않은 이용자가 증상을 쓰면 어떻게 처리해야 하나?
- P4. 외국인 이용자(EU·중국·일본)에게 GDPR·PIPL·APPI가 추가로 적용되는가? 대리인 지정 등 의무가 있는가?
- P5. 계정·요청서 처리 근거를 동의(제15조①1호)로 할지 계약 이행(4호)으로 할지?
- P6. 탈퇴 후 연결을 끊은 동의 기록을 남기는 것이 적법하고, 증명 수단이 되는가?
- P7. 병원이 받은 요청서의 보유기간·파기 책임은 누가 정하고 고지하는가?
- P8. 소상공인 보호책임자 면제(시행령 제32조) 가능 여부, 공개 저장소에 실명 대신 부서·연락처만 써도 되는가?

- M1. 등록 유치사업자의 건당 정액 중개수수료가 의료법 제27조 제3항 예외에 해당하는가? 정액을 고시의 비율 상한과 어떻게 맞추는가?
- M2. 월 입점료가 고시상 "유치 수수료"에 합산되는가?

- M7. 병원 목록 옆 AdSense가 의료광고(제56조①)·유치 국내광고(제56조② 제12호)에 해당하는가?

- M10. 병원 직원이 승인해 보내는 AI 작성 답장도 제31조② 표시 대상인가?
