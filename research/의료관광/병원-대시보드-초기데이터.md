# 병원 계정 대시보드 · 초기에 줄 수 있는 데이터

> 작성 2026-11-12 · 대상: 구매자 D (등록 유치의료기관), 이용자 데이터가 거의 없는 출시 초기
> 표기: **[판단]** = 작성자 판단 · **미확인** = 확인 못 함

## 결론

이용자 데이터가 쌓이기 전에도 3가지는 바로 보여줄 수 있음

1. **시장 데이터** (공공 통계): 대구에 어느 나라 환자가 몇 명 오는지, 어떤 진료과로 오는지, 추이가 어떤지
2. **우리 병원 vs 대구 같은 진료과** (공공 병원 데이터): 정보 완성도, 비급여 가격의 위치, 진료시간
3. **우리 병원 운영 데이터** (병원 자신의 기록): 상담 응답 시간, 예약 전환, 사후관리. 1건부터 의미가 있음

플랫폼 행동 데이터(조회·찜·검색어·언어)는 처음부터 수집하되, 표본이 작을 때는 숨기거나 "표본 적음"으로 표시 **[판단]**

## 2. 우리 병원 vs 대구 같은 진료과 (공공 병원 데이터)

| 보여줄 것 | 예시 위젯 | 출처 | 갱신 | 주의 |
|---|---|---|---|---|
| 정보 완성도 점수 (진료시간·홈페이지·외국어·사진·가격) | "채워진 칸 n/7" + 빠진 칸 바로 입력 | 심평원 API [5], 팀 수집 링크 | 수시 | **병원이 직접 빈칸을 채우게 하는 입구**. 대구 진료시간 채움률 26.1% [6] |
| 진료시간 비교 (야간·토요일·일요일) | 같은 진료과 중 야간 진료 비율 | 심평원 진료시간 [5] | 분기 | 신고 기준, 임시 휴진 반영 X |
| 비급여 가격 위치 | 항목별 대구 최소·중앙·최대 중 우리 병원 위치 | 심평원 비급여 [5], 가공 통계 [7] | 매년 | 병원급만 공개 의무, 의원급은 대부분 없음 [8]. 보톡스·필러 항목 없음 |
| 대구 지역(구)별 같은 진료과 병원 수 | 구별 지도 | 심평원·행안부 [5] | 분기 | 폐업 교차검증 반영 [9] |
| 유치기관 등록·우수기관 제도 | 할 일 체크 (등록, 우수 유치기관 지정 요건) | 법무부 공고 제2026-271호 [10] | 연 1회 | 요건 요약만, 판단은 병원 몫 |

- 다른 **특정 병원**과 1:1로 비교하지 않고 대구 전체 분포(최소·중앙·최대)만 보여줌 **[판단]** — 개별 병원 비교는 의료광고·분쟁 소지

## 3. 우리 병원 운영 데이터 (플랫폼 기록, 1건부터)

| 보여줄 것 | 예시 위젯 | 데이터 생기는 곳 | 주의 |
|---|---|---|---|
| 상담 요청 수·응답 시간 | 평균 첫 답장 시간, 미응답 건 | 상담/예약 페이지 | 페인 포인트 A③·D① [11] 해결 확인 지표 |
| 예약 요청 → 확정 → 방문 완료 | 깔때기 | 예약 관리 페이지 | |
| 환자 국적·언어 | 원 그래프 | 상담 요청 정보 | 5명 미만 칸은 숨김 **[판단]** (개인 특정 방지) |
| 희망 진료·희망 날짜 | 요일·달별 수요 | 예약 요청 | |
| 사후관리 대화 수·응답 | 미응답 알림 | 사후관리 페이지 | 건강정보 → 병원 내부에서만 열람 |

## 4. 플랫폼 행동 데이터 (쌓이면 공개)

| 보여줄 것 | 공개 조건 **[판단]** |
|---|---|
| 우리 병원 상세 조회 수·찜 수 | 월 30회 이상부터 숫자, 그 전에는 "집계 중" |
| 조회한 언어(ko·en·zh·vi) 비율 | 같음 |
| 대구 전체 인기 검색어·시술 카드 조회 | 플랫폼 전체 기준이라 초기에도 가능 |
| 챗봇 질문 주제 (병원명 제외 집계) | 실제 LLM 연결 후, 개인정보 마스킹 시험 후 |
