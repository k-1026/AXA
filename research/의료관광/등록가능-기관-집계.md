### 가격 있는 병원 224곳과 C 등급 124곳의 관계

| 기준 | 기관 수 |
|---|---|
| 심평원 비급여 API에 가격이 있는 대구 병원 | **224** (전부 병원급) |
| └ 그중 진료시간도 있음 = C 등급 | 124 |
| └ 가격은 있지만 진료시간 없음 | 100 |
| 대구 병원급 전체 (병원·요양병원·한방병원·정신병원·종합병원·치과병원·상급종합) | 229 → 가격 있음 224 |
| 대구 의원급 전체 (의원·치과의원·한의원) | 3,971 → 가격 있음 **0** |

- 이유: 의료법 제45조의2 제2항 — 복지부는 비급여 현황을 공개할 수 있고, **병원급은 공개 의무**. 의원급은 의무 아님
- 원자료: `data/raw/영업정보/daegu_nonpay_prices.json` (15,940행), 가공본 `data/interim/영업정보/daegu_nonpay_prices.csv`

### C 등급(가격) 내용 주의

- 가격이 있는 병원 224곳 중 **223곳은 제증명수수료**(진단서 등)가 포함됨. 진단서·병실료 말고 **진료 항목 가격이 있는 곳은 208곳**, 그중 진료시간(API)까지 있는 곳 112곳
- 많이 나오는 항목: 제증명수수료, 상급병실료, 검체검사, 물리치료(이학요법), 예방접종, 초음파, MRI
- 의료관광과 관련된 항목은 적음: 도수치료 127곳, 신경성형술 39곳, **치과 임플란트(지르코니아) 22곳**, 모발이식 3곳. **보톡스·필러·쌍꺼풀 항목은 없음**
→ C 등급 124곳은 "가격이 있다"이지 "**외국인이 찾는 시술 가격이 있다**"는 아님. 가격 화면은 치과 임플란트·검진(초음파·MRI)·도수치료 위주로만 의미 있음

### 가격 기능 재검토 (2026-10-29 팀 논의)

- **공공 가격은 외국인 가격이 아닐 수 있음**: 외국인환자 = 건강보험 미가입자(해외진출법 제2조 제2호) → 공공 비급여 고지 금액이 그대로 적용되는지 **미확인**
- 법에 있는 단서: 복지부는 유치기관의 **수수료·진료비 부과 실태를 조사해 공개할 수 있음** (해외진출법 제9조 제2항, 시행규칙 제7조의2, 2024-07-10 신설) → 실제 공개 결과가 있는지 찾아볼 것 (**미확인**)
- 강남언니·모두닥 가격으로 채우는 것은 X: 병원이 낸 **광고·이벤트가**(규제 노트 결론), 크롤링 약관 미확인, 그리고 역시 **내국인 대상 가격**
- 대안: 가격 숫자 대신 **"예상 진료비를 서면으로 받을 권리"** 안내 — 유치의료기관은 진료계약서·예상 진료비를 외국인환자에게 안내할 의무 (해외진출법 제8조 제2항 제2호) → 서비스-흐름 5단계 체크리스트와 연결
