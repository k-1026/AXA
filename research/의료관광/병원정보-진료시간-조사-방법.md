- 주말·공휴일 진료: 베리미의원 대구점, 유앤아이의원 대구점 (둘 다 일요일 10:00-16:00)
- 유앤아이의원 홈페이지 팝업에 시술별 이벤트 가격이 있음 → 가격 담당(팀원 2) 참고: 비급여 API에 없는 이벤트 가격의 출처 후보
- 홈페이지에 외국어 상담을 명시한 곳은 없음. 사이트 언어 선택(영·중·베트남·태국·일본 등)만 있는 곳 3곳, 태국어 안내 게시글 1곳
- 사이트 표기 오류 의심 1곳 (MS재건병원 점심 '오전 1시~오후 2시') — 그대로 기록하고 메모

## 1. 대구 병원 목록 받기 — 병원정보서비스 `getHospBasisList`
- 조건: 대구 시도코드, 페이지 단위로 전부 받기
- 저장: 원본 응답은 `research/data/raw/`, 정리본은 `research/data/daegu_hospitals.csv`
- 확인할 것
  - 전체 병원 수, 종별(의원·병원·종합병원 등) 분포
  - 피부과·성형외과 병원 수 (진료과목 기준)
  - **좌표(XPos·YPos)가 위도·경도인지**: 병원 3곳을 지도에서 주소와 비교

## 2. 진료시간·휴무 받기 — 상세정보서비스 `getDtlInfo2.8`
- 전체를 한 번에 하지 말고 **샘플부터**: 중구·수성구 피부과·성형외과
- 병원마다 1번에서 받은 ykiho로 호출
- 확인할 항목과 **채움 비율** (값이 있는 병원 수 / 샘플 수)

| 항목 | 필드 |
|---|---|
| 평일 진료시간 | trmtMonStart ~ trmtFriEnd |
| 토·일 진료시간 | trmtSatStart·End, trmtSunStart·End |
| 점심시간 | lunchWeek, lunchSat |
| 접수시간 | rcvWeek, rcvSat |
| 휴진 안내 | noTrmtSun, noTrmtHoli |

- 같이 받으면 좋은 것: `getDgsbjtInfo2.8`(진료과목·의사 수)

## 3. 정확도 검증 (5곳)
- API 진료시간을 병원 공식 홈페이지와 비교 → 일치 / 불일치 / 홈페이지에 정보 없음
- 지도 앱·블로그는 참고만 (출처 등급 낮음)

## 4. 메디컬코리아 CSV와 매칭
- 메디컬코리아 대구 등록 병원 145곳은 **영문 이름·영문 주소**라 이름 매칭이 어려움
- **전화번호로 매칭** 먼저 시도 (메디컬코리아 전화번호 열 ↔ 심평원 telno), 안 되면 주소
- 결과: 매칭률 (매칭된 병원 수 / 145)

## 5. 산출물

  - 정확도 검증 5곳 결과
