# 메디컬코리아 사이트 기준 대구 병원 노출 현황

> 작성 2026-10-29 · 메디컬코리아(한국보건산업진흥원) 공식 사이트 직접 확인 + 기존 CSV 분석
> 관련: [서비스-흐름-법률검토.md](서비스-흐름-법률검토.md) · [상위-데이터-확장-조사.md](상위-데이터-확장-조사.md)

## 결론

- 메디컬코리아는 우리가 만들려는 서비스와 **성격이 가장 비슷한 공식 사이트**(공공기관, 병원 목록·비자·통역 언어 안내, 광고·예약 대행 없음) → **기준 모델로 삼기 좋음**
- 대구 "1곳"은 **인증 병원(KAHF 유치기관 인증)** 메뉴 기준. **등록된 유치의료기관은 대구에 훨씬 많음**
- 차이는 "대구에 병원이 없다"가 아니라 **"있는데 정보가 비어 있다"** → 우리가 채울 수 있는 부분

## 2. 메디컬코리아에 없는 것 = 우리가 채울 것

| 항목 | 메디컬코리아 | 우리 데이터 |
|---|---|---|
| 병원 상세(의사 수·통역 언어·픽업·인증) | 대구는 **13곳만** [4] | 등록 145곳 전체에 심평원 정보 결합 가능 (병원명·주소로 매칭, 매칭률 **미확인**) |
| 진료시간·휴진일 | **없음** [2][4] | 심평원 API + 직접 채움 (수성구 등록 45곳 전부 확보) |
| 가격 | **없음** [2][4] | 공공 비급여 고지 금액 (병원급만, 미용 시술 코드 없음) |
| 지도 좌표 | 주소(영문)만, 좌표 없음 [4] | 심평원 좌표 |
| 다국어 | 영·중(간체)·일·러 [3] | 대구 급증 국적 기준으로 대만(번체)·베트남어 등 추가 검토 |
| 대구 진입점 | 전국 목록 안의 한 지역 | **대구 전용** |

## 3. 그대로 가져올 점 (법률상 안전한 형태)

- **공공기관 목록 + 등록·인증 사실 표시** — 순위·후기·광고 없음
- 병원 정보는 **사실 항목**(주소·연락처·언어·인증)만, 예약은 병원 국제진료센터로 직접
- 비자 안내는 요약 + 공식 링크 ([서비스-흐름-법률검토.md](서비스-흐름-법률검토.md) 6단계)
- 필터: 지역·진료과·통역 제공 여부 [2]

## 4. 발표에 쓸 문장 (숫자는 위 출처)

> 대구에는 외국인환자 유치 등록 병원이 145곳 있지만(메디컬코리아 데이터), 메디컬코리아에서 상세 정보가 있는 곳은 13곳, 인증 병원은 1곳뿐이고, 진료시간·가격은 어디에도 없다.

## 5. 남은 확인

- 메디컬코리아 등록 병원 145곳 ↔ 심평원 병원 목록 매칭률
- 등록 145곳과 진흥원 통계 163곳(2022), 수성구 47곳의 기준 시점·정의 차이
- 메디컬코리아 데이터 재사용 조건(공공누리 유형) → **미확인**
