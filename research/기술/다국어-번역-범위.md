# i18n만으로 MVP 번역이 되나? (번역 범위 정리)

> 작성 2026-10-30 · 대상: plan.md의 MVP (환자용 정보 웹 + 병원용 대시보드 + 예약 요청 에이전트)
> 데이터 수치: `data/raw/영업정보/` 심평원 JSON (2026-10-28 수집) 직접 집계

## 결론

**i18n만으로는 안 됨.** i18n(react-i18next)은 **코드에 미리 적어 둔 고정 문구**만 바꿔 준다. MVP 내용은 3종류라 방법이 다르다.

| 종류 | 예 | 방법 | i18n으로 되나 |
|---|---|---|---|
| ① 고정 문구 | 버튼, 메뉴, 고지 문구, 동의 화면, 체크리스트, 정해진 값(종별·요일·휴진 상태) | i18n 번역 파일 | **O** |
| ② 데이터 값 (바뀌지만 미리 알 수 있음) | 병원명, 주소, 진료시간 메모, 비급여 항목명 | **미리 한 번 변환·번역해서 데이터에 저장** (+ 사람 검수) | X (데이터 쪽 작업) |
| ③ 실행 중 생기는 글 | 환자가 쓴 요청 내용, 병원 답장, 챗봇 답변 | **실시간 기계 번역(LLM 등)** | X |

## ① 고정 문구 — i18n으로 해결

- 화면 문구, 고지("광고·추천·의료 상담 아님"), 동의 2단계, 문의 전 체크리스트(진단명·부작용·진료계약서·예상 진료비·분쟁 절차)
- **정해진 값은 코드 → 번역 사전**: 의료기관 종별 13개, 시군구 9개, 요일, 진료과목, 휴진 상태(`휴진/진료/응급실만/미확인` 4개로 통일한 뒤)
- 실행 중 API 비용 없음

## ② 데이터 값 — 미리 변환해서 저장 (i18n 아님)

| 항목 | 우리 데이터 상황 | 방법 |
|---|---|---|
| 병원명 4,242개 | 심평원에 외국어명 없음 | 번역하지 않고 **로마자 표기 + 한글 병기** (메디컬코리아 영문명 있으면 우선). 번체·베트남어 화면에도 같은 표기 |
| 주소 | 한글 도로명 | **영문 도로명주소**로 변환해 저장, 번체·베트남어 화면도 영문 주소 (변환 방법·규칙 원문 **미확인**) |
| 진료시간 메모 | 접수시간 문장 485가지, 점심시간 315가지, 공휴일 휴진 180가지 (예: "08시00분~16시30분(과에 따라 조기마감, 예약환자 제외)") | **시간은 숫자로 정규화**(08:00-16:30)해서 화면에서 조립, 괄호 안 설명만 따로 번역 or "한국어 원문 + 병원 확인" 표시 |
| 비급여 항목명 | 대구 데이터에 607개 (병원별 자체 명칭은 11,171개) | 표준 항목명 607개만 **한 번 번역 + 검수**해 사전으로 저장. 병원별 자체 명칭은 번역하지 않음 |
| 직접 채운 진료시간·메모 | 수동 입력 문장 | 시간은 정규화, 메모는 원문 표시 |

→ 의료 용어가 섞여 있어 **기계 번역 후 사람 검수** 필요 (특히 비급여 항목명)

## ③ 실행 중 생기는 글 — 기계 번역 필요

| 항목 | 줄이는 방법 | 그래도 남는 것 |
|---|---|---|
| 예약 요청서 | **선택형 칸 위주**(날짜, 진료과, 언어, 비자 필요 여부, 연락 방법) → 선택값은 i18n으로 병원에 한국어로 보임 | "희망 진료 내용" 자유 입력 → 한국어로 번역해 원문과 함께 표시 |
| 병원 답장 | **정형 답장 템플릿**(확정·거절·다른 시간 제안 + 날짜) → i18n으로 환자 언어로 | 자유 문장 답장 → 환자 언어로 번역 (원문 병기) |
| 챗봇 | 답 생성 자체가 LLM → 선택한 언어로 생성 | 베트남어 품질 테스트 필요 (Nemotron 3 공식 지원 언어 아님) |

- 규제 조건: **원문 그대로 번역, 원문·번역문 병기, "기계 번역" 표시** ([규제-1대1상담.md](../의료관광/규제-1대1상담.md) 3-1절)
- 시연은 가상 데이터라 무료 API 사용 가능, 실제 운영은 국외 이전 동의 필요 (개인정보보호법 제28조의8)

## MVP 언어 3개(영어·번체·베트남어) 기준 작업량

| 작업 | 양 | 담당 영역 |
|---|---|---|
| i18n 번역 파일 | 화면 문구 + 정해진 값 사전 × 3개 언어 | `apps/*/i18n/locales` |
| 데이터 변환 | 병원명 로마자, 영문 주소, 진료시간 정규화 4,242곳 (시연은 대상 병원만 먼저) | `data/etl`, `data/processed` |
| 사전 번역 | 비급여 표준 항목명 607개 × 3개 언어 + 검수 (가격 화면에 쓰는 항목만 먼저) | `data/schemas` |
| 실시간 번역 | 요청서 자유 입력, 병원 자유 답장, 챗봇 | `ai/agent/tools/translate.py`, `ai/chatbot` |
