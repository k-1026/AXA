## 1. 메시지 7줄 (이것만 이어 읽어도 말이 되어야 함)

1. **문제** — 대구에서 시술받고 싶은 대만 환자는 고를 근거가 없다: 등록 병원 161곳 중 상세 정보 7곳, 진료시간 채움 26.1%, 미용 시술 공공 가격 0곳.
2. **해결** — 메디대구는 그 빈칸을 공공데이터 + 출처·확인일로 채워 내 언어로 보여 주고, 챗봇 → 상담 예약 → 병원 AI 답장 초안(코디 승인)까지 한 흐름으로 잇는다.
3. **시장** — 대안 5개 중 "공공 근거 + 예약 연결" 칸이 비어 있고, 첫 시장은 대구 대만 미용·외래 환자 연 약 1,200명이다.
4. **BM** — 병원은 결제된 진료에만 기본 13% (또는 프리미엄 연 180만 원 + 8%)를 내므로 공개된 유치 플랫폼(15~25%)·광고보다 싸고, 손익분기는 기본 회원만으로 월 약 22건(나쁜 경우 46건, 팀 4명 최저임금 포함 시 71건)이다.
5. **MVP** — 린이 챗봇에 묻고 예약 요청 초안까지 가는 흐름이 실제로 돌고, AI 평가는 통과했지만 사람 테스트는 아직이다.
6. **팀** — 데이터에서 프론트 2·백엔드 2로 나뉜 4명이 등록 유치기관 161곳 진료시간 159곳 채움, VOC 941건 검수, 레드팀 21개 지적 처리를 AI와 함께 해 왔다.
7. **요청** — 한국에 있는 외국인 유학생·관광객, 그리고 이 자리에 계신 분들께 사용자 테스트 참여를 부탁드립니다 — 혼자 예약 요청까지 가는지 12/4 전에 판정하겠습니다. (병원 인터뷰·LOI는 받기 어렵다고 보고 11/18 바꿈 → 11/19 "대만 5명 연결"은 누구에게 부탁하는지 불분명해 청중이 바로 할 수 있는 테스트 참여로 바꿈)

**v0 → v1에서 고친 끊김**
- A (1→2): VOC 1위가 "가격"인데 해결은 병원 정보 중심 → 1장을 "고를 근거(병원·시간·가격)가 비어 있다"로 묶고, 2장에서 가격은 "공공 자료 있는 항목만 범위 + 병원 견적 요청"이라고 정직하게 말함
- B (3→4): "트립닥은 병원 무료인데 왜 내나" → 4장에 "광고는 안 와도 돈, 우리는 결제된 진료만" + 코디 시간 절감은 [가정]으로
- C (4→5): MVP가 BM의 정산까지 보여 주지 않음 → 5장은 "예약 요청까지"로 범위를 좁혀 말함

## 3. 데모 과업 (1개 고정)

**"린이 로그인 → 챗봇에 'I have acne scars and want treatment in Suseong-gu' → 병원 카드 → 예약 요청 초안"**
- 고른 이유: AI 시나리오 평가 12/12 (`ai/agent/eval/results/2026-11-11-*-7a-verify.md`), 수동 검증 2번 통과 (`docs/7b-수동검증.md`)
- **[가정]**: 사람 테스트 완료율로 고른 게 아님 → 팀 밖 3~5명 테스트 후 완료율 가장 높은 과업으로 다시 고정
- 대비: Gemini 무료 하루 20회 → 발표 당일 챗봇 호출 아끼기 + Nemotron 자동 전환 + **녹화 영상 백업**
- 규제: 가상 병원·가상 환자, 공개 URL에선 실제 제출 막음 (`docs/compliance.md` 0절 ①)
