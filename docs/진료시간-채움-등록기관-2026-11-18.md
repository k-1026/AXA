## 2. 채우는 규칙

- 칸: `mon`~`sun` = `10:00-19:00` 또는 `휴진` (모르면 비움 — 빈칸 = 확인 안 됨, 휴진으로 단정 X) · `lunch_week`·`lunch_sat` = `13:00-14:00` · `holiday` = 공휴일 안내 원문
- `source_grade`(공식 = 병원 홈페이지 / 지도·플랫폼은 개인 등급) · `source_url` · `checked_at`(YYYY-MM-DD) 칸마다 필수 (CLAUDE.md 리서치 규칙)
- `need_match`는 `ykiho` 칸에 확인한 기호를 넣고 `note`에 "후보 확인" 또는 찾은 방법
- 우선순위: 피부·성형 37곳 → 나머지 `need_fill` → `need_match` 중 API 진료시간 없는 곳
