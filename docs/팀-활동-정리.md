## 읽을 때 주의

- **기간 끝이 11/23로 몰린 이유**: 11/23에 요금안 v4 표현을 문서 전체에 맞추는 일괄 수정이 있었어요. 실제 집중 작업 기간은 이보다 짧은 활동이 많아요. 예를 들면 서비스 기획·설계는 11/12~11/18, 진행 발표는 11/12~11/19에 커밋 80%가 몰려 있어요.
- **10/29 시작**: 저장소를 만든 날이에요. 백엔드·AI처럼 그날 뼈대만 만들어 둔 활동도 시작일이 10/29로 나와요.
- **참여 인원**은 커밋 작성자를 기준으로 셌어요. 같이 논의하고 한 사람이 올린 작업은 1명으로 잡혔을 수 있어요.
- 공개 저장소라서 팀원 이름은 적지 않았어요.
