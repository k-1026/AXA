# 번역·표기 기준 — 병원 이름 · 지역명 · 주소 · 진료과 (2026-11-26)

메디대구 웹(6개 언어: 한국어 · 영어 · 중국어 간체 · 중국어 번체 · 베트남어 · 일본어)에서 고유명사와 용어를 어떻게 적는지 정한 기준.
코드: `apps/web-platform/scripts/romanize.mjs`(영어 이름 만들기) · `apps/web-platform/src/features/hospital/localize.ts`(중·베·일 이름, 주소) · `src/i18n/locales/*.json`(지역명·진료과·기관 종류)
규칙을 바꾸면 이 문서와 위 코드를 같이 고친다.

---

## 1. 대원칙

1. **원본은 한국어.** 데이터에는 한국어 이름·주소만 있고, 다른 언어는 이 기준대로 만든다
2. **고유한 이름은 번역하지 않는다.** 뜻을 짐작해 새 이름을 짓지 않고, 소리만 알파벳으로 적는다
3. **뜻이 정해진 부분만 번역한다.** 진료과(피부과), 기관 종류(의원·병원), 시·구 이름
4. **주소는 한국어 원문을 항상 같이 보여 준다.** 택시·지도 앱에는 원문이 정확하다
5. **확인되지 않은 표기는 쓰지 않는다.** 한자 이름·공식 영문명은 출처가 있을 때만 쓴다

## 2. 병원 이름

### 2-1. 어떤 이름을 쓰나 (우선순위)

| 순위 | 이름 | 조건 | 상태 |
|---|---|---|---|
| ① | **병원 공식 영문명** | 메디컬코리아 등록기관 목록(`data/processed/daegu_registered_institutions.csv`의 `name_en`) 또는 병원 홈페이지에 적힌 영문명 | 계획 (아직 미적용) |
| ② | **자동 표기 — 낱말 단위** | 국어의 로마자 표기법대로 낱말을 붙여 씀 (예: Gyemyeong) | 계획 (아직 미적용) |
| ③ | 자동 표기 — 음절 단위 | 지금 방식 (예: Gye Myeong) | **현재** |

- 공식 영문명이 있으면 그것을 영어 이름으로 쓰고, 중국어·일본어·베트남어도 그 영문명을 바탕으로 진료과·기관 종류만 번역한다
- 공식 영문명의 출처와 확인일을 데이터에 같이 남긴다

### 2-2. 자동 표기 만드는 순서

1. 법인 표시 `(재)` `(의)` `(사)` `(학)` `(주)`, 이름 뒤 한자 병기 `(東山)` 삭제
2. 이름 끝에서 **기관 종류**를 떼어 번역 (긴 것부터: 대학교병원 → 요양병원 → 한방병원 → … → 병원 → 의원)
3. 그 앞에서 **진료과**를 떼어 번역 (긴 것부터: 마취통증의학과 → … → 외과 → 안과)
4. 남은 고유 이름은 로마자로
5. 지점명("○○점")은 고유 이름 쪽에 붙인다 — 아트너의원 죽전점 → Ateuneo Jukjeon Clinic

### 2-3. 언어별 형식

| 언어 | 형식 | 예: 고운미피부과의원 |
|---|---|---|
| 한국어 | 원래 이름 | 고운미피부과의원 |
| 영어 | 고유 이름 + 진료과 + 기관 | Go Un Mi Dermatology Clinic |
| 중국어 간체 | 고유 이름(알파벳) + 진료과·기관(한자) | Go Un Mi 皮肤科诊所 |
| 중국어 번체 | 고유 이름(알파벳) + 진료과·기관(한자) | Go Un Mi 皮膚科診所 |
| 일본어 | 고유 이름(알파벳) + 진료과·기관 | Go Un Mi 皮膚科クリニック |
| 베트남어 | 기관 + 진료과 + 고유 이름 (베트남어 어순) | Phòng khám Da liễu Go Un Mi |

### 2-4. 일본어·중국어의 고유 이름

- **일본어: 고유 이름은 알파벳 그대로.** 가타카나로 소리를 옮기지 않는다
  - 이유: 한국어 소리를 가타카나로 정확히 옮기기 어렵고, 틀린 표기는 오히려 찾기 어렵다. 알파벳은 지도·간판·영문 홈페이지와 맞춰 볼 수 있다
- **중국어: 고유 이름은 알파벳.** 병원이 직접 쓰는 한자 이름이 확인된 경우만 한자로 쓴다
  - 한글 이름의 한자를 추측해서 적지 않는다 (같은 소리에 한자가 여러 개라 틀리기 쉽다)
  - 예: 계명대학교 → 啓明大學校는 학교 공식 표기가 있으므로 가능, 동네 의원의 한자는 추측 금지

### 2-5. 시연용 가상 병원

이름 뒤에 언어별 표시를 붙인다 (`name.ts`의 DEMO_SUFFIX):
한국어 `(가상 · 시연용)` · 영어 `(Demo · not a real clinic)` · 중국어 번체 `（虛擬 · 示範用）` · 간체 `（虚拟 · 演示用）` · 베트남어 `(Ảo · dùng để minh họa)` · 일본어 `（架空 · デモ用）`

## 4. 주소

- 도로명·동 이름은 로마자 (국어의 로마자 표기법, 낱말을 붙여 씀)
- 끝말은 정해진 표기: 대로 `-daero` · 로 `-ro` · 길 `-gil` · 번길 `-beon-gil` · 동 `-dong` · 가 `-ga` · 읍 `-eup` · 면 `-myeon` · 리 `-ri`
- 층수: 3층 → `3F`, 지하1층 → `B1F`
- 원본에 주소가 두 번 들어간 행은 두 번째를 뺀다

| 언어 | 순서 | 예: 대구광역시 북구 침산로 138 |
|---|---|---|
| 영어·베트남어 | 번지 도로명, (읍·면,) 구, Daegu | 138 Chimsan-ro, Buk-gu, Daegu |
| 중국어 | 시·구(한자) + 도로명(로마자) 번지 | 大邱广域市 北区 Chimsan-ro 138 |
| 일본어 | 시·구(한자) + 도로명(로마자) 번지 | 大邱広域市 北区 Chimsan-ro 138 |

화면에는 옮긴 주소 아래에 **한국어 원문**을 작게 같이 보여 준다 (`HospitalAddress.tsx`).
