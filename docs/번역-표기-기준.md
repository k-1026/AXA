# 번역·표기 기준 — 병원 이름 · 지역명 · 주소 · 진료과 (2026-11-26)

메디대구 웹(6개 언어: 한국어 · 영어 · 중국어 간체 · 중국어 번체 · 베트남어 · 일본어)에서 고유명사와 용어를 어떻게 적는지 정한 기준.
코드: `apps/web-platform/scripts/romanize.mjs`(영어 이름 만들기) · `apps/web-platform/src/features/hospital/localize.ts`(중·베·일 이름, 주소) · `src/i18n/locales/*.json`(지역명·진료과·기관 종류)
규칙을 바꾸면 이 문서와 위 코드를 같이 고친다.

---

## 1. 대원칙

1. **원본은 한국어.** 데이터에는 한국어 이름·주소만 있고, 다른 언어는 이 기준대로 만든다
2. **고유한 이름은 번역하지 않는다.** 뜻을 짐작해 새 이름을 짓지 않고, 소리만 알파벳으로 적는다
3. **뜻이 정해진 부분만 번역한다.** 진료과(피부과), 기관 종류(의원·병원), 시·구 이름
4. **주소는 한국어 원문을 항상 같이 보여 준다.** 택시·지도 앱에는 원문이 정확하다
5. **확인되지 않은 표기는 쓰지 않는다.** 한자 이름·공식 영문명은 출처가 있을 때만 쓴다

## 2. 병원 이름

### 2-1. 어떤 이름을 쓰나 (우선순위)

| 순위 | 이름 | 조건 | 적용 (2026-11-26, 161곳) |
|---|---|---|---|
| ① | **수동 지정** | 공식 영문명이 약어뿐(KNUH) · 띄어쓰기 없음 · 같은 브랜드 공식 표기가 따로 있음 → `romanize.mjs`의 `MANUAL` | 4곳 |
| ② | **병원 공식 영문명** | 메디컬코리아 등록기관 목록(`data/processed/daegu_registered_institutions.csv`의 `name_en`). 지금 한국어 이름과 **다른 병원 이름**인 것은 `REJECT_OFFICIAL`로 뺀다 | 153곳 |
| ③ | **자동 표기 — 낱말 단위** | 공식 영문명이 없거나 뺀 경우. 국어의 로마자 표기법대로 낱말을 붙여 씀 (예: Gounmi) | 3곳 |

- 음절마다 띄우던 예전 방식(Go Un Mi)은 쓰지 않는다
- 공식 영문명은 **브랜드 표기는 그대로** 두고 아래만 정리한다 (`tidyOfficial`)
  - 대소문자: 모두 대문자·소문자로 시작하는 낱말은 첫 글자만 대문자 (DAEGU FATIMA → Daegu Fatima). 약어(ENT · FM · BL · CHA 등)와 원래 섞인 대소문자(HwaJubMong)는 그대로
  - 오타: Meddicine · Orietnal · Hosptal · Clinnic · Clininc · Dermatologic
  - 붙어 있는 기관 종류 띄우기: hanmihospital → Hanmi Hospital
  - 한방 표기 통일: Oriental Medicine · Korean Medical · Haniwon → Korean Medicine (5-1)
  - 괄호 설명, 끝의 지역 "Daegu" 삭제
  - 기관 종류 낱말(Clinic · Hospital · Center)이 없으면 한국어 이름의 기관 종류를 붙임 (Gounmi Dermatology → Gounmi Dermatology Clinic)
- 공식 영문명은 외래어 브랜드(더블랙 → The Black, 리프트 → Lift)가 많아서 소리 비교로 자동으로 거르지 않는다. 다른 병원 이름인 것은 사람이 확인해 `REJECT_OFFICIAL`에 넣는다 (지금 3곳: 리브의원 · 픽미의원 · 상연의원)
- 중국어·일본어·베트남어도 이 영어 이름을 바탕으로 끝의 진료과·기관 종류만 번역한다. 끝이 기관 종류가 아닌 이름(CHA University Fertility Center 등 2곳)은 영어 그대로

### 2-2. 자동 표기 만드는 순서

1. 법인 표시 `(재)` `(의)` `(사)` `(학)` `(주)`, "의료법인 ○○의료재단" 앞머리, 한자 병기 `(東山)`, 영문 병기 `(H)` 삭제
2. 이름 끝에서 **기관 종류**를 떼어 번역 (긴 것부터: 대학교병원 → 요양병원 → 한방병원 → 치과병원 → 치과의원 → … → 병원 → 의원)
3. 그 앞에서 **진료과**를 떼어 번역 (긴 것부터: 마취통증의학과 → … → 외과 → 안과)
4. 남은 고유 이름은 로마자로, **띄어쓰기 단위로 붙여 씀** (고운미 → Gounmi). 받침 ㄹ + 초성 ㄹ은 ll (신라 → Silla). 소리 동화(종로 → Jongno)는 반영하지 않음
5. 이름 중간의 '대학교'는 University (계명대학교동산병원 → Gyemyeong University Dongsan Hospital)
6. 지점명("○○점")은 고유 이름 쪽에 붙인다 — 리브의원 대구점 → Ribeu Daegu Clinic

### 2-3. 언어별 형식

| 언어 | 형식 | 예: 고운미피부과의원 |
|---|---|---|
| 한국어 | 원래 이름 | 고운미피부과의원 |
| 영어 | 고유 이름 + 진료과 + 기관 | Gounmi Dermatology Clinic |
| 중국어 간체 | 고유 이름(알파벳) + 진료과·기관(한자) | Gounmi 皮肤科诊所 |
| 중국어 번체 | 고유 이름(알파벳) + 진료과·기관(한자) | Gounmi 皮膚科診所 |
| 일본어 | 고유 이름(알파벳) + 진료과·기관 | Gounmi 皮膚科クリニック |
| 베트남어 | 기관 + 진료과 + 고유 이름 (베트남어 어순) | Phòng khám Da liễu Gounmi |

- 공식 영문명에서 기관 종류 뒤에 붙은 지점·지역은 고유 이름 쪽으로 옮긴다: Artner Clinic Juk-Jeon → 중국어 Artner Juk-Jeon 诊所

### 2-4. 일본어·중국어의 고유 이름

- **일본어: 고유 이름은 알파벳 그대로.** 가타카나로 소리를 옮기지 않는다
  - 이유: 한국어 소리를 가타카나로 정확히 옮기기 어렵고, 틀린 표기는 오히려 찾기 어렵다. 알파벳은 지도·간판·영문 홈페이지와 맞춰 볼 수 있다
- **중국어: 고유 이름은 알파벳.** 병원이 직접 쓰는 한자 이름이 확인된 경우만 한자로 쓴다
  - 한글 이름의 한자를 추측해서 적지 않는다 (같은 소리에 한자가 여러 개라 틀리기 쉽다)
  - 예: 계명대학교 → 啓明大學校는 학교 공식 표기가 있으므로 가능, 동네 의원의 한자는 추측 금지

### 2-5. 시연용 가상 병원

이름 뒤에 언어별 표시를 붙인다 (`name.ts`의 DEMO_SUFFIX):
한국어 `(가상 · 시연용)` · 영어 `(Demo · not a real clinic)` · 중국어 번체 `（虛擬 · 示範用）` · 간체 `（虚拟 · 演示用）` · 베트남어 `(Ảo · dùng để minh họa)` · 일본어 `（架空 · デモ用）`

이름은 지어낸 이름이라 언어별로 직접 정했다 (`name.ts`의 DEMO_NAMES, 영어는 `data/processed/demo/demo_hospitals.json`).
'예시'는 뜻이 있는 말이라 번역하고, 구 이름(수성·달서)은 3장대로 한자 언어에서 한자, 도로 이름(동성로)은 알파벳.

| 한국어 | 영어 | 중국어 번체 | 중국어 간체 | 일본어 | 베트남어 |
|---|---|---|---|---|---|
| 예시 피부과의원 | Example Dermatology Clinic | 範例皮膚科診所 | 示例皮肤科诊所 | サンプル皮膚科クリニック | Phòng khám Da liễu Mẫu |
| 예시 수성피부과의원 | Example Suseong Dermatology Clinic | 範例壽城皮膚科診所 | 示例寿城皮肤科诊所 | サンプル寿城皮膚科クリニック | Phòng khám Da liễu Mẫu Suseong |
| 예시 동성로성형외과의원 | Example Dongseongno Plastic Surgery Clinic | 範例 Dongseongno 整形外科診所 | 示例 Dongseongno 整形外科诊所 | サンプル Dongseongno 形成外科クリニック | Phòng khám Thẩm mỹ Mẫu Dongseongno |
| 예시 달서안과의원 | Example Dalseo Eye Clinic | 範例達西眼科診所 | 示例达西眼科诊所 | サンプル達西眼科クリニック | Phòng khám Mắt Mẫu Dalseo |

## 4. 주소

- 도로명·동 이름은 로마자 (국어의 로마자 표기법, 낱말을 붙여 씀)
- 끝말은 정해진 표기: 대로 `-daero` · 로 `-ro` · 길 `-gil` · 번길 `-beon-gil` · 동 `-dong` · 가 `-ga` · 읍 `-eup` · 면 `-myeon` · 리 `-ri`
- 층수: 3층 → `3F`, 지하1층 → `B1F`
- 원본에 주소가 두 번 들어간 행은 두 번째를 뺀다

| 언어 | 순서 | 예: 대구광역시 북구 침산로 138 |
|---|---|---|
| 영어·베트남어 | 번지 도로명, (읍·면,) 구, Daegu | 138 Chimsan-ro, Buk-gu, Daegu |
| 중국어 | 시·구(한자) + 도로명(로마자) 번지 | 大邱广域市 北区 Chimsan-ro 138 |
| 일본어 | 시·구(한자) + 도로명(로마자) 번지 | 大邱広域市 北区 Chimsan-ro 138 |

화면에는 옮긴 주소 아래에 **한국어 원문**을 작게 같이 보여 준다 (`HospitalAddress.tsx`).
