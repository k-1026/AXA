## 3. 테스트 · 평가 (마지막 확인)
- 단위 테스트: AI 232개 · 백엔드 302개 통과, 프론트 `tsc` 통과
- 실제 모델(nemotron) 평가: 기존 시나리오 12/12 · 한 번에 묻는 예약 4/4 · 국내 거주 6/6
- 일본어 대화 1번: 일요일 예약 요청 → "휴진" 안내 + 진료시간 + 다른 시간 질문

## 4. 알게 된 것 (숫자)
- 배포 로그 4턴: 7~15.4초. 그중 LLM 외 시간은 1초 미만
- "통역 돼요?" 한 줄: 생각 켬 2.9초·304토큰(그중 생각 285) / 끔 0.9초·16토큰
- NVIDIA 무료 API는 날에 따라 턴당 20~80초까지 튐 → 타임아웃·재시도 줄이기 필요
- 대화형 응답 기준: 10초 넘으면 주의가 흩어짐 (NN/g). 피클 같은 작업 위임형은 몇 분~몇 시간도 받아들여짐 → 우리 예약은 되묻는 대화라 백그라운드보다 **진행 표시 + 묻는 횟수 줄이기**
- 진료과는 DB에 4개만(내과·안과·피부과·성형외과). 등록 유치의료기관은 4,246곳 중 164곳. 예시 병원에 내과가 없어 내과 추천·예약은 빈 결과
