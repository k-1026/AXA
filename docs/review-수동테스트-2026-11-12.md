# 리뷰 수정 수동 테스트 (PR #22 백엔드 · #23 프론트)

## 서버
- 프론트: http://localhost:5173 (`axa-wt-frontend`, 브랜치 `frontend-review-fix`)
- 백엔드: http://localhost:8000/docs (`axa-wt-backend`, 브랜치 `backend-review-fix`)
- DB: **로컬 SQLite**(scratchpad의 `test.db`, 0001~0005 적용). 공용 Supabase는 쓰지 않음
- `CRON_SECRET=local-test-cron-secret-1234` (테스트용)
- 계정은 `@example.com` 가짜 계정만 쓰기. 비밀번호 예: `test-password-1234`
- ⚠️ `tester-a@example.com`은 시도 제한 확인 때문에 **15분 동안 잠김** → 브라우저 테스트는 `tester-b`, `tester-c`로 새로 가입해서 하기
- 챗봇 질문 1번에 LLM이 약 2번 호출됨 (Gemini 무료 하루 20회)

## 이미 확인함 (curl)
| 확인 | 결과 |
|---|---|
| 예전 동의 버전(`2026-11`)으로 가입 | 422 ✅ |
| 현재 버전(`2026-11-03`)으로 가입 / 같은 메일 다시 | 201 / 409 `auth.email_taken` ✅ |
| 틀린 비밀번호 6번 | 401×5 → 429 ✅ |
| `/internal/purge` 비밀값 없이 / 있게 | 401 / `{"chat_sessions":0,"auth_sessions":0}` ✅ |
| `/exchange-rates` | 200 (0.9초) ✅ |
| 로그인 없이 `/chatbot` | "로그인이 필요해요" 화면 ✅ |

## 직접 해 볼 것 (브라우저)
| # | 해 볼 것 | 기대 결과 | 관련 수정 |
|---|---|---|---|
| 1 | B로 가입 → 챗봇에 질문 2~3개 → 로그아웃 → **같은 탭**에서 C로 가입 → 챗봇 | C 화면에 B의 대화가 **안 보임** | Critical: 계정 간 데이터 노출 |
| 2 | B로 병원 찜 2곳, 마이페이지에 방문 기록 1개 → 로그아웃 → C로 로그인 → 마이페이지 | C에게 B의 찜·방문 기록이 **안 보임**. B로 다시 로그인하면 B 것은 그대로 | 찜·방문 기록 계정별 저장 |
| 3 | 데모 로그인 → 챗봇·상담 화면 → 로그아웃 → B 로그인 | 데모의 예시 대화·상담이 B에게 안 보임. "담당자 응답 가능" 표시는 데모에서만 보임 | 계정 분리, 상담 화면 |
| 4 | B로 대화 2개 만들기 → 새로고침 → 오래된 대화를 골라 **불러오는 동안 바로 입력** | 불러오는 동안 "불러오는 중" 표시, 보내기 버튼이 막힘. 불러온 뒤 질문하면 정상 | 불러오는 중 입력 막기 |
| 5 | 오래된 대화에 질문을 이어서 보냄 → 새로고침 | 그 대화가 목록 **맨 위**로 감 | 마지막 메시지순 정렬 |
| 6 | 대화를 고른 상태에서 백엔드 서버를 끄고 다른 대화 선택 (끄기는 Claude에게 요청) | 대화가 목록에서 **사라지지 않고** "다시 시도" 버튼이 나옴 | 불러오기 실패 처리 |
| 7 | 로그인한 채로 백엔드 쪽 세션을 없애기 (다른 탭에서 로그아웃 후 원래 탭에서 질문, 또는 Claude에게 토큰 무효화 요청) | 질문하면 자동으로 로그아웃되고 로그인 화면으로 감 | 401 자동 로그아웃 |
| 8 | 입력창에 1000자 넘게 붙여 넣기 | 1000자에서 더 안 들어감 | maxLength |
| 9 | "I can't breathe, chest pain" | 119 안내, **AI 표시 없음** | 응급 문구 ai=false |
| 10 | "acne scars in Suseong-gu, I speak English" → 병원 카드 | 진료과·지역·언어가 **화면 언어로 번역**됨 (영어 코드 그대로 X) | 카드 번역 |
| 11 | 답을 기다리는 중인 **새 대화**를 삭제 → 새로고침 | 새로고침 뒤에도 그 대화가 다시 나타나지 않음 | 대기 중 삭제 |
| 12 | 상담/예약 → 예약 신청에서 날짜를 **오늘**로 → 이미 지난 시간 선택 | 오류 문구가 나오고 신청 안 됨 | 지난 시간 막기 |
| 13 | 마이페이지 예약 목록 필터 (데모 계정) | 상태 이름이 계약 코드(확인 대기·확정·거절·다른 시간 제안·취소·만료·방문 완료)로 나옴, 확정 예약은 취소·변경 버튼 없음 | 상태 코드 계약 맞춤 |
| 14 | `/hospitals?dept=abc` 주소로 직접 들어가기 | 잘못된 값은 무시하고 전체 목록 | `?dept=` 검증 |
| 15 | 하단 "AI 서비스 안내", "개인정보 처리방침" 열기 | "저장하지 않음"이 아니라 "회원 대화 30일 저장·삭제 버튼·탈퇴 시 삭제", 회원 계정 항목이 있음 (초안) | 고지 문구 |
| 16 | B 탈퇴 (마이페이지) → 같은 메일로 다시 가입 | 탈퇴 후 B의 찜·방문 기록·대화가 브라우저에 안 남음. 다시 가입 가능 | 탈퇴 시 정리 |
| 17 | 언어를 바꿔 가며 (ko·en·zh-TW·zh-CN·vi) 챗봇·마이페이지 훑어보기 | 빈 문구나 키 이름(`chat.xxx`)이 그대로 보이는 곳 없음 | 새 i18n 키 |
