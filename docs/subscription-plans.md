## 원칙

- 대상: 외국인환자 유치의료기관으로 **등록된 병원**만
- 병원은 **체결 진료 수수료**와 **월 구독료**를 같이 냄. 입점 후 첫 3개월은 구독료 무료
- 요금제·구독 여부는 정보 웹·챗봇 제안의 노출·순서에 영향 없음. 구독하지 않은 병원도 공공정보는 똑같이 노출
- **수수료 + 구독료를 합쳐 종별 상한 이하**로 유지 (아래 "상한 안전장치")

## 요금

| | **체결 진료 수수료** | **월 구독료** |
|---|---|---|
| 성격 | 외국인환자 **유치 수수료** (고시 제2조) | **대시보드·도구 이용료** — 환자 연결 대가를 넣지 않음 |
| 계산 | 그 달 **방문 완료·완납 건 진료비 합계 × 10%** | 매월 정액 |
| 금액 | 10% (가정값). **종별 상한 이하**: 의원 30%·병원 20%·상급종합 15% (부가세 제외 총진료비) | 사후관리 이용 **₩69,000** (사후관리 채팅 월 30건, 초과 1건 ₩2,000) / 사후관리 미이용 **₩99,000** (가정값) |
| 포함 | — | 대시보드·상담 예약 **관리 도구**(요청함·캘린더·답장 초안)·병원 설정 (+ 사후관리 채팅) |
| 한도 기준 | — | 기능·사후관리 채팅 건수. **환자 수·예약 건수와 무관** |
| 병원이 입력할 것 | 방문 완료 + 건별 진료비 (방문일 +7일, 없으면 알림) | — (수수료 입력과 같음) |

- 통역·숙박 등 비의료서비스 대가는 진료비에서 뺌 (고시 제2조)
- 병원에서 받는 결제 정보는 예약번호·방문일·진료비(완납 여부)만. 진료 항목·진단명 X
- 정산 흐름: 병원 입력 → 환자 확인(선택) → 월말 정산서(수수료 + 구독료) 자동 생성 → 병원 확인 → 익월 청구 (E-2)
- 시안 병원 한 달 (방문 24명, 확인 21건 진료비 ₩32,130,000 [가정]): 수수료 ₩3,213,000 + 구독료 ₩69,000 = ₩3,282,000 (진료비의 10.2%)

## 상한 안전장치 (잠정, 출시 전 복지부 질의)

- 구독료가 유치 수수료 상한 계산에 **합산되는지 미확인** (compliance 3절 2번)
- 그래서 합산된다고 보고 설계: 그 달 **(수수료 + 구독료) > 경유 진료비 합계 × 종별 상한**이면 넘는 만큼 **구독료에서 빼거나 다음 달에 차감**
  - 예: 의원이 그 달 방문 완료 1건·진료비 ₩200,000 → 상한 ₩60,000. 수수료 ₩20,000 + 구독료 ₩99,000 = ₩119,000 → ₩59,000 차감
  - 방문 완료 0건인 달: 상한 0 → 구독료를 받을지가 질의의 핵심. 회신 전에는 **차감(사실상 무료)** 으로 둠
- 첫 3개월 무료 기간에도 수수료는 상한 이하만
