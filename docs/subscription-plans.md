## 원칙

- 대상: 외국인환자 유치의료기관으로 **등록된 병원**만
- 병원은 **B 수수료** 또는 **A 구독** 중 하나를 고름. **초기에는 B만 열고**, 실적이 쌓이면 A를 고를 수 있게 함
- 요금제(A·B)는 정보 웹·챗봇 제안의 노출·순서에 영향 없음. 요금제가 없는 병원도 공공정보는 똑같이 노출
- 요금제는 분기마다 바꿀 수 있음 (제안, 매달 바꾸면 환자 적은 달만 B로 옮기는 문제)

## 요금제

| | **B 수수료 (주)** | **A 구독 (선택, 나중)** |
|---|---|---|
| 성격 | 외국인환자 **유치 수수료** (고시 제2조) | **대시보드·도구 이용료** — 환자 연결 대가를 넣지 않음 |
| 계산 | 그 달 **방문 완료·완납 건 진료비 합계 × 지정 %** | 매월 정액 |
| 금액 | 지정 % = 5~10%, 기준 7% (가정값). **종별 상한 이하**: 의원 30%·병원 20%·상급종합 15% (부가세 제외 총진료비) | 월 20만~40만 원 (가정값) |
| 한도 기준 | — | 기능·좌석(직원 계정 수)·AI 사용량. 환자 수·예약 건수와 무관 |
| 상한 안전장치 | 지정 % ≤ 상한이면 문제 없음 | 그 달 구독료 > 경유 진료비 합계 × 상한이면 **차액 환급 또는 다음 달 차감** (**잠정**, 출시 전 복지부 질의) |
| 병원이 입력할 것 | 방문 완료 + 건별 진료비 (방문일 +7일, 없으면 알림) | 방문 완료 + 월 진료비 합계 (상한 계산용) |

- 통역·숙박 등 비의료서비스 대가는 진료비에서 뺌 (고시 제2조)
- 병원에서 받는 결제 정보는 예약번호·방문일·진료비(완납 여부)만. 진료 항목·진단명 X
- 정산 흐름: 병원 입력 → 환자 확인(선택) → 월말 정산서 자동 생성 → 병원 확인 → 익월 청구 (E-2)

## 기능 (두 요금제 공통으로 시작, 나눌지는 나중)

| 묶음 | 기능 |
|---|---|
| 기본 | 요청함·캘린더, 번역, AI 요약, 답장 초안(직원 승인 후 발송), 예약 시간 제안, 병원 설정 |
| 지표 | 유입·상담·예약·사후관리 지표 (`docs-dashboard-integration` 명세), 공공 카드 |

## 정하지 않은 것

| # | 질문 | 제안 |
|---|---|---|
| 1 | 사후관리 건당 비용은 A에 포함? 따로? | A 포함, B 따로 (E-3 Q9) |
| 2 | 지정 %·구독료 확정 | 시장 검증(유치업체 요율, 코디 인터뷰) 후 |
| 3 | 지표를 A 전용으로 할지 | 시작은 공통, 운영 데이터가 쌓이면 다시 판단 |
