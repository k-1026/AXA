## 원칙

- 대상: 외국인환자 유치의료기관으로 **등록된 병원**만
- 병원은 **기본 회원**(회원비 없음, 수수료 13%)과 **프리미엄 회원**(월 회원비 + 수수료 8%) 중 고름
- 등급은 정보 웹·챗봇 제안의 노출·순서에 영향 없음. 기본 회원과 회원이 아닌 병원도 공공정보는 똑같이 노출
- **수수료 + 회원비를 합쳐 종별 상한 이하**로 유지 (아래 "상한 안전장치")

## 요금

| | **기본 회원** | **프리미엄 회원** |
|---|---|---|
| 회원비 | **무료** | 연 **₩1,800,000** (월 환산 ₩150,000) — **대시보드·도구 이용료**, 환자 연결 대가를 넣지 않음 |
| 체결 진료 수수료 (외국인환자 **유치 수수료**, 고시 제2조) | 그 달 **방문 완료·결제 확인된 진료비 합계 × 13%** | 같은 기준 × **8%** |
| 쓰는 기능 | 병원 정보 관리 · 예약 요청 받기·확정 | + AI 요약·번역·답장 초안 · 사후관리 채팅 · 분석 탭 |
| 맞는 병원 | 외국인 환자가 적은 작은 의원 | 환자가 많은 병원 (진료비 월 300만 원, 약 월 3건 넘으면 이득) |
| 상한 | 의원 30%·병원 20%·상급종합 15% 이하 (부가세 제외 총진료비) | 같음 — 월 1건(100만 원)이어도 8% + 15% = 23%로 의원 상한 안 |
| 병원이 입력할 것 | 방문 완료 + 건별 진료비 (방문일 +7일, 없으면 알림) | 같음 |

- 통역·숙박 등 비의료서비스 대가는 진료비에서 뺌 (고시 제2조)
- 병원에서 받는 결제 정보는 예약번호·방문일·진료비(완납 여부)만. 진료 항목·진단명 X
- 정산 흐름: 병원 입력 → 환자 확인(선택) → 월말 정산서(수수료 + 회원비) 자동 생성 → 병원 확인 → 익월 청구 (E-2)
- 시안 병원 한 달 (결제 21건 × 100만 원 [추정], 프리미엄): 21 × 100만 원 × 8% + ₩150,000(연 ₩1,800,000 ÷ 12) = **₩1,830,000 (진료비의 8.7%)** · 같은 병원이 기본 회원이면 ₩2,730,000 (13%)

## 상한 안전장치 (잠정, 출시 전 복지부 질의)

- 프리미엄 회원비가 유치 수수료 상한 계산에 **합산되는지 미확인** (compliance 3절 2번). 기본 회원은 회원비가 없어 해당 없음
- 그래서 합산된다고 보고 설계: 그 달 **(수수료 + 회원비) > 경유 진료비 합계 × 종별 상한**이면 넘는 만큼 **회원비에서 빼거나 다음 달에 차감**
  - 예: 프리미엄 의원이 그 달 방문 완료 1건·진료비 ₩200,000 → 상한 ₩60,000. 수수료 ₩16,000 + 회원비 월 환산 ₩150,000 = ₩166,000 → ₩106,000 차감 (연 회원비에서 빼거나 다음 해에 반영)
  - 방문 완료 0건인 달: 상한 0 → 회원비를 받을지가 질의의 핵심. 회신 전에는 **차감(사실상 무료)** 으로 둠
