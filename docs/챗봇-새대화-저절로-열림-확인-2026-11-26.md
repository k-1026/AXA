# 챗봇: 새 대화가 저절로 열리는 이유 확인 (2026-11-26)

결론: **서버 오류가 아니라 화면 코드(`apps/web-platform/src/features/chatbot/useConversations.ts`)의 동작**이다. 원인은 세 가지다.

## 1. 서버에 저장되지 않은 대화는 다른 화면에 갔다 오면 새 대화로 바뀜 (재현됨)
재현 (회원 계정, 로컬):
1. 챗봇 → [새 대화] → 빠른 메뉴 "가격 정보" (서버에 저장 안 되는 대화)
2. 메뉴 "가격 가이드"로 갔다가 다시 "챗봇"
3. → **새 대화(14:27)가 새로 생겨서 열림**. 방금 대화는 목록에 "가격 정보 안내"로 남아 있지만 선택되지 않음

원인
- 다시 들어오면 "지금 보던 대화"를 **서버 대화 id(serverId)로만** 기억해서 다시 연다 (`chat.active@계정`, sessionStorage)
- 서버 id가 없는 대화는 기억되지 않는다 → 목록에 "시작 전 대화"가 없으면 하나 만들고(`withBlank`) 그것을 연다
- 서버 id가 없는 대화가 생기는 경우:
  - 빠른 메뉴 "가격 정보"만 누른 대화 (오늘 넣은 기능, 서버를 거치지 않음)
  - **첫 질문이 오류로 끝난 대화**: 백엔드가 꺼져 있었거나(오늘 14:06~14:25 로컬 백엔드가 앱에 의해 꺼져 있었음 → "서버에 연결할 수 없어요"), 429·503 등
  - 서버에서 지워진 대화(not_found) → 다음 질문부터 새 서버 대화

## 2. 목록의 모든 회원 대화가 "새 대화"로 표시됨 (확인됨)
- 서버에는 제목이 저장돼 있다 (`GET /chatbot/sessions` → "수성구 피부과 찾아줘", "동성로 피부과 의원 가상 예약 가능해" …, 이 계정 8개)
- 그런데 목록 글자는 `topic`(병원 찾기·가격 정보 등 데모용 분류)으로만 정해져, 회원 대화는 전부 "새 대화"
- 그래서 지난 대화도 새 대화처럼 보이고, 실제로 새로 생긴 빈 대화와 구분이 안 된다

## 3. 새로고침·새 탭·다시 로그인하면 잠깐(약 1.5초) 빈 새 대화가 보임 (확인됨)
- 대화 목록은 메모리에만 있어서 새로고침하면 빈 대화 하나로 시작 → 서버 목록을 받은 뒤 보던 대화로 바뀜
- sessionStorage는 탭마다 따로라, **새 탭이나 다시 로그인하면 보던 대화를 모르고 새 대화로 시작**
- 이때 빈 대화가 매번 하나씩 목록 맨 위에 생긴다 (질문하지 않으면 서버에는 안 생기고 새로고침하면 사라짐)

## 고칠 방법 (제안)
| # | 방법 |
|---|---|
| 1 | 보던 대화를 서버 id가 없어도 기억 (화면 id를 계정별 메모리에 같이 저장) → 다른 화면에 갔다 와도 그대로 |
| 2 | 회원 대화 목록 글자를 서버 제목(첫 질문)으로. 화면에만 있는 대화는 첫 질문 글로. "새 대화"는 아직 아무것도 묻지 않은 대화만 |
| 3 | 새로고침 직후 서버 목록을 받기 전에는 빈 대화 대신 "불러오는 중"을 보여 주기 (기억한 대화가 있을 때만) |

## 고친 것 (같은 날)
| # | 바꾼 것 | 재확인 (로컬 화면) |
|---|---|---|
| 1 | 보던 대화를 화면 id로도 계정별 메모리에 기억 (`activeMemory`) | [새 대화] → "가격 정보" → 가격 가이드 갔다 옴 → **같은 대화가 열림** (전: 새 대화가 생겨 열림) |
| 2 | 목록 글자 = 서버 제목(`GET /chatbot/sessions`의 title) → 화면에만 있는 대화는 첫 질문 → 둘 다 없을 때만 "새 대화". 예시·빠른 메뉴 대화는 주제 그대로 | "수성구 피부과 찾아줘", "동성로 피부과 의원 가상 예약 가능해" 등으로 표시 |
| 3 | 새로고침 직후 기억한 서버 대화를 바로 "불러오는 중" 대화로 넣음 (`withSaved`), 서버 목록이 오면 날짜·제목을 맞춤 | 새로고침 4초 동안 화면 상태: 없음 → 불러오는 중 → 대화. **빈 새 대화가 보이는 순간 없음** |

- 남은 것: 화면을 다시 열 때 목록에 "시작 전 대화"가 없으면 하나 만들어 두는 동작(`withBlank`)은 그대로다. 바로 입력할 수 있게 하려는 설계라 목록 맨 위에 "새 대화" 하나는 보이지만, 저절로 열리지는 않는다
- 새 탭·다시 로그인: 탭 저장소(sessionStorage)는 탭마다 따로라 새 탭에서는 여전히 새 대화로 시작 (서버 대화는 목록에서 고르면 됨)
