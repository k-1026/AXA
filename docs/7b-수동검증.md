# 7b 챗봇 API 수동 검증 (PR 전)

> 서버: http://localhost:8001/docs (Swagger) · 코드: `backend-A-chatbot` worktree · DB: **로컬 SQLite**(공용 Supabase 아님, `0001~0005` 적용됨)
> 가상 데이터·`@example.com` 가짜 계정만 쓴다. 챗봇 질문 1번에 LLM이 약 2회 호출된다 (Gemini 무료 하루 20회)

## 준비 (Swagger)
1. `POST /api/v1/auth/patient/signup`으로 가짜 계정 2개 만들기 (A, B) → 응답의 `access_token` 복사
   ```json
   {"email":"tester-a@example.com","password":"test-password-1234","age14_confirmed":true,"preferred_lang":"en","timezone":"Asia/Taipei",
    "consents":[{"kind":"terms","version":"2026-11"},{"kind":"privacy","version":"2026-11"}]}
   ```
2. 오른쪽 위 **Authorize**에 A의 토큰 붙여 넣기 (B로 바꿀 때 다시)

## 검증할 것

## curl로 하기 (Swagger 대신)

> **Git Bash**에서 실행 (PowerShell의 `curl`은 다른 명령이라 아래 문법이 안 맞음). 토큰·id를 변수에 담아 이어 쓴다

### 0. 준비
```bash
B=http://localhost:8001/api/v1
J='Content-Type: application/json'
SIGN='{"email":"tester-a@example.com","password":"test-password-1234","age14_confirmed":true,"preferred_lang":"en","timezone":"Asia/Taipei","consents":[{"kind":"terms","version":"2026-11"},{"kind":"privacy","version":"2026-11"}]}'
tok() { python -c "import sys,json;print(json.load(sys.stdin)['access_token'])"; }
sid() { python -c "import sys,json;print(json.load(sys.stdin)['session_id'])"; }
show() { python -c "import sys,json;d=json.load(sys.stdin);print(json.dumps(d,ensure_ascii=False,indent=2)[:1500])"; }
```

### 1. 계정 A·B 토큰 받기 (가입 시도 → 이미 있으면 로그인)
```bash
acct() {  # $1 = 이메일
  curl -s -X POST $B/auth/patient/signup -H "$J" -d "${SIGN/tester-a@example.com/$1}" | tok 2>/dev/null \
  || curl -s -X POST $B/auth/patient/login -H "$J" -d "{\"email\":\"$1\",\"password\":\"test-password-1234\"}" | tok
}
A=$(acct tester-a@example.com)
BB=$(acct tester-b@example.com)
echo "${A:0:12}… ${BB:0:12}…"   # 둘 다 eyJ… 로 시작하면 성공
```

### 2. 로그인 없이 → 401 (검증 1)
```bash
curl -s -w '\n%{http_code}\n' -X POST $B/chatbot/ask -H "$J" -d '{"message":"hi"}'
```

### 3. 첫 질문 → 세션 id 저장 (검증 2)
```bash
R=$(curl -s -X POST $B/chatbot/ask -H "Authorization: Bearer $A" -H "$J" -d '{"message":"I have acne scars and want treatment in Suseong-gu"}')
echo "$R" | show
S=$(echo "$R" | sid); echo $S
```

### 4. 대화 이어 가기 (검증 3·4) — 메시지만 바꿔 반복
```bash
ask() { curl -s -X POST $B/chatbot/ask -H "Authorization: Bearer $A" -H "$J" -d "{\"session_id\":\"$S\",\"message\":\"$1\"}" | show; }
ask "Tell me about the first one"
ask "I'm visiting Korea for a week"
ask "Book the first one on December 4 at 10:00. I want to ask about scar laser options."
ask "I'm from Taiwan."
ask "No, I don't need help with a visa."
```

### 5. 응급 표현 (검증 6) → `blocked: true`
```bash
ask "I can't breathe and have chest pain"
```

### 6. 다른 계정 접근 → 둘 다 404 (검증 7)
```bash
curl -s -w '\n%{http_code}\n' -X POST $B/chatbot/ask -H "Authorization: Bearer $BB" -H "$J" -d "{\"session_id\":\"$S\",\"message\":\"hi\"}"
curl -s -o /dev/null -w '%{http_code}\n' -X DELETE $B/chatbot/sessions/$S -H "Authorization: Bearer $BB"
```

### 7. 입력 오류 → 422 (검증 9)
```bash
curl -s -w '\n%{http_code}\n' -X POST $B/chatbot/ask -H "Authorization: Bearer $A" -H "$J" -d '{"message":"hi","language":"ja"}'
```

### 8. 내 대화 삭제 → 204, 다시 질문 → 404 (검증 8)
```bash
curl -s -o /dev/null -w '%{http_code}\n' -X DELETE $B/chatbot/sessions/$S -H "Authorization: Bearer $A"
curl -s -w '\n%{http_code}\n' -X POST $B/chatbot/ask -H "Authorization: Bearer $A" -H "$J" -d "{\"session_id\":\"$S\",\"message\":\"hi\"}"
```

> 토큰 만료로 401이 나오면 1번의 로그인 명령으로 `A`를 다시 받는다. 질문 1번에 LLM이 약 2회 호출되니 4번은 필요한 만큼만
